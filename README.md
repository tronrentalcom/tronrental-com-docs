## Agents tools reference

`snippets/agent-tools-<lang>.mdx` is generated from the backend tool catalog — do not edit it by hand. After a change to `backend/app/agent_access/catalog.py` in the main repo, run `python3 scripts/gen_agent_tools.py <main repo>/backend/app/agent_access/catalog.py` and commit the snippets.
