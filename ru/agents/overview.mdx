TronRental держит удалённый сервер [Model Context Protocol](https://modelcontextprotocol.io) (MCP) по адресу:

```
https://mcp.tronrental.com/mcp
```

Любой MCP-клиент — Claude, ChatGPT, Claude Code, Codex, Cursor или ваш собственный код — подключается к нему, входит через TronRental и получает инструменты для вашего аккаунта. Ничего не нужно устанавливать, API-ключ копировать не нужно.

## Что умеет агент

| Область | Примеры |
|---|---|
| Энергия и bandwidth | Узнать цену и купить энергию или bandwidth для любого TRON-адреса, активировать новый адрес, вернуть заказ bandwidth |
| Energy Broadcaster | Создать broadcast URL для кошелька, изменить его настройки, посмотреть его квоту и события |
| Подписки | Smart Mode, пакеты переводов, автопополнение энергии и bandwidth, авто-bandwidth, Energy Resale |
| Стейкинг | Застейкать TRX с баланса, вывести из стейкинга, забрать награды |
| Node API | Посмотреть тарифы и расход, купить тариф, начать пробный период |
| Инвойсы | Создать инвойс, отправить его по email, следить за статусом |
| Аккаунт | Баланс, история, заказы, адрес для депозита, отчёты |

Полный список — в [справочнике инструментов](/ru/agents/reference/tools). Агент видит только те инструменты, которые разрешены его подключению.

## Вы сохраняете контроль

  <Card title="Экран согласия" icon="hand">
    Когда агент подключается впервые, вы входите на tronrental.com и видите имя приложения и сайт, куда оно вернётся. Пока вы не подтвердите, ничего не передаётся.
  </Card>
  <Card title="Права" icon="key">
    Вы отмечаете, что агенту можно: читать, покупать энергию, вести Smart Mode и так далее. Траты, которые идут сами, — отдельная галочка, по умолчанию выключена. См. [права](/ru/agents/reference/permissions).
  </Card>
  <Card title="Суточный лимит расходов" icon="gauge">
    Каждое подключение может потратить не больше **100 TRX за 24 часа**, если вы не задали другую сумму. Изменить её можно в любой момент в разделе **Подключённые приложения** на [странице API](https://tronrental.com/dashboard/api) личного кабинета.
  </Card>
  <Card title="Отключение в любой момент" icon="plug-circle-xmark">
    **Отключить** в разделе «Подключённые приложения» отзывает подключение и все его токены сразу. Следующий вызов агента получит отказ.
  </Card>
</CardGroup>

- **Пополнение перед покупками.** Пока пополнения аккаунта в сумме не достигли 100 TRX, подключение может только читать: баланс, историю и адрес для депозита. После пополнения подключитесь заново, чтобы разрешить покупки.
- **Цена, с которой вы согласились.** Каждая покупка передаёт `max_price_trx` — агент сначала запрашивает цену и передаёт полученную сумму. Если цена поднимется выше, покупка отклоняется, а не списывается.
- **Без двойных списаний.** Покупки и другие создающие вызовы принимают ключ идемпотентности, поэтому повтор после потерянного ответа возвращает первый результат.
- **Без выводов.** Подключённое приложение никогда не может вывести средства. Вывод остаётся у API-ключей с правом `withdraw`, 2FA и белым списком IP.

Заказы, созданные агентом, помечены `source: "agent"` в [заказе](/ru/api-reference/orders/get-order) и в [вебхуке `order.updated`](/ru/api-reference/webhooks/overview).
