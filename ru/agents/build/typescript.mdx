## Установка

```bash
npm install @modelcontextprotocol/client
```

Запускайте клиент на своём сервере, а не в браузере: MCP-сервер отклоняет запросы с чужим заголовком `Origin`.

## Список инструментов и котировка

```ts quote.mjs
import { Client, StreamableHTTPClientTransport } from "@modelcontextprotocol/client";

const transport = new StreamableHTTPClientTransport(new URL("https://mcp.tronrental.com/mcp"), {
  requestInit: { headers: { Authorization: `Bearer ${process.env.TRONRENTAL_API_KEY}` } },
});
const client = new Client({ name: "my-app", version: "1.0.0" });
await client.connect(transport);

const { tools } = await client.listTools();
console.log(tools.map((t) => t.name));

const quote = await client.callTool({
  name: "quote_energy",
  arguments: { volume: 65000, duration: "1h" },
});
console.log(quote.structuredContent);
// { volume: 65000, duration: "1h", total_trx: "1.694350", ... }

await client.close();
```

```bash
TRONRENTAL_API_KEY=your_key node quote.mjs
```

`tools/list` возвращает только те инструменты, которые разрешены правами вашего ключа. `inputSchema` каждого инструмента описывает его аргументы.

## Покупка энергии

Сначала запросите цену, передайте `total_trx` из котировки как `max_price_trx` и держите один `idempotency_key` на покупку, чтобы повтор не мог списать дважды:

```ts
import { randomUUID } from "node:crypto";

const target = "TRecipientAddress...";
const quote = await client.callTool({
  name: "quote_energy",
  arguments: { volume: 65000, duration: "1h" },
});

const idempotencyKey = randomUUID(); // используйте его повторно, если повторяете эту покупку
const order = await client.callTool({
  name: "buy_energy",
  arguments: {
    target_address: target,
    volume: 65000,
    duration: "1h",
    max_price_trx: quote.structuredContent.total_trx,
    idempotency_key: idempotencyKey,
  },
});

if (order.isError) {
  console.error(order.structuredContent.error); // { code, message, status }
} else {
  console.log(order.structuredContent); // заказ: id, status, price_trx, ...
}
```

Отклонённый вызов не бросает исключение: у результата `isError: true`, а [код ошибки](/ru/agents/reference/spending-and-errors#коды-ошибок) — в `structuredContent.error`.

## Вход пользователей через OAuth

Для приложения, где каждый пользователь подключает свой аккаунт, передайте в транспорт `authProvider` вместо заголовка. Интерфейс `OAuthClientProvider` из SDK выполняет обнаружение, регистрацию клиента и PKCE на [OAuth-сервере](/ru/agents/reference/oauth) TronRental; вы храните токены и отправляете пользователя по URL авторизации. См. [руководство по OAuth](https://ts.sdk.modelcontextprotocol.io/v2/clients/oauth) в документации SDK.

Для десктопных и CLI-приложений используйте loopback redirect URI (`http://127.0.0.1:<port>/callback`); для собственного адреса возврата веб-приложения [напишите в поддержку](https://t.me/TronRentalcom_Help_bot).
