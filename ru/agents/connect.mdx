Каждый клиент ниже подключается к одному и тому же серверу и входит через TronRental — API-ключ копировать не нужно:

```
https://mcp.tronrental.com/mcp
```

При первом использовании клиент открывает tronrental.com. Войдите (или зарегистрируйтесь), выберите аккаунт, отметьте [права](/ru/agents/reference/permissions), задайте суточный лимит расходов и подтвердите. Клиент получит токен только для этого подключения.

  <Tab title="Claude">

    2. Нажмите **Connect** рядом с TronRental.
    3. Войдите на tronrental.com и подтвердите.
    4. В чате включите TronRental в меню инструментов и спросите, например: *«Какой у меня баланс в TronRental?»*

    На тарифах Team и Enterprise коннектор добавляет владелец в **Organization settings → Connectors**; участники затем нажимают **Connect**.
  </Tab>
  <Tab title="ChatGPT">
    1. Откройте [ChatGPT Plugins](https://chatgpt.com/plugins) и нажмите **+** → **Add custom MCP server**.
    2. Введите имя `TronRental`, выберите **Public endpoint** и вставьте адрес выше.
    3. Оставьте аутентификацию **OAuth**, подтвердите предупреждение и нажмите **Create as a plugin**.
    4. Войдите на tronrental.com и подтвердите.
    5. В чате выберите TronRental в меню инструментов.

    Если такого пункта нет, возможно, ваше рабочее пространство не разрешает собственные MCP-серверы — спросите его администратора. ChatGPT подключается только через OAuth; API-ключ он использовать не может.
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp
    ```

    Добавьте `--scope user`, чтобы TronRental был доступен во всех проектах, или `--scope project`, чтобы поделиться им с командой через `.mcp.json`.

## Проверьте, что всё работает

Спросите агента: *«Сколько стоит 65,000 энергии на 1 час в TronRental?»* Он вызовет `quote_energy` и покажет цену — ничего не списывается.

Перед любой покупкой агент запрашивает цену, показывает её вам и передаёт как `max_price_trx`; он также отправляет `idempotency_key`, поэтому повтор никогда не спишет дважды. Для покупок нужны пополнения аккаунта на 100 TRX в сумме — до этого подключение может только читать. См. [Расходы и ошибки](/ru/agents/reference/spending-and-errors).

## Управление и отключение

Список **Подключённые приложения** на [странице API](https://tronrental.com/dashboard/api) показывает каждый подключённый клиент: кто его подключил, его права, суточный лимит и сколько он потратил за последние 24 часа. Там же можно изменить лимит или нажать **Отключить**, чтобы сразу отозвать подключение.

## Вместо этого — API-ключ

Клиенты, в которых можно задать заголовки, могут подключаться с [API-ключом](/ru/authentication) без входа — например, для агента, который работает на вашем сервере:

```bash
claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp \
  --header "Authorization: Bearer $TRONRENTAL_API_KEY"
```

В Codex укажите переменную окружения с ключом в `~/.codex/config.toml`:

```toml
[mcp_servers.tronrental]
url = "https://mcp.tronrental.com/mcp"
bearer_token_env_var = "TRONRENTAL_API_KEY"
```

В Cursor добавьте `"headers": { "Authorization": "Bearer ${env:TRONRENTAL_API_KEY}" }` рядом с `url`.

У API-ключа нет суточного лимита: давайте ему только те права, которые нужны агенту. См. [Разработка с MCP](/ru/agents/build/overview).

## Агенты без браузера

Агенты, которые не могут открыть браузер, могут использовать локальный пакет [@tronrental-com/mcp-server](https://www.npmjs.com/package/@tronrental-com/mcp-server): он работает на вашей машине с API-ключом в `TRONRENTAL_API_KEY` или позволяет агенту зарегистрировать аккаунт на ваш email с кодом из письма. Настройка описана в его [README](https://github.com/tronrentalcom/tronrental-com-mcp).
