---

Подключение получает права, которые вы отметили на экране согласия. API-ключ получает права, которые вы задали при его создании в личном кабинете. MCP-сервер показывает только инструменты, которые открывают эти права (`tools/list`), и каждый вызов ещё раз проверяется на сервере.

| Право | Что открывает | Подключённое приложение (OAuth) | API-ключ |
|---|---|---|---|
| `view` | Баланс, история, отчёты, заказы, котировки, проверка адресов, квота и события бродкастера, позиции стейкинга, тариф и расход Node API | ✓ | ✓ |
| `deposit_view` | Адрес для депозита, депозиты, депозиты в других монетах | ✓ | ✓ |
| `buy_energy` | Покупка энергии, активация адреса, автопополнение энергии, инвойсы | ✓ | ✓ |
| `buy_bandwidth` | Покупка и возврат bandwidth, автопополнение bandwidth, авто-bandwidth | ✓ | ✓ |
| `smart_mode` | Smart Mode | ✓ | ✓ |
| `transfer_packages` | Пакеты переводов | ✓ | ✓ |
| `energy_resale` | Energy Resale | ✓ | ✓ |
| `broadcaster` | Создание, изменение и удаление broadcast URL | ✓ | ✓ |
| `staking` | Стейк, вывод из стейкинга, получение наград, автополучение наград | ✓ только владелец аккаунта | ✓ только владелец аккаунта |
| `node_api_plan` | Покупка тарифа Node API, пробный период, автопродление | ✓ только владелец аккаунта | ✓ только владелец аккаунта |
| `recurring` | Включать списания, которые идут сами, — см. ниже | ✓ по умолчанию выключено | не нужно |
| `withdraw` | Вывод средств | **никогда** | ✓ с 2FA и белым списком IP |

## Списания, которые идут сами (`recurring`)

Некоторые инструменты не тратят деньги в момент вызова, а включают списания, которые продолжаются потом: автопополнение, авто-bandwidth, Smart Mode, Energy Resale, broadcast URL, автопродление Node API. Подключённому приложению для их создания или изменения нужно `recurring` в дополнение к праву продукта. Для выключения и удаления оно не нужно никогда. Для паузы Smart Mode — нужно, потому что тот же инструмент и возобновляет его.

<Warning>
  Списания, которые идут сами, **не входят в суточный лимит** и **продолжаются после отключения приложения**. Выключайте их на странице продукта в личном кабинете.
</Warning>

## До первого пополнения

Пока пополнения аккаунта в сумме не достигли 100 TRX, экран согласия выдаёт только `view` и `deposit_view` и показывает, сколько ещё осталось пополнить. После пополнения подключите приложение заново и отметьте больше прав — обновится то же подключение.

## Командные аккаунты

На экране согласия вы выбираете, с каким аккаунтом будет работать приложение: со своим или с командным, где вы управляете API-ключами. Участник команды может выдать только права, которые есть у его роли, не может выдать `staking` или `node_api_plan` и не может снять суточный лимит (`OAUTH_UNCAPPED_OWNER_ONLY`).

## API-ключ или подключённое приложение

| | Подключённое приложение (OAuth) | API-ключ |
|---|---|---|
| Кому подходит | Людям, которые пользуются агентом или вашим приложением | Вашим собственным серверам и скриптам |
| Суточный лимит расходов | 100 TRX по умолчанию | нет |
| `max_price_trx` при покупках | обязателен | необязателен |
| Вывод средств | никогда | с `withdraw`, 2FA и белым списком IP |
| `source` заказа | `agent` | `api` |

API-ключи выдаются, когда пополнения аккаунта в сумме достигают 100 TRX — см. [Аутентификация](/ru/authentication).
