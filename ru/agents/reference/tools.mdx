Каждый инструмент — один маршрут [REST API](/ru/api-reference/energy/get-prices), который вызывается на сервере с учётными данными вызывающего. Правила те же, что и в REST: те же цены, проверки, идемпотентность и коды ошибок.

- **Аргументы** — параметры маршрута в плоском виде: параметры пути и запроса и поля JSON-тела. Их имена и типы — в `inputSchema` инструмента и в справочнике API для маршрута.
- **`idempotency_key`** — заголовок `Idempotency-Key` маршрута; есть у каждого инструмента, чей маршрут его принимает.
- **Результат** приходит как `structuredContent` (JSON-ответ маршрута; список оборачивается в `{"result": [...]}`) и как тот же JSON в текстовом блоке.
- **Ошибка** приходит с `isError: true` и `{"error": {"code", "message", "status"}}` — собственным [кодом ошибки](/ru/agents/reference/spending-and-errors#коды-ошибок) API.
- **Подсказки:** у каждого инструмента есть `title`, `readOnlyHint`, `destructiveHint` и `openWorldHint`. Всё, что тратит баланс или включает регулярные списания, помечено `destructiveHint: true`, поэтому клиенты спрашивают перед вызовом.

**Деньги:** `списывает` — списывает с баланса при вызове; `регулярно` — включает списания, которые идут сами, и требует [`recurring`](/ru/agents/reference/permissions#списания-которые-идут-сами-recurring) для подключённого приложения; `на баланс` — возвращает деньги на баланс.
