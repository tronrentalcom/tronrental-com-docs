## Как это работает

1. Добавьте сервер TronRental в агента — см. [MCP-сервер](/ru/resources/mcp-server).
2. Агент откроет страницу входа TronRental. Войдите (или зарегистрируйтесь) — откроется экран согласия: имя приложения, сайт, куда оно вернётся, и что оно просит.
3. Выберите аккаунт, права и суточный потолок и подтвердите.
4. Агент получит токен только для этого подключения. Пароля и API-ключа он не видит.

## Права

| Право | Что может агент |
|---|---|
| `view` | Баланс, история, заказы, проверка адресов |
| `deposit_view` | Адрес и история пополнений |
| `buy_energy` | Покупка энергии, активация адресов, инвойсы |
| `buy_bandwidth` | Покупка bandwidth |
| `smart_mode` | Smart Mode |
| `transfer_packages` | Пакеты переводов |
| `energy_resale` | Energy Resale |
| `recurring` | Включать списания, которые идут сами (автопополнение, авто-bandwidth, Smart Mode, Energy Resale, бродкастер). По умолчанию выключено |

Пока пополнения аккаунта в сумме не достигли 100 TRX, подключение получает только `view` и `deposit_view`; после пополнения подключитесь заново, чтобы разрешить покупки.

**Вывод средств подключённому приложению недоступен никогда.** Он остаётся у API-ключей с правом `withdraw`, 2FA и белым списком IP.

## Суточный потолок расходов

У каждого подключения есть потолок трат за 24 часа — 100 TRX, если на экране согласия не задано другое число. Владелец аккаунта может выбрать «без потолка». Списания, которые идут сами (`recurring`), в потолок не входят: они видны в кабинете и там же выключаются.

## Подключённые приложения

На странице API в кабинете — все подключённые приложения: кто подключил, права, запросы за 7 дней. «Отключить» отзывает подключение и все его токены сразу — следующий вызов агента получит отказ.

## Разработчикам MCP-клиентов

- Обнаружение: `https://mcp.tronrental.com/mcp` → `401` + `WWW-Authenticate` → `https://mcp.tronrental.com/.well-known/oauth-protected-resource/mcp` (RFC 9728); `https://mcp.tronrental.com/.well-known/oauth-authorization-server` (RFC 8414).
- OAuth 2.1 с PKCE (только `S256`), публичные клиенты (`token_endpoint_auth_method: none`). Регистрация клиента — Dynamic Client Registration (RFC 7591); Client ID Metadata Document принимается от поддерживаемых платформ.
- Redirect URI: loopback (`http://127.0.0.1:<любой порт>`, `http://localhost:<любой порт>`) и адреса возврата поддерживаемых платформ. Нужен другой — напишите в поддержку.
- Access-токен — 1 час, refresh — 30 суток с ротацией; повтор старого refresh отзывает подключение.
