## Список инвойсов

Возвращает пагинированный список ваших инвойсов.

### Параметры запроса

<ParamField query="page" type="number" default="1">
  Номер страницы
</ParamField>

<ParamField query="status" type="string">
  Фильтр по статусу: `pending`, `paid`, `delegated`, `expired`, `failed`
</ParamField>

<ParamField query="from" type="string">
  Первый день периода, `YYYY-MM-DD`, включительно. Без обеих дат — весь список.
</ParamField>

<ParamField query="to" type="string">
  Последний день периода, `YYYY-MM-DD`, **включительно** — учитываются все сутки, до 23:59:59.999 в вашей таймзоне.
</ParamField>

<ParamField query="tz" type="string">
  Таймзона IANA, в которой читаются обе даты, например `Europe/Berlin`. Без неё — UTC.
</ParamField>

<Info>
  В отличие от отчёта, у списка нет ограничения в один год — он постраничный. Обе даты необязательны: только `from` означает «с этого дня и дальше», только `to` — «по этот день включительно».
</Info>

### Ответ

Возвращает пагинированный объект с массивом `invoices` и общим количеством `total`.

### Пример

```bash
curl "https://api.tronrental.com/v1/invoices/my?page=1&status=delegated" \
  -H "X-API-Key: your_api_key"
```
