## Создать вывод

<div>
  `POST /api/v1/account/withdrawal`
</div>

Выводит TRX на любой адрес TRON. Комиссия: 1 TRX.

### Тело запроса

<ParamField body="to_address" type="string" required>
  Адрес TRON назначения
</ParamField>

<ParamField body="amount_trx" type="string" required>
  Сумма вывода в TRX
</ParamField>

<ParamField body="currency" type="string">
  `TRX` (по умолчанию) или `USDT`. Для `USDT` в `amount_trx` передаётся сумма в USDT.
</ParamField>

<ParamField body="totp_code" type="string">
  Код 2FA (если 2FA включена)
</ParamField>

### Заголовки

<ParamField header="Idempotency-Key" type="string">
  Необязательный, до 64 символов. Передавайте новый ключ (например, UUID) с каждым новым выводом и тот же ключ, когда повторяете запрос, ответ на который не получили, — повтор вернёт первый вывод, а не создаст второй.
</ParamField>

### Безопасный повтор

- Тот же ключ с теми же `to_address`, `amount_trx` и `currency` возвращает `200` с выводом, который создал первый запрос, в его текущем состоянии. Второго списания нет.
- Тот же ключ с другим телом запроса отклоняется с `422` и кодом `IDEMPOTENCY_KEY_REUSED`; ключ длиннее 64 символов — с `422` и `IDEMPOTENCY_KEY_TOO_LONG`. Ключи действуют в пределах вашего аккаунта и не истекают — не используйте один ключ для другого вывода.
- Незавершённый вывод (`pending`, `scheduled` или `processing`) может быть только один: новый запрос, пока он есть, получит `400` с `You already have a pending withdrawal`.
- После вывода, созданного с `Idempotency-Key`, следующий можно создать через 5 секунд; без заголовка пауза остаётся 60 секунд (`429`, см. [Лимиты запросов](/resources/rate-limits)).

### Пример

```bash
curl -X POST https://api.tronrental.com/v1/account/withdrawal \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 7f9c2b1e-5d4a-4c1e-9b3f-2a6d8e0c4f11" \
  -d '{
    "to_address": "TDestinationAddress...",
    "amount_trx": "100"
  }'
```

```json Response
{
  "id": 56,
  "to_address": "TDestinationAddress...",
  "amount_trx": "100.00",
  "fee_trx": "1.00",
  "status": "completed",
  "tx_hash": "a1b2c3d4e5f6...",
  "created_at": "2026-03-05T12:00:00Z"
}
```

## Список выводов

<div>
  `GET /api/v1/account/withdrawals`
</div>

Возвращает историю ваших выводов.

```bash
curl https://api.tronrental.com/v1/account/withdrawals \
  -H "X-API-Key: your_api_key"
```

```json Response
[
  {
    "id": 56,
    "to_address": "TDestinationAddress...",
    "amount_trx": "100.00",
    "fee_trx": "1.00",
    "status": "completed",
    "tx_hash": "a1b2c3d4e5f6...",
    "created_at": "2026-03-05T12:00:00Z"
  }
]
```

### Статусы выводов

| Статус | Описание |
|--------|----------|
| `pending` | В очереди на обработку |
| `completed` | TRX отправлены, tx_hash доступен |
| `failed` | Ошибка, сумма возвращена |
| `scheduled` | Создан в веб-кабинете; ждёт окно отмены 20 секунд перед отправкой |
| `processing` | Отправляется в сеть |
| `cancelled` | Отменён пользователем в окне отмены; сумма возвращена |

Выводы, созданные через API-ключ, отправляются сразу и не проходят через `scheduled`. У строк, созданных в веб-кабинете, есть поле `execute_after` — момент отправки, если вывод не отменили раньше.

### Блокировка вывода после смены email

В течение 24 часов после смены email аккаунта создание вывода отклоняется с кодом `403` и ошибкой `WITHDRAWAL_EMAIL_COOLDOWN`. В ответе приходит `retry_after_seconds` — сколько секунд осталось до разблокировки:

```json Response
{
  "detail": {
    "error": {
      "code": "WITHDRAWAL_EMAIL_COOLDOWN",
      "message": "Withdrawals are temporarily blocked after an email change",
      "retry_after_seconds": 79214
    }
  }
}
```

Блокировка действует для сессий любого типа, включая API-ключи с правом `withdraw`. Если вы не меняли email аккаунта — немедленно обратитесь в поддержку.
