## Список разрешений API-ключа

Возвращает каталог разрешений API-ключей, сгруппированный так же, как в кабинете. Используйте его,
чтобы узнать допустимые имена разрешений.

Ключи Node API — отдельный вид ключей: они несут только разрешение `node_api`, никогда вместе с другими
разрешениями, и работают только на `node.tronrental.com`. Их создают как эндпоинты в разделе
[Личный кабинет → Node API](https://tronrental.com/dashboard/node-api); сколько их может быть, зависит
от вашего тарифа Node API. Ключ Node API не может вызвать этот эндпоинт — REST API отвечает на него
`403 NODE_API_KEY_ONLY`. См. [Node API → Эндпоинты и ключи](/ru/node-api/authentication).

### Ответ

<ResponseField name="read" type="string[]">
  Разрешения на чтение: `view`, `deposit_view`
</ResponseField>

<ResponseField name="node" type="string[]">
  Разрешение Node API: `node_api`. Ключ с ним не несёт других разрешений
</ResponseField>

<ResponseField name="write" type="string[]">
  Разрешения, которые расходуют баланс или изменяют услуги: `buy_energy`, `buy_bandwidth`, `smart_mode`,
  `transfer_packages`, `energy_resale`
</ResponseField>

<ResponseField name="danger" type="string[]">
  `withdraw`. Чтобы включить его на ключе, нужны 2FA и непустой белый список IP
</ResponseField>

<ResponseField name="default" type="string[]">
  Разрешения, которые получает новый ключ REST API, если ни одно не выбрано: все разрешения на чтение и
  запись, кроме `withdraw`
</ResponseField>

<ResponseField name="locked" type="string[]">
  Разрешения, которые всегда есть у любого ключа REST API: `view`
</ResponseField>

### Пример

```bash
curl https://api.tronrental.com/v1/auth/api-keys/scopes \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "read": ["view", "deposit_view"],
  "node": ["node_api"],
  "write": ["buy_energy", "buy_bandwidth", "smart_mode", "transfer_packages", "energy_resale"],
  "danger": ["withdraw"],
  "default": ["view", "deposit_view", "buy_energy", "buy_bandwidth", "smart_mode", "transfer_packages", "energy_resale"],
  "locked": ["view"]
}
```
