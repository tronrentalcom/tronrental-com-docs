## Возобновить пакеты

Возобновляет **все приостановленные пакеты вашего аккаунта на адресе**. Переводы с адреса снова получают энергию и учитываются, а BW Guarantee возвращается для пакетов, у которых она есть.

### Что списывается при возобновлении

Пакет платит один перевод за каждые 24 часа, пока он активен. Уже оплаченные 24 часа продолжают идти и во время паузы — пауза этот отсчёт не останавливает.

| Когда вы возобновляете | Что списывается |
|-----------------|-----------------|
| Оплаченные 24 часа ещё не истекли | Ничего. Следующий суточный перевод спишется в момент, уже указанный в `next_subscription_at` |
| Оплаченные 24 часа истекли во время паузы | Один перевод, сразу. Следующие 24 часа отсчитываются с момента возобновления |
| В пакете остался один перевод | Ничего — последний перевод остаётся вашим |

### Тело запроса

<ParamField body="address" type="string" required>
  Адрес TRON, пакеты которого нужно возобновить
</ParamField>

### Ответ

<ResponseField name="address" type="string">
  Адрес из запроса.
</ResponseField>

<ResponseField name="paused" type="boolean">
  Всегда `false`.
</ResponseField>

<ResponseField name="packages" type="array">
  Ваши пакеты на адресе, которые снова активны, — те же объекты, что в [Списке пакетов](/ru/api-reference/transfer-packages/list). `paused_at` равен `null`.
</ResponseField>

Повторный вызов, когда ничего не приостановлено, ничего не меняет и ничего не списывает: вы получите свои активные пакеты на адресе.

<Note>
  Энергия может дойти до адреса через несколько секунд после ответа. Сделайте небольшую паузу перед первым переводом.
</Note>

### Пример

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/resume \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

В этом примере оплаченные 24 часа истекли во время паузы, поэтому при возобновлении списан один перевод: `subscription_used` вырос с `3` до `4`, `remaining` уменьшился с `310` до `309`.

### Ошибки

Приходят в [стандартной форме](/ru/errors), в `detail.error.code`. После любой из них пакеты остаются на паузе и ничего не списывается.

| Код | Статус | Когда |
|------|--------|------|
| `PACKAGE_NOT_FOUND` | `404` | У вашего аккаунта нет приостановленного или активного пакета на адресе |
| `PACKAGE_NOT_SETTLED` | `400` | Пакет на адресе ещё активируется — повторите позже |
| `SMART_MODE_ACTIVE` | `400` | На адресе активен Smart Mode — сначала отключите его |
| `ADDRESS_BUSY` | `409` | По адресу выполняется другая операция — повторите через минуту |
| `PROVIDER_UNAVAILABLE` | `503` | Не удалось запустить доставку энергии на адрес — повторите через минуту |
