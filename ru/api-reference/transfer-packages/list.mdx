## Мои пакеты

Возвращает все ваши пакеты переводов.

### Ответ

Массив объектов пакетов. Основные поля: `id`, `address`, `package_size`, `quota_total` (переводов в пакете), `quota_used` (переводов обслужено), `subscription_used` (переводов списано суточной платой, по одному в день), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `bw_fee_per_transfer` (сколько вернёт выключение Гарантии BW за каждый оставшийся перевод; `null`, если она выключена), `status`, `paused_at` (когда пакет приостановлен; `null`, если `status` не `paused`), `created_at`, `label` (ваше название адреса, см. [Подписать кошелёк](/ru/api-reference/transfer-packages/set-label); `null` — без подписи), `archived_at` (когда пакет убран в архив, см. [Архив кошелька](/ru/api-reference/transfer-packages/archive); `null` — в основном списке).

Пакеты из архива входят в ответ. Читать список постранично, как кабинет, — [Пакеты постранично](/ru/api-reference/transfer-packages/list-page).

### Статусы пакетов

| Статус | Описание |
|--------|----------|
| `pending_payment` | Ожидание оплаты инвойса |
| `provisioning` | Оплачен с баланса, идёт активация |
| `active` | Мониторинг адреса, переводы доступны |
| `paused` | [Приостановлен](/ru/api-reference/transfer-packages/pause) вами: суточная плата не списывается, переводы не обслуживаются и не учитываются, оставшиеся переводы сохраняются |
| `completed` | Все переводы использованы |
| `cancelled` | Отменён пользователем |
| `expired` | Инвойс не оплачен вовремя |
| `manual_review` | Исход активации неясен; его проверяет поддержка, до этого оплата удерживается |
| `failed_refunded` | Активация не удалась; цена возвращена на баланс |

```bash
  -H "X-API-Key: your_api_key"
```
