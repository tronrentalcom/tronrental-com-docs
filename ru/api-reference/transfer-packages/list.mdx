## Мои пакеты

Возвращает все ваши пакеты переводов.

### Ответ

Массив объектов пакетов. Основные поля: `id`, `address`, `package_size`, `quota_total` (переводов в пакете), `quota_used` (переводов обслужено), `subscription_used` (переводов списано суточной платой, по одному в день), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `status`, `created_at`.

### Статусы пакетов

| Статус | Описание |
|--------|----------|
| `pending_payment` | Ожидание оплаты инвойса |
| `provisioning` | Оплачен с баланса, идёт активация |
| `active` | Мониторинг адреса, переводы доступны |
| `completed` | Все переводы использованы |
| `cancelled` | Отменён пользователем |
| `expired` | Инвойс не оплачен вовремя |
| `manual_review` | Исход активации неясен; его проверяет поддержка, до этого оплата удерживается |
| `failed_refunded` | Активация не удалась; цена возвращена на баланс |

### Пример

```bash
curl https://api.tronrental.com/v1/transfer-packages/my \
  -H "X-API-Key: your_api_key"
```

  }
