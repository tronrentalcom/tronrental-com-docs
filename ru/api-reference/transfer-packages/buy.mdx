## Купить пакет переводов

Покупает пакет переводов с использованием баланса вашего аккаунта.

### Тело запроса

<ParamField body="address" type="string" required>
  Адрес TRON для мониторинга
</ParamField>

<ParamField body="package_size" type="number">
  Количество переводов в пакете (2 – 10 000). Обязателен, если `single_transfer` не `true`. `package_size: 1` отклоняется с `422` — один перевод покупается с `single_transfer: true`.
</ParamField>

<ParamField body="single_transfer" type="boolean" default="false">
  Купить один перевод вместо пакета; `package_size` тогда не учитывается. Цена — `single_transfer_price` из [Получить тарифы](/api-reference/transfer-packages/get-tiers) (с BW Guarantee — плюс `bw_fee_per_transfer`).
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  Включить BW Guarantee
</ParamField>

### Ответ

Возвращает `package_id`, `status`, `total_price_trx`, `activation_cost_trx` (TRX за активацию адреса, если он ещё не был активирован, иначе `0`) и `total_charged_trx`.

### Пример

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "package_size": 500,
    "bw_guarantee": true
  }'
```

```json Response
{
  "package_id": 101,
  "status": "active",
  "total_price_trx": "1500.0",
  "activation_cost_trx": "0",
  "total_charged_trx": "1500.0"
}
```

<Info>
  Вы также можете оплатить через инвойс с помощью `POST /api/v1/transfer-packages/buy-invoice` —
  это сгенерирует адрес для оплаты в TRX/USDT.
</Info>
