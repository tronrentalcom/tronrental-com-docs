## Пакеты постранично

Возвращает одну страницу ваших пакетов переводов: основной список или архив при `archived=true`. Сначала идут незакрытые пакеты — активные, на паузе, ожидающие оплаты или активации, — затем новые. Это тот список, что показывает кабинет; [Список пакетов](/ru/api-reference/transfer-packages/list) по-прежнему отдаёт все пакеты сразу.

### Параметры запроса

<ParamField query="archived" type="boolean" default="false">
  `true` — архив (пакеты, убранные туда через [Архив кошелька](/ru/api-reference/transfer-packages/archive)); `false` (по умолчанию) — основной список
</ParamField>

<ParamField query="page" type="number">
  Номер страницы (по умолчанию 1)
</ParamField>

<ParamField query="page_size" type="number">
  Пакетов на странице (по умолчанию 20, максимум 100)
</ParamField>

### Ответ

<ResponseField name="packages" type="array">
  Пакеты страницы — те же объекты, что в [Списке пакетов](/ru/api-reference/transfer-packages/list), с `label` и `archived_at`.
</ResponseField>

<ResponseField name="total" type="number">
  Пакетов в запрошенном списке, на всех страницах.
</ResponseField>

<ResponseField name="page" type="number">
  Страница из запроса.
</ResponseField>

<ResponseField name="page_size" type="number">
  Размер страницы из запроса.
</ResponseField>

<ResponseField name="archived_packages" type="number">
  Сколько пакетов у аккаунта в архиве — какой бы список ни был запрошен.
</ResponseField>

<ResponseField name="archived_wallets" type="number">
  На скольких адресах лежат эти пакеты из архива.
</ResponseField>

### Пример

```bash
curl "https://api.tronrental.com/v1/transfer-packages/list?page=1&page_size=20" \
  -H "X-API-Key: your_api_key"
```

### Ошибки

Приходят в [стандартной форме](/ru/errors), в `detail.error.code`. После любой из них ничего не изменилось.

| Код | Статус | Когда |
|------|--------|------|
| — | `422` | `page` < 1, `page_size` ∉ 1–100 |
