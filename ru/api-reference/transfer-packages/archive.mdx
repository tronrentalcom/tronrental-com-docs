## Архив кошелька

Убирает **закрытые** пакеты вашего аккаунта на адресе в архив: кабинет показывает их в блоке *Архив*, а не в основном списке. Закрытые — `completed`, `expired`, `cancelled` и `failed_refunded`; пакет активный, на паузе, ожидающий оплаты или активации остаётся в основном списке.

Больше ничего не меняется: пакеты, их история и списания остаются как есть, и [Список пакетов](/ru/api-reference/transfer-packages/list) по-прежнему их отдаёт, с заполненным `archived_at`. Пакет, купленный на адрес позже, — в основном списке. Вернуть кошелёк — [Вернуть из архива](/ru/api-reference/transfer-packages/restore).

### Тело запроса

<ParamField body="address" type="string" required>
  Адрес TRON, закрытые пакеты которого убрать в архив
</ParamField>

### Ответ

<ResponseField name="address" type="string">
  Адрес из запроса.
</ResponseField>

<ResponseField name="archived" type="boolean">
  Всегда `true`.
</ResponseField>

<ResponseField name="packages" type="number">
  Сколько пакетов ушло в архив сейчас; `0` — убирать нечего (закрытых нет или все уже в архиве).
</ResponseField>

### Пример

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/archive \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

```json Response
{
  "address": "TYourAddress...",
  "archived": true,
  "packages": 3
}
```

### Ошибки

Приходят в [стандартной форме](/ru/errors), в `detail.error.code`. После любой из них ничего не изменилось.

| Код | Статус | Когда |
|------|--------|------|
| `PACKAGE_NOT_FOUND` | `404` | У вашего аккаунта нет пакета на адресе |
