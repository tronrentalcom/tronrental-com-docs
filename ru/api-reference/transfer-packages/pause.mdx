## Приостановить пакеты

Приостанавливает сразу **все активные пакеты вашего аккаунта на адресе**. Приостановить один пакет отдельно нельзя.

Пока пакеты приостановлены:

- суточный перевод не списывается;
- переводы с адреса не получают энергию и не учитываются;
- BW Guarantee с адреса снимается;
- оставшиеся переводы сохраняются, без ограничения по времени.

Пакеты остаются на паузе, пока вы не вызовете [Возобновить пакеты](/ru/api-reference/transfer-packages/resume), — сами они не возобновляются.

<Warning>
  **Вызов отвечает примерно за 15 секунд** — задайте таймаут клиента 30 секунд или больше. Пауза действует с момента, когда вы получили ответ. Перевод, отправленный до ответа, всё ещё учитывается, поэтому считайте адрес приостановленным только после ответа.
</Warning>

### Тело запроса

<ParamField body="address" type="string" required>
  Адрес TRON, пакеты которого нужно приостановить
</ParamField>

### Ответ

<ResponseField name="address" type="string">
  Адрес из запроса.
</ResponseField>

<ResponseField name="paused" type="boolean">
  Всегда `true`.
</ResponseField>

<ResponseField name="packages" type="array">
  Ваши приостановленные пакеты на адресе — те же объекты, что в [Списке пакетов](/ru/api-reference/transfer-packages/list), теперь со `status: "paused"` и `paused_at`.
</ResponseField>

Повторный вызов для адреса, который уже на паузе, ничего не меняет и ничего не списывает: вы получите те же приостановленные пакеты.

### Пример

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/pause \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

### Ошибки

Приходят в [стандартной форме](/ru/errors), в `detail.error.code`. После любой из них ничего не изменилось: пакеты работают как раньше.

| Код | Статус | Когда |
|------|--------|------|
| `PACKAGE_NOT_FOUND` | `404` | У вашего аккаунта нет активного пакета на адресе |
| `PACKAGE_NOT_SETTLED` | `400` | Пакет на адресе ещё активируется — повторите позже |
| `ADDRESS_SHARED` | `400` | На адресе есть активный пакет другого аккаунта |
| `SMART_MODE_ACTIVE` | `400` | На адресе активен Smart Mode — сначала отключите его |
| `ADDRESS_BUSY` | `409` | По адресу выполняется другая операция — повторите через минуту |
| `PAUSE_BUSY` | `429` | Одновременно выполняется слишком много приостановок — повторите через минуту |
| `PROVIDER_UNAVAILABLE` | `503` | Не удалось остановить доставку энергии на адрес — повторите через минуту |

<Note>
  Пока ваши пакеты на адресе приостановлены, купить новый пакет для этого адреса нельзя: покупка отклоняется с `ADDRESS_PAUSED`. Сначала возобновите пакеты.
</Note>
