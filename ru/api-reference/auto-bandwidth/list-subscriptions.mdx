## Список подписок

Возвращает все подписки Авто-bandwidth в вашем аккаунте, а также ваш баланс и признак того, можно ли прямо сейчас создавать новые подписки. Удалённые подписки не включаются. Нужен скоуп `view`.

### Ответ

<ResponseField name="subscriptions" type="array">
  Ваши подписки.

  <Expandable title="объект подписки">
    <ResponseField name="id" type="number">
      ID подписки — используется в путях изменения и удаления
    </ResponseField>
    <ResponseField name="address" type="string">
      Адрес, на котором подписка держит bandwidth
    </ResponseField>
    <ResponseField name="label" type="string | null">
      Ваше название подписки
    </ResponseField>
    <ResponseField name="token" type="string">
      `USDT`, `TRX`, `USDD`, `CUSTOM` или `OWN` — см. [Токен](/ru/api-reference/auto-bandwidth/overview#параметры)
    </ResponseField>
    <ResponseField name="contract" type="object | null">
      Контракт токена подписки `CUSTOM` или `OWN`: `address`, `symbol` и `name` (`symbol` и `name` — как их сообщила сеть, `null`, если неизвестны). `null`, если контракта нет.
    </ResponseField>
    <ResponseField name="volume" type="number">
      Bandwidth, который держится на адресе
    </ResponseField>
    <ResponseField name="auto_pause" type="boolean">
      Включена ли авто-пауза
    </ResponseField>
    <ResponseField name="threshold" type="number">
      Уровень бесплатного bandwidth для авто-паузы и для уведомления о бесплатном bandwidth
    </ResponseField>
    <ResponseField name="stop_after_transfer" type="boolean">
      Ставит ли следующий перевод токена подписки её на паузу
    </ResponseField>
    <ResponseField name="notify_free_bw" type="boolean">
      Уведомляем ли мы вас, когда бесплатный bandwidth адреса восстанавливается до `threshold`
    </ResponseField>
    <ResponseField name="status" type="string">
      `active`, `free_bw`, `paused` или `stopped_balance` — см. [Статус](/ru/api-reference/auto-bandwidth/overview#статус)
    </ResponseField>
    <ResponseField name="stopped_reason" type="string | null">
      `insufficient_balance`, `transfer` или `admin`; `null`, если причины нет
    </ResponseField>
    <ResponseField name="address_change_to" type="string | null">
      Новый адрес, пока идёт перенос; иначе `null`
    </ResponseField>
    <ResponseField name="free_bw" type="number | null">
      Бесплатный bandwidth на адресе при последней проверке. `null` до первой проверки.
    </ResponseField>
    <ResponseField name="delegated_bw" type="number">
      Bandwidth, который мы сейчас делегировали на адрес; `0`, если делегации нет
    </ResponseField>
    <ResponseField name="transfers" type="number">
      Покрытых переводов на данный момент — делегаций, которые были израсходованы и обновлены
    </ResponseField>
    <ResponseField name="delivery_state" type="string">
      `ok`, `waiting_stake` или `failed` — см. [Статус](/ru/api-reference/auto-bandwidth/overview#статус)
    </ResponseField>
    <ResponseField name="paid_until" type="string | null">
      Конец оплаченных 24 часов (ISO 8601, UTC). `null`, если ни одни сутки ещё не оплачены.
    </ResponseField>
    <ResponseField name="total_charged_trx" type="string">
      Всего списано TRX по этой подписке
    </ResponseField>
    <ResponseField name="daily_trx" type="string | null">
      Текущая комиссия за 24 часа. `null`, если цена временно недоступна.
    </ResponseField>
    <ResponseField name="transfer_trx" type="string | null">
      Текущая комиссия за перевод: `transfer_bw_trx` + `transfer_fee_trx`. `null`, если цена временно недоступна.
    </ResponseField>
    <ResponseField name="transfer_bw_trx" type="string | null">
      Часть комиссии за перевод, приходящаяся на bandwidth
    </ResponseField>
    <ResponseField name="transfer_fee_trx" type="string | null">
      Часть комиссии за перевод, приходящаяся на фиксированную комиссию
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Когда подписка создана (ISO 8601, UTC)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="balance_trx" type="string">
  Баланс вашего аккаунта
</ResponseField>

<ResponseField name="enabled" type="boolean">
  `false`, пока Авто-bandwidth временно выключен: создание подписки или её включение тогда возвращает `503 AUTO_BW_DISABLED`
</ResponseField>

Цены в подписке относятся к этой подписке: они рассчитаны по API-ключу, с которым она создана, либо как покупка на сайте.

```python Python
)

```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto", {
```
