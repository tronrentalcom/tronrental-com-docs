## Удалить подписку

Удаляет подписку. Мы перестаём следить за адресом и забираем делегированный на него bandwidth в течение нескольких секунд; адрес освобождается для новой подписки. Перевод, использовавший наш bandwidth до удаления, всё равно оплачивается. Нужен скоуп `buy_bandwidth`.

Чтобы ненадолго остановиться, не теряя настроек, вместо этого [поставьте подписку на паузу](/ru/api-reference/auto-bandwidth/update-subscription) с `enabled: false`.

### Параметры пути

<ParamField path="sub_id" type="number" required>
  ID подписки — `id` из создания подписки или списка подписок
</ParamField>

### Ответ

<ResponseField name="id" type="number">
  ID удалённой подписки
</ResponseField>

<ResponseField name="status" type="string">
  `deleted`
</ResponseField>

### Пример

<CodeGroup>
```bash cURL
curl -X DELETE https://api.tronrental.com/v1/bandwidth/auto/42 \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.delete(
    "https://api.tronrental.com/v1/bandwidth/auto/42",
    headers={"X-API-Key": "your_api_key"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto/42", {
  method: "DELETE",
  headers: { "X-API-Key": "your_api_key" },
});
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "id": 42,
  "status": "deleted"
}
```

### Ошибки

| Статус | Код | Когда |
|--------|------|------|
| `403` | `FORBIDDEN` | У API-ключа нет скоупа `buy_bandwidth` |
| `404` | `NOT_FOUND` | В вашем аккаунте нет подписки с таким ID (или она уже удалена) |

```json
{
  "detail": {
    "error": {
      "code": "NOT_FOUND",
      "message": "Auto-Bandwidth subscription not found"
    }
  }
}
```
