## Досрочный отзыв заказа

Сразу отзывает делегированный bandwidth вашего заказа — например, когда адрес уже сделал перевод, ради которого брали ресурс, — не дожидаясь конца срока. **Неиспользованное время не возвращается.** Досрочно отозвать можно только заказы bandwidth.

### Параметры пути

<ParamField path="order_id" type="number" required>
  ID заказа — значение `id`, которое возвращает Buy Bandwidth.
</ParamField>

### Ответ

Возвращает объект заказа, как Get Order. Поле `status` показывает, что произошло:

| Статус | Значение |
|--------|-------------|
| `reclaimed` | Bandwidth отозван в этом же запросе; `undelegate_txid` — транзакция в сети |
| `filled` | Заказ поставлен в следующий цикл отзыва, обычно до 30 секунд. Итог придёт вебхуком `order.updated`, либо опрашивайте Get Order |
| `reclaiming` | Отзыв этого заказа уже идёт |
| `reclaim_failed` | Отозвать на нашей стороне не удалось после повторов. Вам ничего делать не нужно |

Повторный вызов для заказа в статусе `reclaiming`, `reclaimed` или `reclaim_failed` возвращает заказ без изменений, поэтому повторять запрос безопасно. Ключу API нужно право `buy_bandwidth`.

### Ошибки

| Код | Статус | Когда |
|------|--------|------|
| `ORDER_NOT_FOUND` | `404` | У аккаунта нет такого заказа |
| `ORDER_NOT_RECLAIMABLE` | `409` | Заказ ещё не доставлен (`filled`) или завершился ошибкой |
| `BAD_REQUEST` | `400` | Это не заказ bandwidth |
| `FORBIDDEN` | `403` | У ключа API нет права `buy_bandwidth` |

### Пример

```bash
curl -X POST https://api.tronrental.com/v1/orders/12345/reclaim \
  -H "X-API-Key: your_api_key"
```
