## Рассчитать цену пополнения энергии

Возвращает, сколько стоит вашему аккаунту одно пополнение на `add_volume` энергии: цену, которую правило с таким объёмом платит за каждое пополнение, включая фиксированную комиссию. Ничего не создаётся и не списывается. Нужен скоуп `view`.

Цена зависит от того, как вы вызываете эндпоинт. С API-ключом это цена правила, созданного с этим API-ключом; с сайта — цена правила, созданного на сайте. Это цена на момент запроса, и в неё не входит активация адреса, которого ещё нет в сети, — её добавит первое пополнение.

### Параметры запроса

<ParamField query="add_volume" type="number" required>
  Энергия за одно пополнение. От 1 до 5 000 000 — тот же диапазон, что при создании правила.
</ParamField>

Пополнения энергии всегда длятся один час, поэтому параметра `duration` нет; в ответе всегда `"duration": "1h"`.

### Ответ

<ResponseField name="add_volume" type="number">
  Объём, о котором вы спросили
</ResponseField>

<ResponseField name="duration" type="string">
  Срок аренды для пополнения — для энергии всегда `1h`
</ResponseField>

<ResponseField name="estimated_cost_per_refill_trx" type="string">
  Полная цена одного пополнения для вашего аккаунта, включая фиксированную комиссию
</ResponseField>

### Пример

<CodeGroup>
```bash cURL
curl "https://api.tronrental.com/v1/energy/auto-refill/quote?add_volume=131000" \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.get(
    "https://api.tronrental.com/v1/energy/auto-refill/quote",
    headers={"X-API-Key": "your_api_key"},
    params={"add_volume": 131000},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch(
  "https://api.tronrental.com/v1/energy/auto-refill/quote?add_volume=131000",
  { headers: { "X-API-Key": "your_api_key" } },
);
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "add_volume": 131000,
  "duration": "1h",
  "estimated_cost_per_refill_trx": "2.618000"
}
```

### Ошибки

| Статус | Код | Когда |
|--------|------|------|
| `403` | `FORBIDDEN` | У API-ключа нет скоупа `view` |
| `422` | — | `add_volume` отсутствует или вне диапазона 1 – 5 000 000 |
| `503` | `TEMPORARILY_UNAVAILABLE` | Цену сейчас не удалось получить — повторите запрос, подождав столько секунд, сколько указано в `Retry-After` |

```json
{
  "detail": {
    "error": {
      "code": "TEMPORARILY_UNAVAILABLE",
      "message": "Please retry shortly"
    }
  }
}
```

Ошибка валидации приходит в формате фреймворка, где `detail` — массив:

```json
{
  "detail": [
    {
      "type": "greater_than_equal",
      "loc": ["query", "add_volume"],
      "msg": "Input should be greater than or equal to 1",
      "input": "1000",
      "ctx": {"ge": 1}
    }
  ]
}
```
