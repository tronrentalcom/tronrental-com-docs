## Удалить правило для bandwidth

Удаляет правило. Пополнений по нему больше не будет, а адрес освобождается для нового правила для bandwidth. Уже купленный bandwidth не забирается: эти аренды действуют до конца своего срока. Прошлые заказы пополнения остаются в истории заказов. Нужен скоуп `buy_bandwidth`.

Чтобы на время остановить пополнения, не теряя правило, лучше [поставьте его на паузу](/ru/api-reference/auto-refill/update-bandwidth-rule).

### Параметры пути

<ParamField path="rule_id" type="number" required>
  ID правила — `id` из ответа создания или списка правил для bandwidth
</ParamField>

### Ответ

<ResponseField name="status" type="string">
  `ok`
</ResponseField>

<CodeGroup>

### Ошибки

| Статус | Код | Когда |
|--------|------|------|
| `403` | `FORBIDDEN` | У API-ключа нет скоупа `buy_bandwidth` |
| `404` | `NOT_FOUND` | В вашем аккаунте нет правила для bandwidth с таким ID (или оно уже удалено) |
| `409` | `AUTOREFILL_IN_PROGRESS` | Прямо сейчас по этому правилу покупается пополнение — повторите через минуту |

```json
{
  "detail": {
    "error": {
      "code": "NOT_FOUND",
      "message": "Auto-refill rule not found"
    }
  }
}
```
