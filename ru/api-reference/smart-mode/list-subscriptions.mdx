## Список подписок

Возвращает все активные и приостановленные подписки Smart Mode. Деактивированные подписки не включаются.

### Ответ

Массив объектов подписок:

<ResponseField name="id" type="number">
  ID подписки
</ResponseField>

<ResponseField name="address" type="string">
  Отслеживаемый адрес TRON
</ResponseField>

<ResponseField name="label" type="string">
  Необязательная метка
</ResponseField>

<ResponseField name="status" type="string">
  `active` — деактивированные подписки в список не попадают
</ResponseField>

<ResponseField name="paused" type="boolean">
  `true`, пока подписка приостановлена через [Переключение подписки](/ru/api-reference/smart-mode/toggle): плата не взимается, переводы не отслеживаются
</ResponseField>

<ResponseField name="stop_after_transfer" type="boolean">
  Выключится ли подписка после следующего перевода USDT (см. `stop_after_transfer` в разделе [Активация](/ru/api-reference/smart-mode/activate))
</ResponseField>

<ResponseField name="paused_reason" type="string">
  Почему подписка на паузе: `transfer` — её выключил перевод USDT; `null` — пауза через [Переключение подписки](/ru/api-reference/smart-mode/toggle) или паузы нет
</ResponseField>

<ResponseField name="bw_guarantee" type="boolean">
  Включена ли BW Guarantee
</ResponseField>

<ResponseField name="created_at" type="string">
  Временная метка в формате ISO 8601
</ResponseField>

### Пример

```bash
curl https://api.tronrental.com/v1/smart-mode/subscriptions \
  -H "X-API-Key: your_api_key"
```
