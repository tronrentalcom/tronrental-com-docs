## Переключение подписки

Приостанавливает активную подписку или возобновляет приостановленную. Пока подписка приостановлена, плата не взимается и переводы не отслеживаются.

### Параметры пути

<ParamField path="sub_id" type="number" required>
  ID подписки
</ParamField>

### Ответ

Возвращает `paused` — состояние подписки после переключения: `true` — приостановлена, `false` — снова активна. То же поле есть у каждой подписки в [Список подписок](/ru/api-reference/smart-mode/list-subscriptions).

### Пример

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "paused": true
}
```
