## Список изменений

### Октябрь 2026

- **Energy Broadcaster** — свопы на SunSwap и вызовы любых смарт-контрактов получают энергию и bandwidth в пределах лимитов аккаунта; защита от реверта по желанию не отправляет вызов, который откатится. Подробнее — [Energy Broadcaster](/ru/resources/energy-broadcaster)
- **Bandwidth** — аренда bandwidth на любой срок от 5 до 59 минут со скидкой от часовой ставки; [Рассчитать цену bandwidth](/ru/api-reference/bandwidth/quote) возвращает точную сумму, а `max_price_trx` отклоняет покупку, если цена изменилась после котировки
- **API-ключи** — включение разрешения `withdraw`, смена белого списка IP у ключа с выводом и его перевыпуск теперь подтверждаются кодом 2FA или passkey
- **Node API** — доступ к полным нодам TRON по подписке через HTTP и gRPC на `node.tronrental.com`
- **Автопополнение** — энергия и bandwidth на адресе пополняются автоматически, как только опускаются ниже заданного вами порога

### Март 2026

- **Пакеты переводов** — предоплаченные пакеты переводов USDT
- **BW Guarantee** — опциональное делегирование bandwidth для Smart Mode и пакетов переводов
- **Вебхуки** — уведомления в реальном времени о событиях аккаунта
- **API вывода средств** — вывод TRX на любой адрес TRON

### Февраль 2026

- **Smart Mode** — автоматическая энергия для переводов USDT
- **API инвойсов** — создание платёжных инвойсов на энергию
- **API-ключи** — поддержка белого списка IP
- **API bandwidth** — покупка bandwidth для адресов TRON

### Январь 2026 — Первый релиз

- API покупки энергии
- Управление аккаунтом (баланс, депозиты, профиль)
- Цены в реальном времени
