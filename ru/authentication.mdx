## Аутентификация по API-ключу

Все API-запросы требуют передачи API-ключа в заголовке `X-API-Key`.

```bash
curl https://api.tronrental.com/v1/account/balance \
  -H "X-API-Key: your_api_key"
```

### Получение API-ключа

1. Зарегистрируйтесь на [tronrental.com](https://tronrental.com/auth/register)
2. Перейдите в [Личный кабинет → API-ключи](https://tronrental.com/dashboard/api)
3. Нажмите **Создать API-ключ**
4. Скопируйте и надёжно сохраните ключ — он показывается только один раз

### Белый список IP (опционально)

Вы можете ограничить API-ключ определёнными IP-адресами для дополнительной безопасности. Настройте это в личном кабинете при создании или редактировании ключа.

### Разрешения ключа

Каждый API-ключ несёт **разрешения** (scopes) — операции, которые ему доступны. Их выбирают в
личном кабинете при создании или редактировании ключа. Новый ключ получает все разрешения на чтение и
запись (покупка энергии и bandwidth, Smart Mode, просмотр баланса и истории и другие), кроме `withdraw`:
его включают отдельно, и для этого нужны 2FA и белый список IP; включение, смена белого списка IP у такого ключа и его перевыпуск подтверждаются кодом 2FA или passkey. Запрос вне разрешений ключа получает
HTTP `403`. Полный список: [Список разрешений API-ключа](/ru/api-reference/account/api-key-scopes).

<Warning>
  Храните API-ключ в секрете. Не размещайте его в клиентском коде, публичных репозиториях или URL-адресах.
</Warning>

## Ключи Node API

[Node API](/ru/node-api/overview) — доступ к полным нодам TRON на `node.tronrental.com` — использует
собственные ключи. Их создают как эндпоинты в разделе
[Личный кабинет → Node API](https://tronrental.com/dashboard/node-api). Ключ Node API работает только
на ноде: этот API отвечает на него `403 NODE_API_KEY_ONLY`. API-ключи, описанные на этой странице, на
ноде тоже не работают. См. [Node API → Эндпоинты и ключи](/ru/node-api/authentication).

## Использование ключа и журнал запросов

Каждый запрос, аутентифицированный API-ключом, сохраняется на 7 дней: метод, путь, код ответа, задержка и IP клиента. Параметры запроса (query string) в этом журнале не показываются. Откройте [Dashboard → API Keys](https://tronrental.com/dashboard/api) и разверните ключ, чтобы увидеть его последние запросы; колонка **Last Used** показывает самый свежий вызов (отметка при аутентификации обновляется не чаще раза в 5 минут, журнал точен). Журнал доступен только из кабинета — API-ключ не может прочитать собственный журнал.

## Лимиты запросов

Лимиты запросов считаются по аккаунту, а не по ключу: все ключи одного аккаунта делят общий бюджет. Подробности см. в разделе [Лимиты запросов](/ru/resources/rate-limits).

## Ошибки

Ошибки аутентификации возвращают HTTP `401`:

```json
{
  "detail": "Invalid or missing API key"
}
```

Если ваш ключ отключён или заблокирован, вы получите HTTP `403`.
