## Что такое Node API

Node API даёт вашему бэкенду доступ к нашим полным нодам TRON. Это API самой ноды java-tron: те же
HTTP-методы под `/wallet/*` и `/walletsolidity/*` и те же сервисы gRPC — за ключом, с квотой и
лимитами в секунду, которые задаёт ваш тариф.

Транзакции стройте и отправляйте через ноду, а подписывайте у себя. Приватный ключ не покидает ваш
сервер.

## Адреса

| Протокол | Адрес |
|---|---|
| HTTP, полная нода | `https://node.tronrental.com/wallet/<method>` |
| HTTP, подтверждённые данные | `https://node.tronrental.com/walletsolidity/<method>` |
| gRPC | `node.tronrental.com:443`, TLS — сервисы `protocol.Wallet` и `protocol.WalletSolidity` |

`/walletsolidity/*` отвечает только по солидифицированным (подтверждённым) блокам, как и java-tron.
Доступен каждый метод, который нода обслуживает на этих двух путях. HTTP принимает `GET` и `POST`: при
`GET` нода читает строку запроса, при `POST` — JSON-тело, но никогда не то и другое сразу. Имена
методов чувствительны к регистру, как в java-tron: `/wallet/getaccount`, но `/wallet/getReward`.

Ответы размером от 1 KB сжимаются gzip, если в запросе есть `Accept-Encoding: gzip`. Большинство
HTTP-библиотек отправляют его по умолчанию; в curl добавьте `--compressed`.

## Как получить ключ

<Steps>
  <Step title="Войдите">
    Зарегистрируйтесь или войдите на [tronrental.com](https://tronrental.com/auth/register).
  </Step>
  <Step title="Выберите тариф">
    Откройте [Личный кабинет → Node API](https://tronrental.com/dashboard/node-api). Запустите
    бесплатный 7-дневный триал (он открывается после депозитов на $5) или купите тариф — оплата с
    баланса аккаунта. См. [Тарифы и оплата](/ru/node-api/plans).
  </Step>
  <Step title="Создайте эндпоинт">
    Добавьте эндпоинт: название и, по желанию, белый список IP. Каждый эндпоинт — отдельный ключ. Ключ
    показывается один раз — скопируйте его и сохраните в надёжном месте. См.
    [Эндпоинты и ключи](/ru/node-api/authentication).
  </Step>
  <Step title="Сделайте первый запрос">
    Передайте ключ в заголовке `TRON-PRO-API-KEY`.
  </Step>
</Steps>

```bash
curl -i -X POST https://node.tronrental.com/wallet/getaccount \
  -H 'TRON-PRO-API-KEY: <YOUR_KEY>' \
  -d '{"address": "TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t", "visible": true}'
```

В ответе — собственный JSON ноды. Заголовок ответа `X-Node-API-WU` показывает, сколько единиц квоты
стоил вызов, — в этом случае `1`. См. [Единицы квоты](/ru/node-api/quota-units).

## Что входит

- Все методы ноды под `/wallet/*` и `/walletsolidity/*`, а также унарные методы сервисов gRPC
  `protocol.Wallet` и `protocol.WalletSolidity`.
- Ключ в заголовке, в пути URL или в метаданных gRPC.
- До 10 эндпоинтов в зависимости от тарифа, у каждого свой ключ, белый список IP и счётчик.
- Свежие блоки по фиксированной цене: блок в пределах 20 от головы стоит 3 WU, а его квитанции — 2 WU,
  независимо от размера.
- Мягкий предел на тарифах Start, Growth и Pro: когда квота израсходована, запросы продолжают
  работать, а расход сверх неё оплачивается как перерасход.
- CORS, чтобы браузерные приложения могли обращаться к ноде напрямую.

## Что не входит

Это не часть API ноды, поэтому в Node API этого нет:

- **История адреса и индексированные данные** — переводы адреса, переводы TRC-20 по адресу,
  запросы событий контрактов (пути вроде `/v1/...` и `/event/...`). Запросы к ним получают
  `404 not_found`. Чтобы следить за переводами, читайте блоки и их квитанции — см.
  пример «Слежение за USDT» в разделе [Примеры кода](/ru/node-api/examples).
- **JSON-RPC** (`/jsonrpc`, методы `eth_*`) не подключён.
- **Методы, принимающие приватный ключ**, например `gettransactionsign` или `easytransferbyprivate`.
  Нода их не обслуживает: они получают `404 method_not_found` и ничего не стоят. Подписывайте у себя.
- **Другие сервисы gRPC** и gRPC server reflection. См. [gRPC](/ru/node-api/grpc).

<Tip>
Чтобы оценить, сколько энергии израсходует вызов контракта, вызовите `triggerconstantcontract` с теми
же параметрами и возьмите `energy_used` из ответа.
</Tip>

## Заголовки ответа

| Заголовок | Значение |
|---|---|
| `X-Node-API-WU` | Сколько единиц квоты стоил этот вызов. `0`, если у ноды нет такого метода |
| `X-Node-API-Mode` | `degraded`, пока сервис работает на резервной ноде, — см. [Лимиты и ошибки](/ru/node-api/errors) |
| `Retry-After` | При `429` и `503`: сколько секунд подождать перед повтором |

По gRPC те же значения приходят в завершающих метаданных: `x-node-api-wu`, `x-node-api-mode`,
`retry-after`, а при отказе — `x-node-api-reason`.
