## Autenticação por Chave de API

Todas as requisições da API exigem uma chave de API enviada no cabeçalho `X-API-Key`.

```bash
curl https://api.tronrental.com/v1/account/balance \
  -H "X-API-Key: your_api_key"
```

### Obtendo uma chave de API

1. Cadastre-se em [tronrental.com](https://tronrental.com/auth/register)
2. Acesse [Painel → Chaves de API](https://tronrental.com/dashboard/api)
3. Clique em **Criar Chave de API**
4. Copie e armazene sua chave com segurança — ela é exibida apenas uma vez

### Lista de IPs permitidos (opcional)

Você pode restringir sua chave de API a endereços IP específicos para segurança adicional. Configure isso no painel ao criar ou editar uma chave.

### Permissões da chave

Cada chave de API tem acesso total às operações de API da sua conta:
- Comprar energia e largura de banda
- Gerenciar assinaturas do Smart Mode
- Criar faturas
- Consultar saldo e histórico de transações

<Warning>
  Mantenha sua chave de API em sigilo. Não a exponha em código do lado do cliente, repositórios públicos ou URLs.
</Warning>

## Uso da chave e registro de solicitações

Cada solicitação autenticada com uma chave de API é guardada por 7 dias: método, caminho, código de status, latência e IP do cliente. Os parâmetros de consulta não são exibidos nesta visão. Abra [Dashboard → API Keys](https://tronrental.com/dashboard/api) e expanda uma chave para ver suas solicitações recentes; a coluna **Last Used** mostra a chamada mais recente (a marca de autenticação é atualizada no máximo uma vez a cada 5 minutos; o registro é exato). O registro está disponível apenas no painel — uma chave de API não pode ler o próprio registro.

## Limites de Taxa

O limite de taxa é contado por conta, não por chave: todas as chaves de uma conta compartilham um único orçamento. Consulte [Limites de Taxa](/resources/rate-limits) para detalhes.

## Erros

Erros de autenticação retornam HTTP `401`:

```json
{
  "detail": "Invalid or missing API key"
}
```

Se sua chave estiver desabilitada ou bloqueada, você receberá HTTP `403`.
