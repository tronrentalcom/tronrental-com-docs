## Autenticação por Chave de API

Todas as requisições da API exigem uma chave de API enviada no cabeçalho `X-API-Key`.

```bash
curl https://api.tronrental.com/v1/account/balance \
  -H "X-API-Key: your_api_key"
```

### Obtendo uma chave de API

1. Cadastre-se em [tronrental.com](https://tronrental.com/auth/register)
2. Acesse [Painel → Chaves de API](https://tronrental.com/dashboard/api)
3. Clique em **Criar Chave de API**
4. Copie e armazene sua chave com segurança — ela é exibida apenas uma vez

Uma nova conta por e-mail só é criada depois que o endereço é confirmado: o TronRental envia um código de 6 dígitos por e-mail, e a conta passa a existir assim que esse código é informado.

### Cadastro pela API (agentes de IA)

Um agente ou script pode abrir uma conta e emitir a primeira chave sem usar o site. Para isso, ele precisa do e-mail **real** do usuário: a conta só é criada com o código recebido nessa caixa de entrada.

**1. Inicie o cadastro** — nenhuma conta é criada ainda; um código de 6 dígitos é enviado para o endereço:

```bash
curl -X POST https://api.tronrental.com/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com", "password": "<your-password>", "language": "en"}'
```

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|----------|-------------|
| `email` | string | Sim | O e-mail do usuário — ele precisa conseguir ler o código nessa caixa |
| `password` | string | Sim | No mínimo 8 caracteres, com uma letra maiúscula, uma minúscula e um dígito |
| `language` | string | Não | Idioma do e-mail, padrão `en` |

```json
{
  "requires_email_code": true,
  "access_token": null,
  "refresh_token": null
}
```

O código é válido por 10 minutos. Se já houver um código válido pendente, um segundo e-mail não é enviado. Para obter um novo código, chame `POST /v1/auth/email-code/send` com `{"email": "...", "language": "en"}`: o código anterior deixa de funcionar, e cada endereço recebe no máximo 3 e-mails por hora.

**2. Confirme o e-mail** — envie o código junto com a **mesma senha** (ela não é armazenada antes desta etapa). Isso cria a conta e faz o login:

```bash
curl -X POST https://api.tronrental.com/v1/auth/email-code/verify \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com", "code": "123456", "password": "<your-password>"}'
```

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|----------|-------------|
| `email` | string | Sim | O mesmo e-mail da etapa 1 |
| `code` | string | Sim | Código de 6 dígitos do e-mail |
| `password` | string | Sim, no cadastro | A mesma senha da etapa 1 |
| `referral_code` | string | Não | Código de indicação do usuário que convidou você |

```json
{
  "access_token": "eyJhbGciOi...",
  "refresh_token": "eyJhbGciOi...",
  "session_id": "3f9c...",
  "token_type": "bearer",
  "is_new": true
}
```

**3. Crie uma chave de API** com o access token:

```bash
curl -X POST https://api.tronrental.com/v1/auth/api-keys \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-agent"}'
```

O campo `key` da resposta é a chave de API — ela é exibida apenas uma vez.

| Status | Código | Significado |
|--------|------|---------|
| `400` | `WEAK_PASSWORD` | A senha não atende às regras (o código não é consumido) |
| `401` | `INVALID_CREDENTIALS` | Código incorreto ou expirado |
| `403` | `EMAIL_DOMAIN_BLOCKED` | Este provedor de e-mail não é aceito |
| `409` | `EMAIL_EXISTS` | Este e-mail já tem uma conta — faça login |
| `429` | `RATE_LIMIT_EXCEEDED` | Requisições ou e-mails demais, ou 5 códigos incorretos seguidos — solicite um novo código |

<Note>
  O [servidor MCP](/pt/resources/mcp-server) executa essas etapas com as ferramentas `register` e `verify_email_code`.
</Note>

### Lista de IPs permitidos (opcional)

Você pode restringir sua chave de API a endereços IP específicos para segurança adicional. Configure isso no painel ao criar ou editar uma chave.

### Permissões da chave

Cada chave de API tem **escopos** (scopes): as operações que ela pode realizar. Você os escolhe no
painel ao criar ou editar uma chave. Uma chave nova recebe todos os escopos de leitura e escrita
(comprar energia e largura de banda, Smart Mode, consultar saldo e histórico, entre outros), exceto
`withdraw`: esse escopo é ativado separadamente e exige 2FA e uma lista de IPs permitidos; ativá-lo, alterar a lista de IPs dessa chave e regenerá-la são confirmados com seu código 2FA ou passkey. Uma
solicitação fora dos escopos da chave é recusada com HTTP `403`. A lista completa:
[Listar escopos de chaves de API](/pt/api-reference/account/api-key-scopes).

<Warning>
  Mantenha sua chave de API em sigilo. Não a exponha em código do lado do cliente, repositórios públicos ou URLs.
</Warning>

## Chaves do Node API

O [Node API](/pt/node-api/overview) — acesso a nós completos TRON em `node.tronrental.com` — tem chaves
próprias. Você as cria como endpoints em [Painel → Node API](https://tronrental.com/dashboard/node-api).
Uma chave do Node API funciona apenas no nó: esta API a recusa com `403 NODE_API_KEY_ONLY`. As chaves de
API descritas nesta página também não funcionam no nó. Veja
[Node API → Endpoints e chaves](/pt/node-api/authentication).

## Uso da chave e registro de solicitações

Cada solicitação autenticada com uma chave de API é guardada por 7 dias: método, caminho, código de status, latência e IP do cliente. Os parâmetros de consulta não são exibidos nesta visão. Abra [Dashboard → API Keys](https://tronrental.com/dashboard/api) e expanda uma chave para ver suas solicitações recentes; a coluna **Last Used** mostra a chamada mais recente (a marca de autenticação é atualizada no máximo uma vez a cada 5 minutos; o registro é exato). O registro está disponível apenas no painel — uma chave de API não pode ler o próprio registro.

## Limites de Taxa

O limite de taxa é contado por conta, não por chave: todas as chaves de uma conta compartilham um único orçamento. Consulte [Limites de Taxa](/pt/resources/rate-limits) para detalhes.

## Erros

Erros de autenticação retornam HTTP `401`:

```json
{
  "detail": "Invalid or missing API key"
}
```

Se sua chave estiver desabilitada ou bloqueada, você receberá HTTP `403`.
