## Obter Endereço de Depósito

<div>
  `GET /api/v1/account/deposit`
</div>

Retorna seu endereço pessoal de depósito e moedas aceitas.

```bash
curl https://api.tronrental.com/v1/account/deposit \
  -H "X-API-Key: your_api_key"
```

```json
{
  "deposit_address": "TYourDepositAddress...",
  "accepted_currencies": ["TRX", "USDT"],
  "usdt_to_trx_rate": "26.5",
  "trx_usd_rate": "0.234"
}
```

## Listar Depósitos

<div>
  `GET /api/v1/account/deposits`
</div>

Retorna seu histórico de depósitos.

```bash
curl https://api.tronrental.com/v1/account/deposits \
  -H "X-API-Key: your_api_key"
```

### Parâmetros de consulta

<ParamField query="from" type="string">
  Primeiro dia do período, `YYYY-MM-DD`, inclusive. Sem nenhuma das duas datas, a lista completa.
</ParamField>

<ParamField query="to" type="string">
  Último dia do período, `YYYY-MM-DD`, **inclusive** — o dia inteiro conta, até 23:59:59.999 no seu fuso horário.
</ParamField>

<ParamField query="tz" type="string">
  Fuso horário IANA em que as duas datas são lidas, por exemplo `Europe/Berlin`. Omitido significa UTC.
</ParamField>

<Info>
  Ao contrário de um relatório, a lista não tem limite de um ano — ela é paginada. Ambas as datas são opcionais: apenas `from` significa «desse dia em diante»; apenas `to`, «até esse dia inclusive».
</Info>

### Status dos depósitos

| Status | Descrição |
|--------|-----------|
| `pending` | Transação detectada, aguardando confirmação |
| `confirmed` | Creditado no seu saldo |
| `expired` | Endereço de depósito expirado |

<Info>
  Os depósitos são creditados automaticamente. Depósitos em TRX são 1:1. Depósitos em USDT são convertidos para TRX na taxa de mercado atual.
</Info>
