## Listar escopos de chaves de API

Retorna o catálogo de escopos de chaves de API, agrupados do jeito que o painel os mostra. Use-o para
descobrir os nomes de escopo válidos.

As chaves do Node API são um tipo separado de chave: elas têm apenas o escopo `node_api`, nunca junto
com os outros escopos, e funcionam apenas em `node.tronrental.com`. Você as cria como endpoints em
[Painel → Node API](https://tronrental.com/dashboard/node-api); quantas você pode ter depende do seu
plano do Node API. Uma chave do Node API não pode chamar este endpoint — a API REST responde com
`403 NODE_API_KEY_ONLY`. Veja [Node API → Endpoints e chaves](/pt/node-api/authentication).

### Resposta

<ResponseField name="read" type="string[]">
  Escopos de leitura: `view`, `deposit_view`
</ResponseField>

<ResponseField name="node" type="string[]">
  O escopo do Node API: `node_api`. Uma chave com ele não tem nenhum outro escopo
</ResponseField>

<ResponseField name="write" type="string[]">
  Escopos que gastam o saldo ou alteram serviços: `buy_energy`, `buy_bandwidth`, `smart_mode`,
  `transfer_packages`, `energy_resale`
</ResponseField>

<ResponseField name="danger" type="string[]">
  `withdraw`. Ativá-lo em uma chave exige 2FA e uma lista de IPs permitidos não vazia
</ResponseField>

<ResponseField name="default" type="string[]">
  Escopos que uma nova chave da API REST recebe quando nenhum é escolhido: todos os escopos de leitura e
  de escrita, sem `withdraw`
</ResponseField>

<ResponseField name="locked" type="string[]">
  Escopos que toda chave da API REST sempre tem: `view`
</ResponseField>

### Exemplo

```bash
curl https://api.tronrental.com/v1/auth/api-keys/scopes \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "read": ["view", "deposit_view"],
  "node": ["node_api"],
  "write": ["buy_energy", "buy_bandwidth", "smart_mode", "transfer_packages", "energy_resale"],
  "danger": ["withdraw"],
  "default": ["view", "deposit_view", "buy_energy", "buy_bandwidth", "smart_mode", "transfer_packages", "energy_resale"],
  "locked": ["view"]
}
```
