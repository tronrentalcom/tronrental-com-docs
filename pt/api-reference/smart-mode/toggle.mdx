## Alternar Assinatura

Pausa uma assinatura ativa ou retoma uma pausada. Enquanto pausada, nenhuma taxa é cobrada e as transferências não são monitoradas.

### Parâmetros de caminho

<ParamField path="sub_id" type="number" required>
  ID da assinatura
</ParamField>

### Resposta

Uma resposta `200` significa que a assinatura foi pausada ou retomada. O corpo da resposta não faz parte do contrato da API: o novo estado está no campo `paused` de [Listar Assinaturas](/pt/api-reference/smart-mode/list-subscriptions).

### Exemplo

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```
