## Alternar Assinatura

Pausa uma assinatura ativa ou retoma uma pausada. Enquanto pausada, nenhuma taxa é cobrada e as transferências não são monitoradas.

### Parâmetros de caminho

<ParamField path="sub_id" type="number" required>
  ID da assinatura
</ParamField>

### Resposta

Retorna `paused`: o estado da assinatura após a alternância — `true` se agora está pausada, `false` se voltou a ficar ativa. O mesmo campo está em cada assinatura de [Listar Assinaturas](/pt/api-reference/smart-mode/list-subscriptions).

### Exemplo

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "paused": true
}
```
