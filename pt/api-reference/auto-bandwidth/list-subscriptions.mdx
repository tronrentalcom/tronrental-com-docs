## Listar assinaturas

Retorna todas as assinaturas de Bandwidth automático da sua conta, com o seu saldo e se novas assinaturas podem ser criadas agora. As assinaturas excluídas não são incluídas. Exige o escopo `view`.

### Resposta

<ResponseField name="subscriptions" type="array">
  As suas assinaturas.

  <Expandable title="objeto da assinatura">
    <ResponseField name="id" type="number">
      ID da assinatura — use-o nos caminhos de edição e exclusão
    </ResponseField>
    <ResponseField name="address" type="string">
      O endereço onde a assinatura mantém largura de banda
    </ResponseField>
    <ResponseField name="label" type="string | null">
      O seu nome para a assinatura
    </ResponseField>
    <ResponseField name="token" type="string">
      `USDT`, `TRX`, `USDD`, `CUSTOM` ou `OWN` — veja [Token](/pt/api-reference/auto-bandwidth/overview#opções)
    </ResponseField>
    <ResponseField name="contract" type="object | null">
      O contrato do token de uma assinatura `CUSTOM` ou `OWN`: `address`, `symbol` e `name` (`symbol` e `name` como a rede os informou, `null` se desconhecidos). `null` quando não há contrato.
    </ResponseField>
    <ResponseField name="volume" type="number">
      Largura de banda mantida no endereço
    </ResponseField>
    <ResponseField name="auto_pause" type="boolean">
      Se a pausa automática está ligada
    </ResponseField>
    <ResponseField name="threshold" type="number">
      Nível de largura de banda gratuita para a pausa automática e para a notificação de largura de banda gratuita
    </ResponseField>
    <ResponseField name="stop_after_transfer" type="boolean">
      Se a próxima transferência do token da assinatura a pausa
    </ResponseField>
    <ResponseField name="notify_free_bw" type="boolean">
      Se avisamos você quando a largura de banda gratuita do endereço volta a `threshold`
    </ResponseField>
    <ResponseField name="status" type="string">
      `active`, `free_bw`, `paused` ou `stopped_balance` — veja [Status](/pt/api-reference/auto-bandwidth/overview#status)
    </ResponseField>
    <ResponseField name="stopped_reason" type="string | null">
      `insufficient_balance`, `transfer` ou `admin`; `null` quando não há motivo
    </ResponseField>
    <ResponseField name="address_change_to" type="string | null">
      O novo endereço enquanto uma mudança está em andamento; `null` caso contrário
    </ResponseField>
    <ResponseField name="free_bw" type="number | null">
      Largura de banda gratuita do endereço na última verificação. `null` antes da primeira verificação.
    </ResponseField>
    <ResponseField name="delegated_bw" type="number">
      Largura de banda que delegamos ao endereço neste momento; `0` quando não há
    </ResponseField>
    <ResponseField name="transfers" type="number">
      Transferências cobertas até agora — delegações que foram esgotadas e renovadas
    </ResponseField>
    <ResponseField name="delivery_state" type="string">
      `ok`, `waiting_stake` ou `failed` — veja [Status](/pt/api-reference/auto-bandwidth/overview#status)
    </ResponseField>
    <ResponseField name="paid_until" type="string | null">
      Fim das 24 horas pagas (ISO 8601, UTC). `null` se nenhum dia foi pago ainda.
    </ResponseField>
    <ResponseField name="total_charged_trx" type="string">
      TRX cobrados desta assinatura, no total
    </ResponseField>
    <ResponseField name="daily_trx" type="string | null">
      Tarifa atual por 24 horas. `null` se o preço está temporariamente indisponível.
    </ResponseField>
    <ResponseField name="transfer_trx" type="string | null">
      Tarifa atual por transferência: `transfer_bw_trx` + `transfer_fee_trx`. `null` se o preço está temporariamente indisponível.
    </ResponseField>
    <ResponseField name="transfer_bw_trx" type="string | null">
      A parte de largura de banda da tarifa de transferência
    </ResponseField>
    <ResponseField name="transfer_fee_trx" type="string | null">
      A parte de taxa fixa da tarifa de transferência
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Quando a assinatura foi criada (ISO 8601, UTC)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="balance_trx" type="string">
  O saldo da sua conta
</ResponseField>

<ResponseField name="enabled" type="boolean">
  `false` enquanto o Bandwidth automático está temporariamente desligado: criar uma assinatura ou ligar uma retorna então `503 AUTO_BW_DISABLED`
</ResponseField>

Os preços de uma assinatura valem para ela: calculados pela chave de API com a qual foi criada, ou como uma compra no site.

### Exemplo

<CodeGroup>
```bash cURL
curl https://api.tronrental.com/v1/bandwidth/auto \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.get(
    "https://api.tronrental.com/v1/bandwidth/auto",
    headers={"X-API-Key": "your_api_key"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto", {
  headers: { "X-API-Key": "your_api_key" },
});
console.log(await resp.json());
```
