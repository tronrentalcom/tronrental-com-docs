## Comprar bandwidth

Delega bandwidth para o endereço TRON especificado. O custo é deduzido do saldo da sua conta.

### Corpo da solicitação

<ParamField body="target_address" type="string" required>
  Endereço TRON de destino (formato T..., 34 caracteres)
</ParamField>

<ParamField body="volume" type="number" required>
  Quantidade de bandwidth a delegar (mín. 1, máx. 100.000)
</ParamField>

<ParamField body="duration" type="string" required>
  Duração do aluguel, um dos valores:

  - `"1h"` — 1 hora
  - `"1d"` — 24 horas
  - `"5m"` … `"59m"` — qualquer número inteiro de minutos de 5 a 59, pela tarifa horária com desconto (veja [Preços](#preços))

  Escreva os minutos como um número sem zero à esquerda, seguido de um `m` minúsculo: `"5m"`, `"30m"`. `"05m"`, `"5M"`,
  `"60m"` ou `"90m"` são recusados com `400 INVALID_DURATION`: uma hora é `"1h"`, e não há
  nada entre `"1h"` e `"1d"`. Use `"1d"`, não `"24h"` ou valores numéricos de horas.
</ParamField>

<ParamField body="max_price_trx" type="string">
  Opcional. O máximo que você aceita pagar por este pedido, em TRX — aluguel e taxa fixa juntos. Se o
  pedido custar mais, ele é recusado com `409 PRICE_CHANGED` e **nada é cobrado**. Envie o
  `total_trx` de [Calcular preço de bandwidth](/pt/api-reference/bandwidth/quote). Uma string decimal como
  `"0.58"` (um número JSON também é aceito), maior que 0. Sem ele, o pedido é comprado pelo
  preço atual, como antes.
</ParamField>

### Cabeçalhos

<ParamField header="Idempotency-Key" type="string">
  Opcional, até 64 caracteres. Uma repetição com a mesma chave e o mesmo corpo retorna o pedido
  original em vez de comprar de novo. Depois de um pedido bem-sucedido, a mesma chave com outro corpo —
  inclusive com outro `max_price_trx` — retorna `422 IDEMPOTENCY_KEY_REUSED`. Depois de uma recusa que
  não cobrou nada, como `409 PRICE_CHANGED` ou `402 INSUFFICIENT_BALANCE`, a chave fica livre de novo:
  repita com ela e o novo preço.
</ParamField>

### Resposta

<ResponseField name="id" type="number">
  Identificador único do pedido
</ResponseField>

<ResponseField name="status" type="string">
  Status do pedido: `pending`, `filled`, `failed`
</ResponseField>

<ResponseField name="txid" type="string | null">
  ID da transação on-chain após o broadcast da delegação (null enquanto `pending`)
</ResponseField>

<ResponseField name="price_trx" type="string">
  Custo total do pedido debitado do saldo, em TRX — aluguel e taxa fixa
</ResponseField>

<ResponseField name="reclaim_at" type="string | null">
  Timestamp ISO 8601 quando o bandwidth alugado é recuperado
</ResponseField>

<ResponseField name="activation_cost_trx" type="string">
  Cobrado pela ativação on-chain de `target_address`, se ele ainda não estava ativado, além de
  `price_trx`. `"0"` para um endereço que já está ativo.
</ResponseField>

### Preços

`1h` e `1d`: preço = `volume × price_sun / 1,000,000` + taxa fixa (0,2 TRX, a menos que a sua conta
tenha uma taxa própria), em que `price_sun` é
`price_sun_1h` ou `price_sun_1d` de [Consultar preços de bandwidth](/pt/api-reference/bandwidth/get-prices), ou
a sua tarifa negociada, se a sua conta tiver uma.

`5m` … `59m`: a tarifa horária (`price_sun_1h`, ou a sua tarifa horária negociada) com desconto. O
desconto é maior em 5 minutos e cai linearmente até zero em 59 minutos:

```text
discount % = short_max_discount_pct × (59 − minutes) / 54
price_sun  = hourly price_sun × (1 − discount % / 100)
```

O desconto se aplica apenas ao aluguel — a taxa fixa é a mesma para qualquer duração. O aluguel
de um prazo em minutos é arredondado ao SUN mais próximo (0,000001 TRX), com metades para cima. O `short_max_discount_pct` atual está em
[Consultar preços de bandwidth](/pt/api-reference/bandwidth/get-prices).

| Duração | Desconto quando `short_max_discount_pct` é 5 | Tarifa quando `price_sun_1h` é 400 |
|---|---|---|
| `5m` | 5% | 380 SUN |
| `17m` | ≈ 3,89% | ≈ 384,44 SUN |
| `32m` | 2,5% | 390 SUN |
| `45m` | ≈ 1,3% | ≈ 394,81 SUN |
| `59m` | 0% | 400 SUN |

Você não precisa calcular nada disso: [Calcular preço de bandwidth](/pt/api-reference/bandwidth/quote) retorna
o valor exato para o seu volume, a sua duração e a sua conta.

### Mostre o preço e compre por esse preço

1. Chame `GET /v1/bandwidth/quote` com a sua `X-API-Key` e mostre `total_trx` ao seu usuário.
2. Chame `POST /v1/bandwidth/buy` com `max_price_trx` igual a esse `total_trx`.

A cotação é calculada pelo mesmo código que cobra o pedido; por isso, enquanto o preço não muda,
o pedido custa exatamente `total_trx`. Se o preço mudar nesse intervalo, a compra é recusada com
`409 PRICE_CHANGED` antes de qualquer cobrança: obtenha uma nova cotação, mostre-a e repita — com a mesma
`Idempotency-Key`, se você usar uma.

<Warning>
  `max_price_trx` cobre apenas o pedido de bandwidth. Se `target_address` ainda não estiver ativado on-chain,
  a ativação é cobrada à parte (`activation_cost_trx`) e não entra na verificação de
  `max_price_trx`.
</Warning>

### Exemplo: cotação e compra por 5 minutos

<CodeGroup>
```bash cURL
# 1. The exact price — show total_trx to your user
curl "https://api.tronrental.com/v1/bandwidth/quote?volume=1000&duration=5m" \
  -H "X-API-Key: your_api_key"

# 2. Buy, refusing any price above the quoted total_trx
curl -X POST https://api.tronrental.com/v1/bandwidth/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "target_address": "TYourRecipientAddress1234567890abc",
    "volume": 1000,
    "duration": "5m",
    "max_price_trx": "0.580000"
  }'
```

```python Python
import requests

API = "https://api.tronrental.com/v1"
HEADERS = {"X-API-Key": "your_api_key"}
order = {"target_address": "TYourRecipientAddress1234567890abc", "volume": 1000, "duration": "5m"}

quote = requests.get(
    f"{API}/bandwidth/quote",
    params={"volume": order["volume"], "duration": order["duration"]},
    headers=HEADERS,
).json()
print("Price:", quote["total_trx"], "TRX")

resp = requests.post(
    f"{API}/bandwidth/buy",
    headers=HEADERS,
    json={**order, "max_price_trx": quote["total_trx"]},
)
if resp.status_code == 409 and resp.json()["detail"]["error"]["code"] == "PRICE_CHANGED":
    print("The price changed and nothing was charged: quote again and retry")
else:
    print(resp.json())
```

```javascript JavaScript
const API = "https://api.tronrental.com/v1";
const headers = { "X-API-Key": "your_api_key" };
const order = { target_address: "TYourRecipientAddress1234567890abc", volume: 1000, duration: "5m" };

const quote = await (
  await fetch(`${API}/bandwidth/quote?volume=${order.volume}&duration=${order.duration}`, { headers })
).json();
console.log("Price:", quote.total_trx, "TRX");

const resp = await fetch(`${API}/bandwidth/buy`, {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({ ...order, max_price_trx: quote.total_trx }),
});
const body = await resp.json();
if (resp.status === 409 && body.detail?.error?.code === "PRICE_CHANGED") {
  console.log("The price changed and nothing was charged: quote again and retry");
} else {
  console.log(body);
}
```

### Erros

| Código | Significado |
|------|---------|
| `400 INVALID_DURATION` | `duration` não é `1h`, `1d` nem `5m` … `59m` |
| `400 INVALID_VOLUME` | Volume fora de 1–100.000 |
| `402 INSUFFICIENT_BALANCE` | Saldo insuficiente para o pedido. Nada foi cobrado |
| `409 PRICE_CHANGED` | O pedido custa mais que `max_price_trx`. Nada foi cobrado; a mensagem traz o preço atual |
| `422 IDEMPOTENCY_KEY_REUSED` | A `Idempotency-Key` já comprou um pedido com outro corpo |

Um `max_price_trx` igual a 0, negativo ou que não seja um número é um erro de validação `422` no
formato próprio do framework. Os demais códigos estão listados em [Erros](/pt/errors).
