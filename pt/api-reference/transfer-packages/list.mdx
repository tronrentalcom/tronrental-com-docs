## Listar Meus Pacotes

Retorna todos os seus pacotes de transferência.

### Resposta

Array de objetos de pacote. Campos principais: `id`, `address`, `package_size`, `quota_total` (transferências do pacote), `quota_used` (transferências atendidas), `subscription_used` (transferências consumidas pela taxa diária, uma por dia), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `bw_fee_per_transfer` (o valor devolvido por transferência restante ao desativar a Garantia BW; `null` quando desativada), `status`, `paused_at` (quando o pacote foi pausado; `null` a menos que `status` seja `paused`), `created_at`, `label` (seu nome para o endereço, veja [Nomear uma Carteira](/pt/api-reference/transfer-packages/set-label); `null` — sem nome), `archived_at` (quando o pacote foi arquivado, veja [Arquivar Carteira](/pt/api-reference/transfer-packages/archive); `null` — na lista principal).

Pacotes arquivados estão incluídos. Para ler a lista por páginas, como o painel, use [Listar Pacotes por Página](/pt/api-reference/transfer-packages/list-page).

### Status dos pacotes

| Status | Descrição |
|--------|-----------|
| `pending_payment` | Aguardando pagamento da fatura |
| `provisioning` | Pago com o saldo, ativação em andamento |
| `active` | Monitorando endereço, transferências disponíveis |
| `paused` | [Pausado](/pt/api-reference/transfer-packages/pause) por você: sem taxa diária, as transferências não são atendidas nem contadas, as transferências restantes são mantidas |
| `completed` | Todas as transferências utilizadas |
| `cancelled` | Cancelado pelo usuário |
| `expired` | A fatura não foi paga a tempo |
| `manual_review` | O resultado da ativação não está claro; o suporte verifica, e o pagamento fica retido até lá |
| `failed_refunded` | A ativação falhou; o valor foi devolvido ao saldo |

curl https://api.tronrental.com/v1/transfer-packages/my \
  -H "X-API-Key: your_api_key"
