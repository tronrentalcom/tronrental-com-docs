## Listar Meus Pacotes

Retorna todos os seus pacotes de transferência.

### Resposta

Array de objetos de pacote. Campos principais: `id`, `address`, `package_size`, `quota_total` (transferências do pacote), `quota_used` (transferências atendidas), `subscription_used` (transferências consumidas pela taxa diária, uma por dia), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `status`, `created_at`.

### Status dos pacotes

| Status | Descrição |
|--------|-----------|
| `pending_payment` | Aguardando pagamento da fatura |
| `provisioning` | Pago com o saldo, ativação em andamento |
| `active` | Monitorando endereço, transferências disponíveis |
| `completed` | Todas as transferências utilizadas |
| `cancelled` | Cancelado pelo usuário |
| `expired` | A fatura não foi paga a tempo |
| `manual_review` | O resultado da ativação não está claro; o suporte verifica, e o pagamento fica retido até lá |
| `failed_refunded` | A ativação falhou; o valor foi devolvido ao saldo |

### Exemplo

```bash
curl https://api.tronrental.com/v1/transfer-packages/my \
  -H "X-API-Key: your_api_key"
```

  }
