## Listar Pacotes por Página

Retorna uma página dos seus pacotes de transferência: a lista principal, ou o arquivo com `archived=true`. Primeiro vêm os pacotes não encerrados — ativos, pausados, aguardando pagamento ou ativação —, depois os mais recentes. É a lista que o painel mostra; [Listar Pacotes](/pt/api-reference/transfer-packages/list) continua retornando todos os pacotes de uma vez.

### Parâmetros de consulta

<ParamField query="archived" type="boolean" default="false">
  `true` — o arquivo (pacotes movidos para lá com [Arquivar Carteira](/pt/api-reference/transfer-packages/archive)); `false` (padrão) — a lista principal
</ParamField>

<ParamField query="page" type="number">
  Número da página (padrão 1)
</ParamField>

<ParamField query="page_size" type="number">
  Pacotes por página (padrão 20, máximo 100)
</ParamField>

### Resposta

<ResponseField name="packages" type="array">
  Pacotes da página — os mesmos objetos de [Listar Pacotes](/pt/api-reference/transfer-packages/list), com `label` e `archived_at`.
</ResponseField>

<ResponseField name="total" type="number">
  Pacotes da lista pedida, em todas as páginas.
</ResponseField>

<ResponseField name="page" type="number">
  A página da requisição.
</ResponseField>

<ResponseField name="page_size" type="number">
  O tamanho de página da requisição.
</ResponseField>

<ResponseField name="archived_packages" type="number">
  Pacotes que sua conta tem no arquivo — qualquer que seja a lista pedida.
</ResponseField>

<ResponseField name="archived_wallets" type="number">
  Endereços em que esses pacotes arquivados estão.
</ResponseField>

### Exemplo

```bash
curl "https://api.tronrental.com/v1/transfer-packages/list?page=1&page_size=20" \
  -H "X-API-Key: your_api_key"
```

### Erros

Retornados no [formato padrão](/pt/errors), em `detail.error.code`. Depois de qualquer um deles, nada mudou.

| Código | Status | Quando |
|--------|--------|--------|
| — | `422` | `page` < 1, `page_size` ∉ 1–100 |
