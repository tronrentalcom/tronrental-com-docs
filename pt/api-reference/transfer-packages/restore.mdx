## Restaurar Carteira

Traz de volta à lista principal os pacotes arquivados da sua conta no endereço. Os pacotes em si não mudam.

### Corpo da requisição

<ParamField body="address" type="string" required>
  Endereço TRON cujos pacotes arquivados voltam
</ParamField>

### Resposta

<ResponseField name="address" type="string">
  O endereço da requisição.
</ResponseField>

<ResponseField name="archived" type="boolean">
  Sempre `false`.
</ResponseField>

<ResponseField name="packages" type="number">
  Quantos pacotes voltaram; `0` — não havia nenhum no arquivo.
</ResponseField>

### Exemplo

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/restore \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

```json Response
{
  "address": "TYourAddress...",
  "archived": false,
  "packages": 3
}
```

### Erros

Retornados no [formato padrão](/pt/errors), em `detail.error.code`. Depois de qualquer um deles, nada mudou.

| Código | Status | Quando |
|--------|--------|--------|
| `PACKAGE_NOT_FOUND` | `404` | Sua conta não tem nenhum pacote no endereço |
