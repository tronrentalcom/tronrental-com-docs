## Comprar Pacote de Transferência

Compra um pacote de transferências usando o saldo da sua conta.

### Corpo da requisição

<ParamField body="address" type="string" required>
  Endereço TRON a monitorar
</ParamField>

<ParamField body="package_size" type="number">
  Número de transferências do pacote (2 – 10.000). Obrigatório, exceto quando `single_transfer` é `true`. `package_size: 1` é rejeitado com `422` — para comprar uma única transferência, envie `single_transfer: true`.
</ParamField>

<ParamField body="single_transfer" type="boolean" default="false">
  Comprar uma única transferência em vez de um pacote; `package_size` é ignorado. Preço: `single_transfer_price` de [Consultar Níveis](/pt/api-reference/transfer-packages/get-tiers) (com BW Guarantee, soma-se `bw_fee_per_transfer`).
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  Ativar BW Guarantee
</ParamField>

### Resposta

Retorna `package_id`, `status`, `total_price_trx`, `activation_cost_trx` (TRX gastos para ativar o endereço, se ainda não estava ativado; caso contrário, `0`) e `total_charged_trx`.

### Exemplo

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "package_size": 500,
    "bw_guarantee": true
  }'
```

```json Response
{
  "package_id": 101,
  "status": "active",
  "total_price_trx": "1500.0",
  "activation_cost_trx": "0",
  "total_charged_trx": "1500.0"
}
```

<Info>
  Você também pode pagar via fatura usando `POST /api/v1/transfer-packages/buy-invoice` —
  isso gera um endereço de pagamento para TRX/USDT.
</Info>
