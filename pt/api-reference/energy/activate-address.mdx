## Ativar Endereço

Ativa um endereço TRON que nunca recebeu nenhuma transação. Necessário antes que o endereço possa receber tokens.

**Custo: 1,2 TRX** (deduzido do seu saldo)

### Corpo da requisição

<ParamField body="target_address" type="string" required>
  Endereço TRON a ativar (formato T...)
</ParamField>

### Resposta

<ResponseField name="success" type="boolean">
  Se a ativação teve sucesso
</ResponseField>

<ResponseField name="status" type="string">
  `completed` — enviamos a ativação; `already_activated` — o endereço já estava ativo na rede
</ResponseField>

<ResponseField name="txid" type="string">
  Hash da transação de ativação
</ResponseField>

<ResponseField name="cost_trx" type="string">
  TRX cobrados pela ativação (0 se o endereço já estava ativo)
</ResponseField>

<ResponseField name="id" type="number">
  Identificador do registro de ativação
</ResponseField>

### Exemplo

```bash
curl -X POST https://api.tronrental.com/v1/energy/activate \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"target_address": "TNewInactiveAddress..."}'
```

```json Response
{
  "success": true,
  "status": "completed",
  "txid": "a1b2c3d4e5f6...",
  "cost_trx": "1.2",
  "id": 12345
}
```
