## Comprar Energia

Delega energia ao endereço TRON especificado. O custo é deduzido do saldo da sua conta.

### Corpo da requisição

<ParamField body="target_address" type="string" required>
  Endereço TRON de destino (formato T..., 34 caracteres)
</ParamField>

<ParamField body="volume" type="number" required>
  Quantidade de energia a delegar (mín. 1, máx. 5.000.000)
</ParamField>

<ParamField body="duration" type="string" required>
  Duração do aluguel: `"1h"` (apenas 1 hora)
</ParamField>

<ParamField body="max_price_trx" type="string">
  Opcional. O máximo que você aceita pagar por este pedido, em TRX — aluguel e taxa fixa juntos. Se o
  pedido custar mais, ele é recusado com `409 PRICE_CHANGED` e **nada é cobrado**. Envie o
  `total_trx` de [Calcular preço](/pt/api-reference/energy/quote). Uma string decimal como
  `"2.15"` (um número JSON também é aceito), maior que 0. Sem ele, o pedido é comprado pelo
  preço atual, como antes.
</ParamField>

### Cabeçalhos

<ParamField header="Idempotency-Key" type="string">
  Opcional, até 64 caracteres. Uma repetição com a mesma chave e o mesmo corpo retorna o pedido
  original em vez de comprar de novo. Depois de um pedido bem-sucedido, a mesma chave com outro corpo —
  inclusive com outro `max_price_trx` — retorna `422 IDEMPOTENCY_KEY_REUSED`. Depois de uma recusa que
  não cobrou nada, como `409 PRICE_CHANGED` ou `402 INSUFFICIENT_BALANCE`, a chave fica livre de novo:
  repita com ela e o novo preço.
</ParamField>

### Resposta

<ResponseField name="id" type="number">
  Unique order identifier
</ResponseField>

<ResponseField name="status" type="string">
  Order status: `pending`, `filled`, `failed`, `submitted_unknown` (pedidos abaixo de 32.000 — veja a nota abaixo)
</ResponseField>

<ResponseField name="txid" type="string | null">
  On-chain transaction id once the delegation is broadcast (null while `pending`)
</ResponseField>

<ResponseField name="price_trx" type="string">
  Total cost charged from your balance, in TRX
</ResponseField>

<ResponseField name="reclaim_at" type="string | null">
  ISO 8601 timestamp when the bandwidth rental is reclaimed (energy is reclaimed automatically by the provider)
</ResponseField>

<ResponseField name="activation_cost_trx" type="string">
  Address activation cost in TRX (`"0"` if the recipient is already activated)
</ResponseField>

### Mostre o preço e compre por esse preço

1. Chame `GET /v1/energy/quote` com a sua `X-API-Key` e mostre `total_trx` ao seu usuário.
2. Chame `POST /v1/energy/buy` com `max_price_trx` igual a esse `total_trx`.

A cotação é arredondada ao SUN exatamente como o pedido é cobrado; por isso, enquanto o preço não
muda, o pedido custa exatamente `total_trx`. O preço da energia acompanha o mercado e pode mudar
entre a cotação e a compra: nesse caso a compra é recusada com `409 PRICE_CHANGED` antes de qualquer
cobrança — obtenha uma nova cotação, mostre-a e repita, com a mesma `Idempotency-Key`, se você usar uma.

<Warning>
  `max_price_trx` cobre apenas o pedido de energia. Se `target_address` ainda não estiver ativado on-chain,
  a ativação é cobrada à parte (`activation_cost_trx`) e não entra na verificação de
  `max_price_trx`.
</Warning>

### Exemplo

<CodeGroup>
```bash cURL
curl -X POST https://api.tronrental.com/v1/energy/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "target_address": "TYourRecipientAddress1234567890abc",
    "volume": 65000,
    "duration": "1h"
  }'
```

```python Python
import requests

resp = requests.post(
    "https://api.tronrental.com/v1/energy/buy",
    headers={"X-API-Key": "your_api_key"},
    json={
        "target_address": "TYourRecipientAddress1234567890abc",
        "volume": 65000,
        "duration": "1h",
    },
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/energy/buy", {
  method: "POST",
  headers: {
    "X-API-Key": "your_api_key",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    target_address: "TYourRecipientAddress1234567890abc",
    volume: 65000,
    duration: "1h",
  }),
});
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "id": 12345,
  "price_trx": "2.75",
  "status": "pending"

```

<Tip>
  **65.000 energia** cobre uma transferência USDT para um endereço que já possui USDT.
  Use **131.000** para destinatários de USDT pela primeira vez (criação de novo slot de armazenamento).
</Tip>

<Note>
  **Pedidos abaixo de 32.000 de energia** são entregues a partir do nosso próprio pool. Se ele não puder atender este endereço no momento, a requisição falha com `503 POOL_EXHAUSTED` e **nada é cobrado** — tente novamente mais tarde ou peça 32.000 ou mais. Enquanto um pedido anterior abaixo de 32.000 para o mesmo endereço ainda estiver ativo, um novo é recusado da mesma forma.

  Um pedido assim pode voltar como `submitted_unknown`: a delegação foi transmitida, mas ainda não foi confirmada em um bloco. Em poucos minutos ele passa a `filled`, ou a `failed` com reembolso integral — consulte [Get Order](/pt/api-reference/orders/get-order).
</Note>
