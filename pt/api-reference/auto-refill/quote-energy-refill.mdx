## Cotação de recarga de energia

Retorna quanto custa para a sua conta uma recarga de `add_volume` de energia: o preço que uma regra com esse volume paga por recarga, taxa fixa incluída. Nada é criado nem cobrado. Exige o escopo `view`.

O preço depende de como você faz a chamada. Chamado com uma chave de API, é o preço de uma regra criada com essa chave de API; a partir do site, o preço de uma regra criada no site. É o preço no momento da requisição e não inclui a ativação de um endereço que ainda não existe na blockchain — a primeira recarga acrescenta esse valor.

### Parâmetros de consulta

<ParamField query="add_volume" type="number" required>
  Energia por recarga. De 32.000 a 5.000.000, o mesmo intervalo aceito ao criar uma regra.
</ParamField>

As recargas de energia sempre duram uma hora, por isso não há parâmetro `duration`; a resposta sempre traz `"duration": "1h"`.

### Resposta

<ResponseField name="add_volume" type="number">
  O volume que você consultou
</ResponseField>

<ResponseField name="duration" type="string">
  Duração do aluguel da recarga — sempre `1h` para energia
</ResponseField>

<ResponseField name="estimated_cost_per_refill_trx" type="string">
  Preço total de uma recarga para a sua conta, taxa fixa incluída
</ResponseField>

### Exemplo

<CodeGroup>
```bash cURL
curl "https://api.tronrental.com/v1/energy/auto-refill/quote?add_volume=131000" \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.get(
    "https://api.tronrental.com/v1/energy/auto-refill/quote",
    headers={"X-API-Key": "your_api_key"},
    params={"add_volume": 131000},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch(
  "https://api.tronrental.com/v1/energy/auto-refill/quote?add_volume=131000",
  { headers: { "X-API-Key": "your_api_key" } },
);
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "add_volume": 131000,
  "duration": "1h",
  "estimated_cost_per_refill_trx": "2.618000"
}
```

### Erros

| Status | Código | Quando |
|--------|------|------|
| `403` | `FORBIDDEN` | A chave de API não tem o escopo `view` |
| `422` | — | `add_volume` está ausente ou fora de 32.000 – 5.000.000 |
| `503` | `TEMPORARILY_UNAVAILABLE` | Não foi possível obter o preço agora — tente novamente após os segundos indicados em `Retry-After` |

```json
{
  "detail": {
    "error": {
      "code": "TEMPORARILY_UNAVAILABLE",
      "message": "Please retry shortly"
    }
  }
}
```

Um erro de validação vem no formato do framework, com `detail` como array:

```json
{
  "detail": [
    {
      "type": "greater_than_equal",
      "loc": ["query", "add_volume"],
      "msg": "Input should be greater than or equal to 32000",
      "input": "1000",
      "ctx": {"ge": 32000}
    }
  ]
}
```
