## Atualizar regra de largura de banda

Altera o limiar, o volume, a duração ou o rótulo de uma regra, ou a pausa e retoma. Envie apenas os campos que deseja alterar; os demais permanecem como estão. As alterações valem a partir da verificação seguinte. Exige o escopo `buy_bandwidth`.

O endereço de uma regra não pode ser alterado. Para mover uma regra para outro endereço, exclua-a e crie uma nova.

### Parâmetros de caminho

<ParamField path="rule_id" type="number" required>
  ID da regra — o `id` retornado por Criar ou Listar regras de largura de banda
</ParamField>

### Corpo da requisição

<ParamField body="threshold_bandwidth" type="number">
  Novo limiar. De 1 a 1.000.000.
</ParamField>

<ParamField body="add_volume" type="number">
  Nova quantidade de largura de banda por recarga. De 350 a 100.000.
</ParamField>

<ParamField body="duration" type="string">
  Nova duração do aluguel para as próximas recargas: `"1h"` ou `"1d"`. Os aluguéis já comprados mantêm a duração que tinham.
</ParamField>

<ParamField body="label" type="string">
  Novo rótulo, até 100 caracteres. Uma string vazia remove o rótulo.
</ParamField>

<ParamField body="status" type="string">
  `"paused"` para pausar a regra, `"active"` para retomá-la. Retomar também limpa `stopped_reason` e redefine `consecutive_failures` para 0. Uma regra parada por saldo é retomada sozinha após um depósito, então você não precisa fazer isso; se você a retomar enquanto o saldo ainda for insuficiente, ela para de novo na verificação seguinte. `stopped_insufficient_balance` não pode ser definido diretamente.
</ParamField>

### Resposta

A regra atualizada, com os mesmos campos de [Listar regras de largura de banda](/api-reference/auto-refill/list-bandwidth-rules).

### Exemplo

<CodeGroup>
```bash cURL
curl -X PATCH https://api.tronrental.com/v1/bandwidth/auto-refill/15 \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"duration": "1d"}'
```

```python Python
import requests

resp = requests.patch(
    "https://api.tronrental.com/v1/bandwidth/auto-refill/15",
    headers={"X-API-Key": "your_api_key"},
    json={"duration": "1d"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto-refill/15", {
  method: "PATCH",
  headers: { "X-API-Key": "your_api_key", "Content-Type": "application/json" },
  body: JSON.stringify({ duration: "1d" }),
});
console.log(await resp.json());
```

### Erros

| Status | Código | Quando |
|--------|------|------|
| `403` | `FORBIDDEN` | A chave de API não tem o escopo `buy_bandwidth` |
| `404` | `NOT_FOUND` | Não há regra de largura de banda com este ID na sua conta (ou ela foi excluída) |
| `409` | `AUTOREFILL_IN_PROGRESS` | Uma recarga desta regra está sendo comprada neste momento — tente novamente em um minuto |
| `422` | — | Um valor está fora do intervalo, `duration` não é `"1h"` nem `"1d"`, ou `status` não é `"active"` nem `"paused"` |

```json
{
  "detail": {
    "error": {
      "code": "AUTOREFILL_IN_PROGRESS",
      "message": "A refill is in progress for this rule; try again in a minute"
    }
  }
}
```
