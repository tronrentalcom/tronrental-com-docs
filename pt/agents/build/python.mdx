## Listar ferramentas e obter uma cotação

```python quote.py
import asyncio
import os

import httpx2
from mcp import Client
from mcp.client.streamable_http import streamable_http_client

URL = "https://mcp.tronrental.com/mcp"


async def main() -> None:
    headers = {"Authorization": f"Bearer {os.environ['TRONRENTAL_API_KEY']}"}
    async with httpx2.AsyncClient(headers=headers, timeout=httpx2.Timeout(30.0, read=120.0)) as http:
        async with Client(streamable_http_client(URL, http_client=http)) as client:
            tools = await client.list_tools()
            print([tool.name for tool in tools.tools])

            quote = await client.call_tool("quote_energy", {"volume": 65000, "duration": "1h"})
            print(quote.structured_content)
            # {'volume': 65000, 'duration': '1h', 'total_trx': '1.694350', ...}


asyncio.run(main())
```

```bash
TRONRENTAL_API_KEY=your_key python quote.py
```

O `Client` faz o handshake `initialize` do MCP por você. `tools/list` devolve apenas as ferramentas que os escopos da sua chave permitem.

## Comprar energia

Cote primeiro, envie o `total_trx` da cotação como `max_price_trx` e mantenha um único `idempotency_key` para a compra, para que uma nova tentativa não cobre duas vezes:

```python
import uuid


async def buy_energy(client: Client, target: str, volume: int = 65000) -> dict:
    quote = await client.call_tool("quote_energy", {"volume": volume, "duration": "1h"})
    total = quote.structured_content["total_trx"]

    key = str(uuid.uuid4())  # reutilize-a se repetir esta compra
    order = await client.call_tool(
        "buy_energy",
        {
            "target_address": target,
            "volume": volume,
            "duration": "1h",
            "max_price_trx": total,
            "idempotency_key": key,
        },
    )
    if order.is_error:
        raise RuntimeError(order.structured_content["error"])  # {code, message, status}
    return order.structured_content  # o pedido: id, status, price_trx, ...
```

No SDK, uma chamada recusada não lança exceção: o resultado tem `is_error` definido e o [código de erro](/pt/agents/reference/spending-and-errors#códigos-de-erro) em `structured_content["error"]`.

## Login de usuários com OAuth

Para um app em que cada usuário conecta a própria conta, use o `mcp.client.auth.OAuthClientProvider` do SDK como `auth` do `httpx2.AsyncClient` em vez de um cabeçalho. Ele executa a descoberta, o registro do cliente e o PKCE com o [servidor OAuth](/pt/agents/reference/oauth) da TronRental; você fornece o armazenamento dos tokens e os handlers de redirecionamento e de callback. Veja o [guia de autorização](https://py.sdk.modelcontextprotocol.io/) do SDK.

Use uma redirect URI de loopback (`http://127.0.0.1:<port>/callback`) para apps de desktop e CLI; para o callback próprio de um app web, [fale com o suporte](https://t.me/TronRentalcom_Help_bot).
