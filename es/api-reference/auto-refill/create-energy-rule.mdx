## Crear regla de energía

Crea una regla de Recarga automática para una dirección. A partir de la siguiente comprobación, cada vez que la dirección tenga menos energía disponible que `threshold_energy`, compramos `add_volume` de energía por una hora y lo cobramos de tu saldo. Consulta la [descripción general](/es/api-reference/auto-refill/overview) para ver cómo funcionan las comprobaciones, el coste y los estados.

La solicitud solo crea la regla — no compra nada por sí misma. Requiere el alcance `buy_energy`. Para ver antes el precio de una recarga, usa [Cotización de recarga de energía](/es/api-reference/auto-refill/quote-energy-refill).

### Cuerpo de la solicitud

<ParamField body="target_address" type="string" required>
  Dirección TRON que se mantendrá abastecida (formato T..., 34 caracteres). Las direcciones de contrato se rechazan.
</ParamField>

<ParamField body="threshold_energy" type="number" required>
  Se compra cuando la dirección tiene menos energía disponible que este valor. De 1 a 50,000,000.
</ParamField>

<ParamField body="add_volume" type="number" required>
  Energía que se compra en cada recarga. De 1 a 5,000,000. Mantenlo igual o por encima de `threshold_energy` — consulta la [advertencia de la descripción general](/es/api-reference/auto-refill/overview#cómo-elegir-los-valores).
</ParamField>

<ParamField body="duration" type="string" default="1h">
  Duración del alquiler de cada recarga. Solo se acepta `"1h"`; cualquier otro valor devuelve `422`.
</ParamField>

<ParamField body="label" type="string">
  Tu propio nombre para la regla, hasta 100 caracteres. Opcional.
</ParamField>

### Respuesta

La nueva regla — con los mismos campos que en [Listar reglas de energía](/es/api-reference/auto-refill/list-energy-rules) — más dos campos sobre el estado actual de la dirección:

<ResponseField name="current_energy" type="number | null">
  Energía disponible en la dirección en el momento de crear la regla. `null` si no se pudo leer; la regla se crea de todos modos.
</ResponseField>

<ResponseField name="will_refill_now" type="boolean">
  `true` si `current_energy` ya está por debajo del umbral, de modo que la siguiente comprobación — normalmente en menos de un minuto — comprará. `false` si la dirección tiene suficiente, o si no se pudo leer el nivel.
</ResponseField>

  -H "X-API-Key: your_api_key" \

### Errores

| Estado | Código | Cuándo |
|--------|--------|--------|
| `400` | `INVALID_ADDRESS` | `target_address` no es una dirección TRON válida |
| `400` | `CONTRACT_ADDRESS_NOT_SUPPORTED` | `target_address` es un contrato inteligente |
| `403` | `FORBIDDEN` | La clave API carece del alcance `buy_energy` |
| `409` | `AUTOREFILL_ADDRESS_TAKEN` | Tu cuenta ya tiene una regla de energía para esta dirección — edítala en su lugar |
| `409` | `AUTOREFILL_LIMIT_REACHED` | Tu cuenta ya tiene 20 reglas de energía; el límite también figura en `error.limit` |
| `422` | — | Falta un campo o está fuera de rango, o `duration` no es `"1h"` |
| `429` | `RATE_LIMIT_EXCEEDED` | Más de 10 solicitudes de creación en un minuto |
| `503` | `AUTOREFILL_DISABLED` | La Recarga automática de energía está desactivada temporalmente; no se creó ninguna regla — reintenta más tarde |

Un error de validación llega en el formato del framework, con `detail` como array:

```json
{
  "detail": [
    {
      "type": "literal_error",
      "loc": ["body", "duration"],
      "msg": "Input should be '1h'",
      "input": "1d",
      "ctx": {"expected": "'1h'"}
    }
  ]
}
```

<Tip>
Reintentar una creación tras agotarse el tiempo de espera es seguro. Si la primera solicitud se completó, el reintento devuelve `409 AUTOREFILL_ADDRESS_TAKEN` en lugar de crear una segunda regla; [lista tus reglas](/es/api-reference/auto-refill/list-energy-rules) para obtener su `id`.
</Tip>
