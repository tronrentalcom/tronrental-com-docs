## Comprar paquete de transferencias

Compra un paquete de transferencias usando el saldo de tu cuenta.

### Cuerpo de la solicitud

<ParamField body="address" type="string" required>
  Direccion TRON a monitorear
</ParamField>

<ParamField body="package_size" type="number">
  Numero de transferencias del paquete (2 – 10,000). Obligatorio salvo que `single_transfer` sea `true`. `package_size: 1` se rechaza con `422`: para comprar una sola transferencia, envia `single_transfer: true`.
</ParamField>

<ParamField body="single_transfer" type="boolean" default="false">
  Comprar una sola transferencia en lugar de un paquete; `package_size` se ignora. Precio: `single_transfer_price` de [Obtener niveles](/es/api-reference/transfer-packages/get-tiers) (con Garantia de BW se suma `bw_fee_per_transfer`).
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  Habilitar Garantia de BW
</ParamField>

### Respuesta

Devuelve `package_id`, `status`, `total_price_trx`, `activation_cost_trx` (TRX para activar la direccion si aun no estaba activada; si no, `0`) y `total_charged_trx`.

### Ejemplo

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "package_size": 500,
    "bw_guarantee": true
  }'
```

```json Response
{
  "package_id": 101,
  "status": "active",
  "total_price_trx": "1500.0",
  "activation_cost_trx": "0",
  "total_charged_trx": "1500.0"
}
```

<Info>
  Tambien puedes pagar mediante factura usando `POST /api/v1/transfer-packages/buy-invoice` —
  esto genera una direccion de pago para TRX/USDT.
</Info>
