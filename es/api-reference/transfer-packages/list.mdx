## Listar mis paquetes

Devuelve todos tus paquetes de transferencias.

### Respuesta

Array de objetos de paquetes. Campos principales: `id`, `address`, `package_size`, `quota_total` (transferencias del paquete), `quota_used` (transferencias atendidas), `subscription_used` (transferencias que consume la tarifa diaria, una por dia), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `status`, `created_at`.

### Estados del paquete

| Estado | Descripcion |
|--------|-------------|
| `pending_payment` | Esperando pago de la factura |
| `provisioning` | Pagado con el saldo, activacion en curso |
| `active` | Monitoreando direccion, transferencias disponibles |
| `completed` | Todas las transferencias utilizadas |
| `cancelled` | Cancelado por el usuario |
| `expired` | La factura no se pago a tiempo |
| `manual_review` | El resultado de la activacion no es claro; soporte lo revisa y el pago queda retenido hasta entonces |
| `failed_refunded` | La activacion fallo; el precio se devolvio al saldo |

### Ejemplo

```bash
curl https://api.tronrental.com/v1/transfer-packages/my \
  -H "X-API-Key: your_api_key"
```
