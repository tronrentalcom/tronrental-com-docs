## Restaurar billetera

Devuelve a la lista principal los paquetes archivados de tu cuenta en la dirección. Los paquetes en sí no cambian.

### Cuerpo de la solicitud

<ParamField body="address" type="string" required>
  Dirección TRON cuyos paquetes archivados se devuelven
</ParamField>

### Respuesta

<ResponseField name="address" type="string">
  La dirección de la solicitud.
</ResponseField>

<ResponseField name="archived" type="boolean">
  Siempre `false`.
</ResponseField>

<ResponseField name="packages" type="number">
  Cuántos paquetes volvieron; `0` — no había ninguno en el archivo.
</ResponseField>

### Ejemplo

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/restore \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

```json Response
{
  "address": "TYourAddress...",
  "archived": false,
  "packages": 3
}
```

### Errores

Se devuelven en la [forma estándar](/es/errors), en `detail.error.code`. Después de cualquiera de ellos no ha cambiado nada.

| Código | Estado | Cuándo |
|--------|--------|--------|
| `PACKAGE_NOT_FOUND` | `404` | Tu cuenta no tiene ningún paquete en la dirección |
