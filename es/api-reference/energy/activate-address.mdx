## Activar direccion

Activa una direccion TRON que nunca ha recibido ninguna transaccion. Es necesario antes de que la direccion pueda recibir tokens.

**Costo: 1.2 TRX** (se deduce de tu saldo)

### Cuerpo de la solicitud

<ParamField body="target_address" type="string" required>
  Direccion TRON a activar (formato T...)
</ParamField>

### Respuesta

<ResponseField name="success" type="boolean">
  Si la activación tuvo éxito
</ResponseField>

<ResponseField name="status" type="string">
  `completed` — enviamos la activación; `already_activated` — la dirección ya estaba activa en la red
</ResponseField>

<ResponseField name="txid" type="string">
  Hash de la transacción de activación
</ResponseField>

<ResponseField name="cost_trx" type="string">
  TRX cobrados por la activación (0 si la dirección ya estaba activa)
</ResponseField>

<ResponseField name="id" type="number">
  Identificador del registro de activación
</ResponseField>

### Ejemplo

```bash
curl -X POST https://api.tronrental.com/v1/energy/activate \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"target_address": "TNewInactiveAddress..."}'
```

```json Response
{
  "success": true,
  "status": "completed",
  "txid": "a1b2c3d4e5f6...",
  "cost_trx": "1.2",
  "id": 12345
}
```
