## Listar suscripciones

Devuelve todas las suscripciones de Bandwidth automático de tu cuenta, con tu saldo y si se pueden crear suscripciones nuevas en este momento. Las suscripciones eliminadas no se incluyen. Requiere el alcance `view`.

### Respuesta

<ResponseField name="subscriptions" type="array">
  Tus suscripciones.

  <Expandable title="objeto de suscripción">
    <ResponseField name="id" type="number">
      ID de la suscripción — úsalo en las rutas de edición y eliminación
    </ResponseField>
    <ResponseField name="address" type="string">
      La dirección en la que la suscripción mantiene ancho de banda
    </ResponseField>
    <ResponseField name="label" type="string | null">
      Tu nombre para la suscripción
    </ResponseField>
    <ResponseField name="token" type="string">
      `USDT`, `TRX`, `USDD`, `CUSTOM` u `OWN` — ver [Token](/es/api-reference/auto-bandwidth/overview#opciones)
    </ResponseField>
    <ResponseField name="contract" type="object | null">
      El contrato del token de una suscripción `CUSTOM` u `OWN`: `address`, `symbol` y `name` (`symbol` y `name` tal como los informó la red, `null` si se desconocen). `null` cuando no hay ninguno.
    </ResponseField>
    <ResponseField name="volume" type="number">
      Ancho de banda que se mantiene en la dirección
    </ResponseField>
    <ResponseField name="auto_pause" type="boolean">
      Si la pausa automática está activada
    </ResponseField>
    <ResponseField name="threshold" type="number">
      Nivel de ancho de banda gratuito para la pausa automática y para la notificación de ancho de banda gratuito
    </ResponseField>
    <ResponseField name="stop_after_transfer" type="boolean">
      Si la siguiente transferencia del token de la suscripción la pausa
    </ResponseField>
    <ResponseField name="notify_free_bw" type="boolean">
      Si te avisamos cuando el ancho de banda gratuito de la dirección se recupera hasta `threshold`
    </ResponseField>
    <ResponseField name="status" type="string">
      `active`, `free_bw`, `paused` o `stopped_balance` — ver [Estado](/es/api-reference/auto-bandwidth/overview#estado)
    </ResponseField>
    <ResponseField name="stopped_reason" type="string | null">
      `insufficient_balance`, `transfer` o `admin`; `null` cuando no hay ninguno
    </ResponseField>
    <ResponseField name="address_change_to" type="string | null">
      La nueva dirección mientras hay un cambio en curso; `null` en caso contrario
    </ResponseField>
    <ResponseField name="free_bw" type="number | null">
      Ancho de banda gratuito de la dirección en la última comprobación. `null` antes de la primera comprobación.
    </ResponseField>
    <ResponseField name="delegated_bw" type="number">
      Ancho de banda que tenemos delegado ahora mismo a la dirección; `0` cuando no hay ninguno
    </ResponseField>
    <ResponseField name="transfers" type="number">
      Transferencias cubiertas hasta ahora — delegaciones que se agotaron y se renovaron
    </ResponseField>
    <ResponseField name="delivery_state" type="string">
      `ok`, `waiting_stake` o `failed` — ver [Estado](/es/api-reference/auto-bandwidth/overview#estado)
    </ResponseField>
    <ResponseField name="paid_until" type="string | null">
      Fin de las 24 horas pagadas (ISO 8601, UTC). `null` si todavía no se ha pagado ningún día.
    </ResponseField>
    <ResponseField name="total_charged_trx" type="string">
      TRX cobrados por esta suscripción, en total
    </ResponseField>
    <ResponseField name="daily_trx" type="string | null">
      Comisión actual cada 24 horas. `null` si el precio no está disponible temporalmente.
    </ResponseField>
    <ResponseField name="transfer_trx" type="string | null">
      Comisión actual por transferencia: `transfer_bw_trx` + `transfer_fee_trx`. `null` si el precio no está disponible temporalmente.
    </ResponseField>
    <ResponseField name="transfer_bw_trx" type="string | null">
      La parte de ancho de banda de la comisión por transferencia
    </ResponseField>
    <ResponseField name="transfer_fee_trx" type="string | null">
      La parte de comisión fija de la comisión por transferencia
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Cuándo se creó la suscripción (ISO 8601, UTC)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="balance_trx" type="string">
  El saldo de tu cuenta
</ResponseField>

<ResponseField name="enabled" type="boolean">
  `false` mientras Bandwidth automático está desactivado temporalmente: crear una suscripción o activar una devuelve entonces `503 AUTO_BW_DISABLED`
</ResponseField>

Los precios de una suscripción son los de esa suscripción: calculados según la clave API con la que se creó, o como una compra en el sitio web.
