## Quitar contrato de token

Quita un contrato de tu lista de tokens. Un contrato que todavía usa alguna de tus suscripciones no se puede quitar: cambia antes el `token` o el `contract` de esa suscripción, o elimínala. Requiere el alcance `buy_bandwidth`.

### Parámetros de ruta

<ParamField path="address" type="string" required>
  Dirección del contrato que se quitará
</ParamField>

### Respuesta

<ResponseField name="address" type="string">
  La dirección del contrato quitado
</ResponseField>

<ResponseField name="deleted" type="boolean">
  Siempre `true`
</ResponseField>

### Ejemplo

<CodeGroup>
```bash cURL
curl -X DELETE https://api.tronrental.com/v1/bandwidth/auto/contracts/TYourTokenContract1234567890abcdef \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.delete(
    "https://api.tronrental.com/v1/bandwidth/auto/contracts/TYourTokenContract1234567890abcdef",
    headers={"X-API-Key": "your_api_key"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch(
  "https://api.tronrental.com/v1/bandwidth/auto/contracts/TYourTokenContract1234567890abcdef",
  { method: "DELETE", headers: { "X-API-Key": "your_api_key" } },
);
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "address": "TYourTokenContract1234567890abcdef",
  "deleted": true
}
```

### Errores

| Estado | Código | Cuándo |
|--------|--------|--------|
| `400` | `INVALID_ADDRESS` | `address` no es una dirección TRON válida |
| `403` | `FORBIDDEN` | La clave API carece del alcance `buy_bandwidth` |
| `404` | `NOT_FOUND` | Este contrato no está en tu lista |
| `409` | `AUTO_BW_CONTRACT_IN_USE` | Hay una suscripción configurada para este contrato |
