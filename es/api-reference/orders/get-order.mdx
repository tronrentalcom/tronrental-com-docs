## Obtener orden

Devuelve el estado actual y los detalles completos de una orden de energía o ancho de banda.

### Parámetros de ruta

<ParamField path="order_id" type="number" required>
  ID de la orden — el `id` devuelto por Buy Energy o Buy Bandwidth.
</ParamField>

### Respuesta

Devuelve el objeto completo de la orden, incluyendo `status`, `type`, `volume`, `price_trx`, `delegate_txid` y marcas de tiempo.

<ResponseField name="activation_id" type="number | null">
  ID de la activacion de direccion que pago este pedido, o `null` si no pago ninguna.
</ResponseField>

<ResponseField name="activation_cost_trx" type="string | null">
  Cuanto costo esa activacion, en TRX, **por encima** de `price_trx`: es la diferencia entre el precio del pedido y el importe que salio de tu saldo.
</ResponseField>

<Note>
**`null`, no `"0"`.** Ambos campos son `null` cuando el pedido no pago ninguna activacion: la cuenta destinataria ya existia o la creo la transaccion de otra persona. Ojo con la diferencia respecto a `activation_cost_trx` en la respuesta de Buy Energy, que en ese caso es la cadena `"0"`: comparar con `"0"` aqui no coincidiria nunca.
</Note>

### Estados de la orden

| Estado | Descripción |
|--------|-------------|
| `pending` | Orden recibida, delegación en curso |
| `filled` | Energía o ancho de banda delegados correctamente |
| `failed` | La delegación falló |
| `reclaimed` | Ancho de banda devuelto tras el período de alquiler (solo órdenes de ancho de banda) |

### Ejemplo

```bash
curl https://api.tronrental.com/v1/orders/12345 \
  -H "X-API-Key: your_api_key"
```
