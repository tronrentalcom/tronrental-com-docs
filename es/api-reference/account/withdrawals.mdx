## Crear retiro

<div>
  `POST /api/v1/account/withdrawal`
</div>

Retira TRX a cualquier direccion TRON. Comision: 1 TRX.

### Cuerpo de la solicitud

<ParamField body="to_address" type="string" required>
  Direccion TRON de destino
</ParamField>

<ParamField body="amount_trx" type="string" required>
  Monto a retirar en TRX
</ParamField>

<ParamField body="currency" type="string">
  `TRX` (predeterminado) o `USDT`. Con `USDT`, `amount_trx` lleva el importe en USDT a enviar.
</ParamField>

<ParamField body="totp_code" type="string">
  Codigo 2FA (si la autenticacion de dos factores esta habilitada)
</ParamField>

### Encabezados

<ParamField header="Idempotency-Key" type="string">
  Opcional, hasta 64 caracteres. Envía una clave nueva (un UUID, por ejemplo) con cada retiro nuevo y la misma clave cuando repitas una solicitud cuya respuesta no recibiste: la repetición devuelve el primer retiro en lugar de crear un segundo.
</ParamField>

### Reintentos seguros

- La misma clave con los mismos `to_address`, `amount_trx` y `currency` devuelve `200` con el retiro que creó la primera solicitud, en su estado actual. No se cobra dos veces.
- La misma clave con otro cuerpo se rechaza con `422` y el código `IDEMPOTENCY_KEY_REUSED`; una clave de más de 64 caracteres, con `422` y `IDEMPOTENCY_KEY_TOO_LONG`. Las claves son propias de tu cuenta y no caducan: nunca reutilices una para otro retiro.
- Un solo retiro sin completar (`pending`, `scheduled` o `processing`) a la vez: otra solicitud mientras exista recibe `400` con `You already have a pending withdrawal`.
- Tras un retiro creado con `Idempotency-Key`, el siguiente puede crearse a los 5 segundos; sin el encabezado la pausa sigue siendo de 60 segundos (`429`, consulta [Límites de solicitudes](/resources/rate-limits)).

### Ejemplo

```bash
curl -X POST https://api.tronrental.com/v1/account/withdrawal \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 7f9c2b1e-5d4a-4c1e-9b3f-2a6d8e0c4f11" \
  -d '{
    "to_address": "TDestinationAddress...",
    "amount_trx": "100"
  }'
```

```json Response
{
  "id": 56,
  "to_address": "TDestinationAddress...",
  "amount_trx": "100.00",
  "fee_trx": "1.00",
  "status": "completed",
  "tx_hash": "a1b2c3d4e5f6...",
  "created_at": "2026-03-05T12:00:00Z"
}
```

## Listar retiros

<div>
  `GET /api/v1/account/withdrawals`
</div>

Devuelve tu historial de retiros.

```bash
curl https://api.tronrental.com/v1/account/withdrawals \
  -H "X-API-Key: your_api_key"
```

```json Response
[
  {
    "id": 56,
    "to_address": "TDestinationAddress...",
    "amount_trx": "100.00",
    "fee_trx": "1.00",
    "status": "completed",
    "tx_hash": "a1b2c3d4e5f6...",
    "created_at": "2026-03-05T12:00:00Z"
  }
]
```

### Estados del retiro

| Estado | Descripcion |
|--------|-------------|
| `pending` | En cola para procesamiento |
| `completed` | TRX enviado, tx_hash disponible |
| `failed` | Fallido, monto reembolsado |
| `scheduled` | Creado desde el panel web; espera una ventana de cancelación de 20 segundos antes del envío |
| `processing` | Enviándose a la red |
| `cancelled` | Cancelado por el usuario dentro de la ventana de cancelación; importe devuelto |

Los retiros creados con clave API se envían de inmediato y nunca pasan por `scheduled`. Las filas creadas en el panel web incluyen `execute_after`: el momento del envío, salvo cancelación previa.

### Bloqueo de seguridad tras cambiar el correo electrónico

Durante las 24 horas siguientes al cambio del correo electrónico de la cuenta, la creación de retiros se rechaza con `403` y el código de error `WITHDRAWAL_EMAIL_COOLDOWN`. La respuesta incluye `retry_after_seconds`: el tiempo restante hasta que los retiros se desbloqueen:

```json Response
{
  "detail": {
    "error": {
      "code": "WITHDRAWAL_EMAIL_COOLDOWN",
      "message": "Withdrawals are temporarily blocked after an email change",
      "retry_after_seconds": 79214
    }
  }
}
```

Este bloqueo se aplica a todos los tipos de sesión, incluidas las claves API con el permiso `withdraw`. Si usted no cambió el correo electrónico de la cuenta, contacte con el soporte de inmediato.
