## Historial de saldo

Devuelve todos los movimientos del saldo de tu cuenta, los mas recientes primero: compras, depositos, reembolsos y comisiones en una sola lista. Los pedidos, las facturas y las activaciones muestran cada uno solo su parte, por lo que este es el unico endpoint donde la aritmetica cuadra: la suma de `delta_trx` en un periodo equivale al cambio de saldo en ese mismo periodo.

<Note>
**Sobre los scopes.** El scope `view` devuelve compras, reembolsos y comisiones. Los movimientos de deposito requieren ademas el scope `deposit_view` y los retiros requieren `withdraw`; sin ellos esas filas simplemente no aparecen en la lista ni en `total`, y filtrar por ese motivo devuelve una pagina vacia, no un error.
</Note>

### Parametros de consulta

<ParamField query="page" type="number" default="1">
  Numero de pagina, empezando en 1.
</ParamField>

<ParamField query="page_size" type="number" default="50">
  Elementos por pagina (maximo 100).
</ParamField>

<ParamField query="reason" type="string">
  Devolver solo movimientos con este motivo exacto, por ejemplo `energy_order`.
</ParamField>

### Respuesta

<ResponseField name="items" type="array">
  <Expandable title="item">
    <ResponseField name="id" type="number">
      ID del movimiento. Tambien es la clave de orden: la lista va de mayor a menor.
    </ResponseField>
    <ResponseField name="delta_trx" type="string">
      Importe en TRX con signo: negativo es cargo, positivo es ingreso.
    </ResponseField>
    <ResponseField name="balance_after" type="string">
      Tu saldo inmediatamente despues de este movimiento.
    </ResponseField>
    <ResponseField name="reason" type="string">
      Para que fue el movimiento (ver abajo). Con el tiempo pueden aparecer motivos nuevos: trata un valor desconocido como opaco en lugar de fallar.
    </ResponseField>
    <ResponseField name="ref_type" type="string | null">
      Entidad que se pago: `order`, `invoice`, `activation`, `deposit`, etc. `null` si no referencia nada.
    </ResponseField>
    <ResponseField name="ref_id" type="string | null">
      ID de esa entidad, como cadena.
    </ResponseField>
    <ResponseField name="ref_address" type="string | null">
      Direccion de destino de esa entidad, cuando la tiene, para no necesitar una segunda peticion. `null` en caso contrario.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Cuando ocurrio el movimiento (UTC).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">
  Numero total de movimientos que cumplen el filtro.
</ResponseField>

<ResponseField name="page" type="number">
  Numero de pagina, empezando en 1.
</ResponseField>

<ResponseField name="page_size" type="number">
  Elementos por pagina (maximo 100).
</ResponseField>

### Motivos frecuentes

| Motivo | Significado |
|------|------|
| `energy_order` | Compra de energia |
| `bw_order` | Compra de bandwidth |
| `energy_order_refund` | Reembolso de un pedido de energia |
| `bw_order_refund` | Reembolso de un pedido de bandwidth |
| `activation` | Creacion de la cuenta destinataria en la red |
| `activation_refund` | Reembolso de una activacion que no ocurrio |
| `deposit` | Deposito entrante |

### Ejemplo

```bash
curl "https://api.tronrental.com/v1/account/history?page=1&page_size=50" \
  -H "X-API-Key: your_api_key"
```
