## Alternar suscripcion

Pausa una suscripcion activa o reanuda una pausada. Mientras esta pausada, no se cobran tarifas y las transferencias no se monitorean.

### Parametros de ruta

<ParamField path="sub_id" type="number" required>
  ID de la suscripcion
</ParamField>

### Respuesta

Devuelve `paused`: el estado de la suscripcion despues del cambio — `true` si ahora esta pausada, `false` si vuelve a estar activa. El mismo campo esta en cada suscripcion de [Listar suscripciones](/es/api-reference/smart-mode/list-subscriptions).

### Ejemplo

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "paused": true
}
```
