## Comprar bandwidth

Delega bandwidth a la dirección TRON especificada. El costo se deduce del saldo de su cuenta.

### Cuerpo de la solicitud

<ParamField body="target_address" type="string" required>
  Dirección TRON de destino (formato T..., 34 caracteres)
</ParamField>

<ParamField body="volume" type="number" required>
  Cantidad de bandwidth a delegar (mín. 1, máx. 100,000)
</ParamField>

<ParamField body="duration" type="string" required>
  Duración del alquiler, uno de estos valores:

  - `"1h"` — 1 hora
  - `"1d"` — 24 horas
  - `"5m"` … `"59m"` — cualquier número entero de minutos de 5 a 59, a la tarifa por hora con descuento (ver [Precios](#precios))

  Escriba los minutos como un número sin cero a la izquierda, seguido de una `m` minúscula: `"5m"`, `"30m"`. `"05m"`, `"5M"`,
  `"60m"` o `"90m"` se rechazan con `400 INVALID_DURATION`: una hora es `"1h"`, y no hay
  nada entre `"1h"` y `"1d"`. Use `"1d"`, no `"24h"` ni valores numéricos de horas.
</ParamField>

<ParamField body="max_price_trx" type="string">
  Opcional. Lo máximo que acepta pagar por este pedido, en TRX — alquiler y comisión fija juntos. Si el
  pedido costara más, se rechaza con `409 PRICE_CHANGED` y **no se cobra nada**. Pase el
  `total_trx` de [Calcular precio de bandwidth](/es/api-reference/bandwidth/quote). Una cadena decimal como
  `"0.58"` (también se acepta un número JSON), mayor que 0. Sin él, el pedido se compra al
  precio actual, como hasta ahora.
</ParamField>

### Cabeceras

<ParamField header="Idempotency-Key" type="string">
  Opcional, hasta 64 caracteres. Un reintento con la misma clave y el mismo cuerpo devuelve el pedido
  original en lugar de comprar de nuevo. Tras un pedido exitoso, la misma clave con otro cuerpo —
  incluido un `max_price_trx` distinto — devuelve `422 IDEMPOTENCY_KEY_REUSED`. Tras un rechazo que
  no cobró nada, como `409 PRICE_CHANGED` o `402 INSUFFICIENT_BALANCE`, la clave vuelve a quedar libre:
  reintente con ella y el nuevo precio.
</ParamField>

### Respuesta

<ResponseField name="id" type="number">
  Identificador único del pedido
</ResponseField>

<ResponseField name="status" type="string">
  Estado del pedido: `pending`, `filled`, `failed`
</ResponseField>

<ResponseField name="txid" type="string | null">
  ID de transacción on-chain tras el broadcast de la delegación (null mientras `pending`)
</ResponseField>

<ResponseField name="price_trx" type="string">
  Costo total del pedido cargado al saldo, en TRX — alquiler y comisión fija
</ResponseField>

<ResponseField name="reclaim_at" type="string | null">
  Marca de tiempo ISO 8601 cuando se recupera el bandwidth alquilado
</ResponseField>

<ResponseField name="activation_cost_trx" type="string">
  Lo que se cobra por activar `target_address` on-chain si aún no estaba activada, además de
  `price_trx`. `"0"` para una dirección que ya está activa.
</ResponseField>

### Precios

`1h` y `1d`: precio = `volume × price_sun / 1,000,000` + comisión fija (0.2 TRX salvo que su cuenta tenga
una comisión propia), donde `price_sun` es
`price_sun_1h` o `price_sun_1d` de [Obtener precios de bandwidth](/es/api-reference/bandwidth/get-prices), o
su tarifa negociada si su cuenta tiene una.

`5m` … `59m`: la tarifa por hora (`price_sun_1h`, o su tarifa por hora negociada) con descuento. El
descuento es máximo en 5 minutos y baja linealmente hasta cero en 59 minutos:

```text
discount % = short_max_discount_pct × (59 − minutes) / 54
price_sun  = hourly price_sun × (1 − discount % / 100)
```

El descuento se aplica solo al alquiler — la comisión fija es la misma para cualquier duración. El alquiler
de un plazo en minutos se redondea al SUN más cercano (0.000001 TRX), con las mitades hacia arriba. El `short_max_discount_pct` actual está en
[Obtener precios de bandwidth](/es/api-reference/bandwidth/get-prices).

| Duración | Descuento cuando `short_max_discount_pct` es 5 | Tarifa cuando `price_sun_1h` es 400 |
|---|---|---|
| `5m` | 5% | 380 SUN |
| `17m` | ≈ 3.89% | ≈ 384.44 SUN |
| `32m` | 2.5% | 390 SUN |
| `45m` | ≈ 1.3% | ≈ 394.81 SUN |
| `59m` | 0% | 400 SUN |

No necesita calcular nada de esto: [Calcular precio de bandwidth](/es/api-reference/bandwidth/quote) devuelve
el importe exacto para su volumen, duración y cuenta.

### Mostrar el precio y comprar a ese precio

1. Llame a `GET /v1/bandwidth/quote` con su `X-API-Key` y muestre `total_trx` a su usuario.
2. Llame a `POST /v1/bandwidth/buy` con `max_price_trx` igual a ese `total_trx`.

La cotización se calcula con el mismo código que cobra el pedido, así que mientras el precio no cambie
el pedido cuesta exactamente `total_trx`. Si el precio cambió entre medias, la compra se rechaza con
`409 PRICE_CHANGED` antes de cobrar nada: obtenga una nueva cotización, muéstrela y reintente — con la misma
`Idempotency-Key`, si usa una.

<Warning>
  `max_price_trx` cubre solo el pedido de bandwidth. Si `target_address` aún no está activada on-chain,
  la activación se cobra aparte (`activation_cost_trx`) y no se compara con
  `max_price_trx`.
</Warning>

### Ejemplo: cotizar y luego comprar por 5 minutos

<CodeGroup>
```bash cURL
# 1. The exact price — show total_trx to your user
curl "https://api.tronrental.com/v1/bandwidth/quote?volume=1000&duration=5m" \
  -H "X-API-Key: your_api_key"

# 2. Buy, refusing any price above the quoted total_trx
curl -X POST https://api.tronrental.com/v1/bandwidth/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "target_address": "TYourRecipientAddress1234567890abc",
    "volume": 1000,
    "duration": "5m",
    "max_price_trx": "0.580000"
  }'
```

```python Python
import requests

API = "https://api.tronrental.com/v1"
HEADERS = {"X-API-Key": "your_api_key"}
order = {"target_address": "TYourRecipientAddress1234567890abc", "volume": 1000, "duration": "5m"}

quote = requests.get(
    f"{API}/bandwidth/quote",
    params={"volume": order["volume"], "duration": order["duration"]},
    headers=HEADERS,
).json()
print("Price:", quote["total_trx"], "TRX")

resp = requests.post(
    f"{API}/bandwidth/buy",
    headers=HEADERS,
    json={**order, "max_price_trx": quote["total_trx"]},
)
if resp.status_code == 409 and resp.json()["detail"]["error"]["code"] == "PRICE_CHANGED":
    print("The price changed and nothing was charged: quote again and retry")
else:
    print(resp.json())
```

```javascript JavaScript
const API = "https://api.tronrental.com/v1";
const headers = { "X-API-Key": "your_api_key" };
const order = { target_address: "TYourRecipientAddress1234567890abc", volume: 1000, duration: "5m" };

const quote = await (
  await fetch(`${API}/bandwidth/quote?volume=${order.volume}&duration=${order.duration}`, { headers })
).json();
console.log("Price:", quote.total_trx, "TRX");

const resp = await fetch(`${API}/bandwidth/buy`, {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({ ...order, max_price_trx: quote.total_trx }),
});
const body = await resp.json();
if (resp.status === 409 && body.detail?.error?.code === "PRICE_CHANGED") {
  console.log("The price changed and nothing was charged: quote again and retry");
} else {
  console.log(body);
}
```

### Errores

| Código | Significado |
|------|---------|
| `400 INVALID_DURATION` | `duration` no es `1h`, `1d` ni `5m` … `59m` |
| `400 INVALID_VOLUME` | Volumen fuera de 1–100,000 |
| `402 INSUFFICIENT_BALANCE` | Saldo insuficiente para el pedido. No se cobró nada |
| `409 PRICE_CHANGED` | El pedido cuesta más que `max_price_trx`. No se cobró nada; el mensaje incluye el precio actual |
| `422 IDEMPOTENCY_KEY_REUSED` | La `Idempotency-Key` ya compró un pedido con otro cuerpo |

Un `max_price_trx` de 0, un número negativo o un valor no numérico es un error de validación `422` en el
formato propio del framework. Los demás códigos se listan en [Errores](/es/errors).
