## ¿Qué es MCP?

[Model Context Protocol (MCP)](https://modelcontextprotocol.io) es un estándar abierto que permite a los agentes de IA (Claude Code, Cursor, Windsurf y otros) interactuar con servicios externos a través de una interfaz unificada.

TronRental proporciona un servidor MCP oficial que da a los agentes de IA acceso completo a la API de compra de energía — desde consultar precios hasta completar compras.

## Servidor remoto (iniciar sesión con TronRental)

La forma principal de conectarse. El agente trabaja con `https://mcp.tronrental.com/mcp`; inicias sesión con TronRental y eliges qué puede hacer y cuánto puede gastar al día. No hay que copiar ninguna clave API. Detalles: [OAuth para agentes](/es/resources/oauth-for-agents).

**Claude (web / desktop):** [Añadir a Claude](https://claude.ai/new?modal=add-custom-connector&connectorName=TronRental&connectorUrl=https%3A%2F%2Fmcp.tronrental.com%2Fmcp#settings/customize-connectors) — o Settings → Connectors → Add custom connector con la URL de arriba. Después Connect e inicia sesión.

**ChatGPT (web):** Plugins → Add → Add Custom MCP Server → pega la URL → deja Authentication en OAuth → crea → inicia sesión con TronRental. Si no aparece, activa el modo desarrollador en Ajustes.

```bash Claude Code
claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp
# then: /mcp → tronrental → Authenticate
```

```bash Codex
codex mcp add tronrental --url https://mcp.tronrental.com/mcp
# if the browser does not open: codex mcp login tronrental
```

```json Cursor (~/.cursor/mcp.json)
{ "mcpServers": { "tronrental": { "url": "https://mcp.tronrental.com/mcp" } } }
```

El servidor muestra solo las herramientas que permite tu conexión. Antes de comprar, el agente consulta el precio y lo pasa como `max_price_trx`, y envía un `idempotency_key` para que un reintento nunca cobre dos veces.

Guía para agentes: [tronrental.com/skill.md](https://tronrental.com/skill.md).

## Paquete local (clave API)

Añade a tu agente de IA:

```bash
npx -y @tronrental-com/mcp-server
```

### Claude Code

```bash
# Sin clave API (el agente registra una cuenta con tu email)
claude mcp add tronrental -- npx -y @tronrental-com/mcp-server

# Con clave API
claude mcp add tronrental -e TRONRENTAL_API_KEY=your_key -- npx -y @tronrental-com/mcp-server
```

### Cursor / Windsurf

Añade a tu configuración de MCP:

```json
{
  "mcpServers": {
    "tronrental": {
      "command": "npx",
      "args": ["-y", "@tronrental-com/mcp-server"],
      "env": {
        "TRONRENTAL_API_KEY": "your_key"  // pragma: allowlist secret
      }
    }
  }
}
```

La variable de entorno `TRONRENTAL_API_KEY` es opcional. Si no se proporciona, el agente puede registrar una nueva cuenta a través de las herramientas MCP y trabajar con su token de inicio de sesión; la clave API se emite cuando las recargas de la cuenta suman 100 TRX. El agente te pide tu email: TronRental envía allí un código de 6 dígitos, y la cuenta solo se crea después de que le des ese código al agente.

## Herramientas disponibles

El servidor MCP proporciona 12 herramientas:

| Herramienta | Autenticación | Descripción |
|-------------|---------------|-------------|
| `get_prices` | Ninguna | Precios actuales de energía y bandwidth |
| `calculate_savings` | Ninguna | Calcular ahorro: coste de quemado vs coste de alquiler |
| `register` | Ninguna | Iniciar el registro: envía un código de 6 dígitos al email del usuario |
| `verify_email_code` | Ninguna | Confirmar el código y crear la cuenta |
| `resend_email_code` | Ninguna | Enviar un código nuevo (si caducó o no llegó) |
| `login` | Ninguna | Iniciar sesión en una cuenta existente |
| `create_api_key` | Token | Crear una clave API (tras recargas de 100 TRX en total) |
| `get_deposit_address` | Clave API o token | Obtener dirección de depósito de TRX |
| `get_balance` | Clave API o token | Consultar saldo de la cuenta |
| `buy_energy` | Clave API o token | Comprar energía para una dirección TRON |
| `get_order` | Clave API o token | Consultar estado del pedido |
| `regenerate_deposit_address` | Clave API o token | Generar una nueva dirección de depósito |

## Flujo típico

### Nuevo usuario (sin clave API)

1. `get_prices` — mostrar precios actuales
2. `calculate_savings` — calcular ahorro para el volumen de transferencias del usuario
3. `register` — el email real del usuario y una contraseña; allí se envía un código de 6 dígitos
4. El usuario lee el código en el correo y se lo da al agente
5. `verify_email_code` — crea la cuenta e inicia sesión
6. `get_deposit_address` — obtener dirección de depósito, el usuario envía TRX o USDT
7. `get_balance` — verificar que el depósito llegó
8. `buy_energy` — comprar energía
9. `get_order` — confirmar delegación
10. `create_api_key` — cuando las recargas sumen 100 TRX: la clave mantiene el acceso después de la sesión (configúrala como `TRONRENTAL_API_KEY`)

<Note>
  El agente nunca inventa una dirección de email: sin un código de una bandeja de entrada real no se crea ninguna cuenta. El código es válido durante 10 minutos; `resend_email_code` envía uno nuevo (hasta 3 correos por hora). Mientras no haya clave, las herramientas usan el token de inicio de sesión; vale 1 hora, y después el agente vuelve a llamar a `login`. Por debajo de 100 TRX, `create_api_key` indica cuánto falta recargar. Los mismos pasos mediante HTTP simple se describen en [Autenticación](/es/authentication).
</Note>

### Usuario existente (clave API configurada)

1. `get_balance` — consultar saldo
2. `buy_energy` — comprar energía
3. `get_order` — confirmar delegación

## Cantidades de energía

| Escenario | Energía |
|-----------|---------|
| El destinatario ya tiene USDT | 65,000 |
| El destinatario nunca tuvo USDT | 131,000 |
| Pedido mínimo | 1 |
| Pedido máximo | 5,000,000 |

La duración es siempre `1h` — la energía se usa en segundos, 1 hora es la ventana de alquiler.
