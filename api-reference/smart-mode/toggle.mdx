## Toggle Subscription

Pauses an active subscription or resumes a paused one. While paused, no fees are charged and transfers are not monitored.

### Path parameters

<ParamField path="sub_id" type="number" required>
  Subscription ID
</ParamField>

### Response

Returns `paused`: the subscription state after the toggle — `true` if it is now paused, `false` if it is active again. The same field is in every subscription in [List Subscriptions](/api-reference/smart-mode/list-subscriptions).

### Example

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "paused": true
}
```
