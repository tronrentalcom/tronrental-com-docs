## Restore Wallet

Brings your account's archived packages on the address back to the main list. The packages themselves do not change.

### Request body

<ParamField body="address" type="string" required>
  TRON address whose archived packages to bring back
</ParamField>

### Response

<ResponseField name="address" type="string">
  The address from the request.
</ResponseField>

<ResponseField name="archived" type="boolean">
  Always `false`.
</ResponseField>

<ResponseField name="packages" type="number">
  How many packages came back; `0` — none were in the archive.
</ResponseField>

### Example

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/restore \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

```json Response
{
  "address": "TYourAddress...",
  "archived": false,
  "packages": 3
}
```

### Errors

Returned in the [standard shape](/errors), under `detail.error.code`. After any of them nothing has changed.

| Code | Status | When |
|------|--------|------|
| `PACKAGE_NOT_FOUND` | `404` | Your account has no package on the address |
