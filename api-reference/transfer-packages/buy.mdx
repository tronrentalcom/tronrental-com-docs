## Buy Transfer Package

Purchases a transfer package using your account balance.

### Request body

<ParamField body="address" type="string" required>
  TRON address to monitor
</ParamField>

<ParamField body="package_size" type="number">
  Number of transfers in the package (2 – 10,000). Required unless `single_transfer` is `true`. `package_size: 1` is rejected with `422` — to buy one transfer, send `single_transfer: true`.
</ParamField>

<ParamField body="single_transfer" type="boolean" default="false">
  Buy one transfer instead of a package; `package_size` is then ignored. Priced at `single_transfer_price` from [Get Tiers](/api-reference/transfer-packages/get-tiers) (BW Guarantee adds `bw_fee_per_transfer`).
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  Enable BW Guarantee
</ParamField>

### Response

Returns `package_id`, `status`, `total_price_trx`, `activation_cost_trx` (TRX spent to activate the address if it was not activated yet, otherwise `0`) and `total_charged_trx`.

### Example

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "package_size": 500,
    "bw_guarantee": true
  }'
```

```json Response
{
  "package_id": 101,
  "status": "active",
  "total_price_trx": "1500.0",
  "activation_cost_trx": "0",
  "total_charged_trx": "1500.0"
}
```

<Info>
  You can also pay via invoice using `POST /api/v1/transfer-packages/buy-invoice` —
  this generates a payment address for TRX/USDT.
</Info>
