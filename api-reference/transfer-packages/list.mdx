## List My Packages

Returns all your transfer packages.

### Response

Array of package objects. Main fields: `id`, `address`, `package_size`, `quota_total` (transfers in the package), `quota_used` (transfers delivered), `subscription_used` (transfers taken by the daily subscription fee, one per day), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `status`, `created_at`.

### Package statuses

| Status | Description |
|--------|-------------|
| `pending_payment` | Awaiting invoice payment |
| `provisioning` | Paid from balance, activation in progress |
| `active` | Monitoring address, transfers available |
| `completed` | All transfers used |
| `cancelled` | Cancelled by user |
| `expired` | Invoice not paid in time |
| `manual_review` | Activation result is unclear; support checks it, the payment is held until then |
| `failed_refunded` | Activation failed; the price was returned to the balance |

### Example

```bash
curl https://api.tronrental.com/v1/transfer-packages/my \
  -H "X-API-Key: your_api_key"
```
