## List Packages by Page

Returns one page of your transfer packages: the main list, or the archive with `archived=true`. Packages that are not closed — active, paused, awaiting payment or activation — come first, then the newest. This is the list the dashboard shows; [List Packages](/api-reference/transfer-packages/list) still returns every package at once.

### Query parameters

<ParamField query="archived" type="boolean" default="false">
  `true` — the archive (packages moved there with [Archive Wallet](/api-reference/transfer-packages/archive)); `false` (default) — the main list
</ParamField>

<ParamField query="page" type="number">
  Page number (default 1). At most `1000000`.
</ParamField>

<ParamField query="page_size" type="number">
  Packages per page (default 20, max 100)
</ParamField>

### Response

<ResponseField name="packages" type="array">
  Packages of the page — the same objects as in [List Packages](/api-reference/transfer-packages/list), with `label` and `archived_at`.
</ResponseField>

<ResponseField name="total" type="number">
  Packages in the list you asked for, on all pages.
</ResponseField>

<ResponseField name="page" type="number">
  The page from the request.
</ResponseField>

<ResponseField name="page_size" type="number">
  The page size from the request.
</ResponseField>

<ResponseField name="archived_packages" type="number">
  Packages your account has in the archive — whichever list you asked for.
</ResponseField>

<ResponseField name="archived_wallets" type="number">
  Addresses those archived packages are on.
</ResponseField>

### Example

```bash
curl "https://api.tronrental.com/v1/transfer-packages/list?page=1&page_size=20" \
  -H "X-API-Key: your_api_key"
```

### Errors

Returned in the [standard shape](/errors), under `detail.error.code`. After any of them nothing has changed.

| Code | Status | When |
|------|--------|------|
| — | `422` | `page` < 1 or `page_size` outside 1–100 |
