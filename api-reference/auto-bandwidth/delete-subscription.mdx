## Delete Subscription

Deletes a subscription. We stop watching the address and take back the bandwidth we delegated to it, within a few seconds; the address becomes free for a new subscription. A transfer that used our bandwidth before the deletion is still charged. Requires the `buy_bandwidth` scope.

To stop for a while without losing the settings, [pause the subscription](/api-reference/auto-bandwidth/update-subscription) with `enabled: false` instead.

### Path parameters

<ParamField path="sub_id" type="number" required>
  Subscription ID — the `id` from Create or List Subscriptions
</ParamField>

### Response

<ResponseField name="id" type="number">
  The deleted subscription's ID
</ResponseField>

<ResponseField name="status" type="string">
  `deleted`
</ResponseField>

### Example

<CodeGroup>
```bash cURL
curl -X DELETE https://api.tronrental.com/v1/bandwidth/auto/42 \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.delete(
    "https://api.tronrental.com/v1/bandwidth/auto/42",
    headers={"X-API-Key": "your_api_key"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto/42", {
  method: "DELETE",
  headers: { "X-API-Key": "your_api_key" },
});
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "id": 42,
  "status": "deleted"
}
```

### Errors

| Status | Code | When |
|--------|------|------|
| `403` | `FORBIDDEN` | The API key lacks the `buy_bandwidth` scope |
| `404` | `NOT_FOUND` | No subscription with this ID on your account (or it was already deleted) |

```json
{
  "detail": {
    "error": {
      "code": "NOT_FOUND",
      "message": "Auto-Bandwidth subscription not found"
    }
  }
}
```
