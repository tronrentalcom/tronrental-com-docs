## List Token Contracts

Returns the TRC-20 contracts you have added for Auto Bandwidth. A subscription with `token: "CUSTOM"` or `"OWN"` can use any of them in `contract`. Requires the `view` scope.

USDT and USDD are built in and never appear here: choose them with `token`.

### Response

<ResponseField name="contracts" type="array">
  Your contracts.

  <Expandable title="contract object">
    <ResponseField name="address" type="string">
      Contract address
    </ResponseField>
    <ResponseField name="symbol" type="string">
      Token symbol, as the contract reports it (up to 16 characters)
    </ResponseField>
    <ResponseField name="name" type="string | null">
      Token name, as the contract reports it (up to 40 characters); `null` if it has none
    </ResponseField>
    <ResponseField name="decimals" type="number">
      Token decimals
    </ResponseField>
    <ResponseField name="bandwidth" type="number">
      Bandwidth one transfer of this token takes — a guide for the subscription `volume`
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
`symbol` and `name` come from the contract itself, and anyone can deploy a token that calls itself "Tether USD". Always identify a token by its `address`.
</Warning>
