## Add Token Contract

Adds a TRC-20 contract to your token list, so that a subscription can use it with `token: "CUSTOM"` or `"OWN"`. We ask the network whether the address is a TRC-20 token whose transfers go through, and read its symbol, name, decimals and how much bandwidth one transfer takes. Requires the `buy_bandwidth` scope.

Adding a contract that is already in your list returns it again, without a new check and without counting towards the request limit.

### Request body

<ParamField body="address" type="string" required>
  Address of the TRC-20 contract (T... format, 34 characters). USDT and USDD are rejected — choose them with `token`.
</ParamField>

### Response

The contract, with the same fields as in [List Token Contracts](/api-reference/auto-bandwidth/list-contracts). Use `bandwidth` as a guide for the subscription `volume`, with a small margin.

### Example

<CodeGroup>
```bash cURL
curl -X POST https://api.tronrental.com/v1/bandwidth/auto/contracts \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"address": "TYourTokenContract1234567890abcdef"}'
```

```python Python
import requests

resp = requests.post(
    "https://api.tronrental.com/v1/bandwidth/auto/contracts",
    headers={"X-API-Key": "your_api_key"},
    json={"address": "TYourTokenContract1234567890abcdef"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto/contracts", {
  method: "POST",
  headers: { "X-API-Key": "your_api_key", "Content-Type": "application/json" },
  body: JSON.stringify({ address: "TYourTokenContract1234567890abcdef" }),
});
console.log(await resp.json());
```
</CodeGroup>

### Errors

| Status | Code | When |
|--------|------|------|
| `400` | `INVALID_ADDRESS` | `address` is not a valid TRON address |
| `400` | `AUTO_BW_NOT_A_CONTRACT` | There is no smart contract at this address |
| `400` | `AUTO_BW_NOT_A_TOKEN` | The contract is not a TRC-20 token |
| `400` | `AUTO_BW_TRANSFER_REVERTS` | A transfer of this token fails in simulation — for example, the token is paused |
| `403` | `FORBIDDEN` | The API key lacks the `buy_bandwidth` scope |
| `409` | `AUTO_BW_CONTRACT_LISTED` | This is USDT or USDD — choose it with `token`; the token is in `error.token` |
| `409` | `AUTO_BW_CONTRACT_LIMIT` | Your list already has 20 contracts — remove one first |
| `429` | `RATE_LIMIT_EXCEEDED` | Too many new contracts — see [Rate Limits](/resources/rate-limits) |
| `503` | `AUTO_BW_DISABLED` | Auto Bandwidth is temporarily switched off — try again later |
| `503` | `TEMPORARILY_UNAVAILABLE` | The network could not be read right now; nothing was saved — retry after the `Retry-After` seconds |
