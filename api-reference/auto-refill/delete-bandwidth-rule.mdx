## Delete Bandwidth Rule

Deletes a rule. No more refills are made for it, and the address becomes free for a new bandwidth rule. Bandwidth already bought is not taken back: those rentals run until the end of their term. Past refill orders stay in your order history. Requires the `buy_bandwidth` scope.

To stop refills for a while without losing the rule, [pause it](/api-reference/auto-refill/update-bandwidth-rule) instead.

### Path parameters

<ParamField path="rule_id" type="number" required>
  Rule ID — the `id` from Create or List Bandwidth Rules
</ParamField>

### Response

<ResponseField name="status" type="string">
  `ok`
</ResponseField>

### Example

<CodeGroup>
```bash cURL
curl -X DELETE https://api.tronrental.com/v1/bandwidth/auto-refill/15 \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.delete(
    "https://api.tronrental.com/v1/bandwidth/auto-refill/15",
    headers={"X-API-Key": "your_api_key"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto-refill/15", {
  method: "DELETE",
  headers: { "X-API-Key": "your_api_key" },
});
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "status": "ok"
}
```

### Errors

| Status | Code | When |
|--------|------|------|
| `403` | `FORBIDDEN` | The API key lacks the `buy_bandwidth` scope |
| `404` | `NOT_FOUND` | No bandwidth rule with this ID on your account (or it was already deleted) |
| `409` | `AUTOREFILL_IN_PROGRESS` | A refill for this rule is being bought right now — retry in a minute |

```json
{
  "detail": {
    "error": {
      "code": "NOT_FOUND",
      "message": "Auto-refill rule not found"
    }
  }
}
```
