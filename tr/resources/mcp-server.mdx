## MCP Nedir?

[Model Context Protocol (MCP)](https://modelcontextprotocol.io), AI ajanlarının (Claude Code, Cursor, Windsurf ve diğerleri) birleşik bir arayüz üzerinden harici hizmetlerle etkileşim kurmasını sağlayan açık bir standarttır.

TronRental, AI ajanlarına enerji satın alma API'sine tam erişim sağlayan resmi bir MCP sunucusu sunar — fiyat kontrolünden satın alma işleminin tamamlanmasına kadar.

## Uzak sunucu (TronRental ile giriş)

Bağlanmanın ana yolu. Ajan `https://mcp.tronrental.com/mcp` ile çalışır; TronRental ile giriş yapar, ajanın neler yapabileceğini ve günde ne kadar harcayabileceğini seçersiniz. API anahtarı kopyalanmaz. Ayrıntılar: [Ajanlar için OAuth](/tr/resources/oauth-for-agents).

**Claude (web / desktop):** [Claude'a ekle](https://claude.ai/new?modal=add-custom-connector&connectorName=TronRental&connectorUrl=https%3A%2F%2Fmcp.tronrental.com%2Fmcp#settings/customize-connectors) — veya yukarıdaki adresle Settings → Connectors → Add custom connector. Ardından Connect ve giriş.

**ChatGPT (web):** Plugins → Add → Add Custom MCP Server → adresi yapıştırın → Authentication'ı OAuth'ta bırakın → oluşturun → TronRental ile giriş yapın. Öğe yoksa Ayarlar'dan geliştirici modunu açın.

```bash Claude Code
claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp
# then: /mcp → tronrental → Authenticate
```

```bash Codex
codex mcp add tronrental --url https://mcp.tronrental.com/mcp
# if the browser does not open: codex mcp login tronrental
```

```json Cursor (~/.cursor/mcp.json)
{ "mcpServers": { "tronrental": { "url": "https://mcp.tronrental.com/mcp" } } }
```

Sunucu yalnızca bağlantınızın izin verdiği araçları listeler. Satın almadan önce ajan fiyatı sorar ve `max_price_trx` olarak gönderir; tekrar denemenin asla iki kez ücret almaması için `idempotency_key` de ekler.

Ajanlar için kurulum rehberi: [tronrental.com/skill.md](https://tronrental.com/skill.md).

## Yerel paket (API anahtarı)

AI ajanınıza ekleyin:

```bash
npx -y @tronrental-com/mcp-server
```

### Claude Code

```bash
# API anahtarı olmadan (ajan e-posta adresinizle bir hesap kaydeder)
claude mcp add tronrental -- npx -y @tronrental-com/mcp-server

# API anahtarı ile
claude mcp add tronrental -e TRONRENTAL_API_KEY=your_key -- npx -y @tronrental-com/mcp-server
```

### Cursor / Windsurf

MCP yapılandırmanıza ekleyin:

```json
{
  "mcpServers": {
    "tronrental": {
      "command": "npx",
      "args": ["-y", "@tronrental-com/mcp-server"],
      "env": {
        "TRONRENTAL_API_KEY": "your_key"  // pragma: allowlist secret
      }
    }
  }
}
```

`TRONRENTAL_API_KEY` ortam değişkeni isteğe bağlıdır. Sağlanmazsa, ajan MCP araçları aracılığıyla yeni bir hesap kaydedebilir ve bu hesabın oturum token'ı ile çalışabilir; API anahtarı, hesabın yüklemeleri toplam 100 TRX'e ulaştığında verilir. Ajan e-posta adresinizi sorar: TronRental bu adrese 6 haneli bir kod gönderir ve hesap ancak bu kodu ajana verdikten sonra oluşturulur.

## Mevcut Araçlar

MCP sunucusu 12 araç sunar:

| Araç | Kimlik Doğrulama | Açıklama |
|------|-------------------|----------|
| `get_prices` | Yok | Güncel enerji ve bandwidth fiyatları |
| `calculate_savings` | Yok | Tasarruf hesaplama: yakma maliyeti ve kiralama maliyeti karşılaştırması |
| `register` | Yok | Kaydı başlatma: kullanıcının e-posta adresine 6 haneli kod gönderir |
| `verify_email_code` | Yok | Kodu onaylama ve hesabı oluşturma |
| `resend_email_code` | Yok | Yeni kod gönderme (süresi dolduysa veya ulaşmadıysa) |
| `login` | Yok | Mevcut hesaba giriş |
| `create_api_key` | Token | API anahtarı oluşturma (toplam 100 TRX yüklemeden sonra) |
| `get_deposit_address` | API anahtarı veya token | TRX yatırma adresi alma |
| `get_balance` | API anahtarı veya token | Hesap bakiyesi sorgulama |
| `buy_energy` | API anahtarı veya token | Bir TRON adresi için enerji satın alma |
| `get_order` | API anahtarı veya token | Sipariş durumu sorgulama |
| `regenerate_deposit_address` | API anahtarı veya token | Yeni yatırma adresi oluşturma |

## Tipik Akış

### Yeni kullanıcı (API anahtarı yok)

1. `get_prices` — güncel fiyatları göster
2. `calculate_savings` — kullanıcının transfer hacmi için tasarrufu hesapla
3. `register` — kullanıcının gerçek e-posta adresi ve bir parola; bu adrese 6 haneli bir kod gönderilir
4. Kullanıcı kodu e-postadan okur ve ajana verir
5. `verify_email_code` — hesabı oluşturur ve oturum açar
6. `get_deposit_address` — yatırma adresi al, kullanıcı TRX veya USDT gönderir
7. `get_balance` — yatırımın ulaştığını doğrula
8. `buy_energy` — enerji satın al
9. `get_order` — delegasyonu onayla
10. `create_api_key` — yüklemeler toplam 100 TRX'e ulaşınca: anahtar oturumdan sonra da erişimi korur (`TRONRENTAL_API_KEY` olarak ayarlayın)

<Note>
  Ajan asla e-posta adresi uydurmaz: gerçek bir gelen kutusundan gelen kod olmadan hesap oluşturulmaz. Kod 10 dakika geçerlidir; `resend_email_code` yenisini gönderir (saatte en fazla 3 e-posta). Anahtar olana kadar araçlar oturum token'ını kullanır; token 1 saat geçerlidir, sonra ajan `login` aracını yeniden çağırır. 100 TRX'in altında `create_api_key` ne kadar daha yükleme gerektiğini bildirir. Aynı adımların düz HTTP ile yapılışı [Kimlik Doğrulama](/tr/authentication) sayfasında anlatılır.
</Note>

### Mevcut kullanıcı (API anahtarı ayarlanmış)

1. `get_balance` — bakiye kontrol et
2. `buy_energy` — enerji satın al
3. `get_order` — delegasyonu onayla

## Enerji Miktarları

| Senaryo | Enerji |
|---------|--------|
| Alıcının zaten USDT'si var | 65,000 |
| Alıcı hiç USDT tutmadı | 131,000 |
| Minimum sipariş | 1 |
| Maksimum sipariş | 5,000,000 |

Süre her zaman `1h` — enerji saniyeler içinde kullanılır, 1 saat kiralama penceresidir.
