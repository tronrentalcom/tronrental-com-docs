## Webhook günlüğü

Son teslimat denemeleri, en yenisi üstte — ne gönderdiğimiz ve sunucunuzun ne yanıtladığı.

### Sorgu parametreleri

<ParamField query="page" type="integer">
  Sayfa numarası, `1`'den başlar. Varsayılan `1`.
</ParamField>

<ParamField query="page_size" type="integer">
  Sayfa başına kayıt, `1`–`100`. Varsayılan `50`.
</ParamField>

### Yanıt

Kayıtlardan oluşan bir dizi.

<ResponseField name="id" type="number">
  Günlük kaydının kimliği.
</ResponseField>

<ResponseField name="event_type" type="string">
  Teslim edilen olay, örneğin `order.updated`.
</ResponseField>

<ResponseField name="payload" type="object">
  Gönderilen zarfın aynısı: `event` / `data` / `timestamp` — imzanın hesaplandığı baytların ta kendisi.
</ResponseField>

<ResponseField name="response_status" type="number">
  Sunucunuzun yanıtladığı HTTP durumu. **`0`, hiçbir HTTP yanıtının ulaşmadığı anlamına gelir** — bağlantı, TLS el sıkışması veya okuma başarısız oldu ya da zaman aşımına uğradı.
</ResponseField>

<ResponseField name="attempts" type="number">
  Üç denemeden kaçının yapıldığı. `1`, ilk seferde başarılı olduğunu gösterir.
</ResponseField>

<ResponseField name="created_at" type="string">
  Teslimatın bittiği an, ISO-8601.
</ResponseField>

### Örnek

```bash
curl https://api.tronrental.com/v1/webhooks/logs \
  -H "X-API-Key: your_api_key"
```

<Note>
  Bu günlükle hata ayıklamadan önce bilinmesi gereken iki eksik:

  - Günlük, **API anahtarlarınıza** atfedilen teslimatları listeler; bu nedenle `subscription.transfer` teslimatları gönderilmiş olsalar bile bugün burada görünmez.
  - Çözümleyemediğimiz bir URL ya da özel bir adrese çözümlenen bir URL **hiç satır oluşturmaz** — boş bir günlük, «olay olmadı» ile «adres reddedildi» durumlarını ayırt etmez. Trafik beklediğiniz hâlde hiçbir şey görmüyorsanız URL'yi [Dashboard → API](https://tronrental.com/dashboard/api) sayfasında kontrol edin.
</Note>
