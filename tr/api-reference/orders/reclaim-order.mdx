## Siparişi geri al

Siparişinizin bant genişliği delegasyonunu hemen geri çeker — örneğin adres, kaynağın kiralandığı transferi zaten yaptıysa — sürenin bitmesini beklemeden. **Kullanılmayan süre iade edilmez.** Yalnızca bant genişliği siparişleri erken geri alınabilir.

### Yol parametreleri

<ParamField path="order_id" type="number" required>
  Sipariş kimliği — Buy Bandwidth'in döndürdüğü `id`.
</ParamField>

### Yanıt

Get Order ile aynı şekilde sipariş nesnesini döndürür. `status` ne olduğunu gösterir:

| Durum | Anlamı |
|--------|-------------|
| `reclaimed` | Bant genişliği bu istek içinde geri alındı; `undelegate_txid` zincirdeki işlemdir |
| `filled` | Sipariş bir sonraki geri alma döngüsüne alındı, genellikle 30 saniye içinde. Sonuç `order.updated` webhook'u ile gelir veya Get Order'ı sorgulayın |
| `reclaiming` | Bu siparişin geri alınması zaten sürüyor |
| `reclaim_failed` | Geri alma, tekrar denemelerden sonra bizim tarafımızda gerçekleşmedi. Sizin yapmanız gereken bir şey yok |

Zaten `reclaiming`, `reclaimed` veya `reclaim_failed` durumundaki bir sipariş için tekrar çağrı siparişi değiştirmeden döndürür, bu yüzden tekrar denemek güvenlidir. API anahtarının `buy_bandwidth` yetkisi olmalıdır.

### Hatalar

| Kod | Durum | Ne zaman |
|------|--------|------|
| `ORDER_NOT_FOUND` | `404` | Hesabınızda böyle bir sipariş yok |
| `ORDER_NOT_RECLAIMABLE` | `409` | Sipariş henüz teslim edilmedi (`filled`) veya başarısız oldu |
| `BAD_REQUEST` | `400` | Bant genişliği siparişi değil |
| `FORBIDDEN` | `403` | API anahtarında `buy_bandwidth` yetkisi yok |

### Örnek

```bash
curl -X POST https://api.tronrental.com/v1/orders/12345/reclaim \
  -H "X-API-Key: your_api_key"
```
