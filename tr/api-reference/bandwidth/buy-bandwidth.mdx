## Bandwidth satın al

Belirtilen TRON adresine bandwidth devreder. Maliyet hesap bakiyenizden düşülür.

### İstek gövdesi

<ParamField body="target_address" type="string" required>
  Hedef TRON adresi (T... formatı, 34 karakter)
</ParamField>

<ParamField body="volume" type="number" required>
  Devredilecek bandwidth miktarı (min 1, maks 100.000)
</ParamField>

<ParamField body="duration" type="string" required>
  Kiralama süresi, şunlardan biri:

  - `"1h"` — 1 saat
  - `"1d"` — 24 saat
  - `"5m"` … `"59m"` — 5 ile 59 arasında herhangi bir tam dakika sayısı, saatlik tarifeden indirimli (bkz. [Fiyatlandırma](#fiyatlandırma))

  Dakikaları başında sıfır olmayan bir sayı ve ardından küçük harf `m` olarak yazın: `"5m"`, `"30m"`. `"05m"`, `"5M"`,
  `"60m"` veya `"90m"` `400 INVALID_DURATION` ile reddedilir: bir saat `"1h"` olarak yazılır ve
  `"1h"` ile `"1d"` arasında başka bir süre yoktur. `"24h"` veya sayısal saat değerleri kullanmayın; `"1d"` kullanın.
</ParamField>

<ParamField body="max_price_trx" type="string">
  İsteğe bağlı. Bu sipariş için ödemeyi kabul ettiğiniz en yüksek tutar (TRX) — kiralama ve sabit
  ücret birlikte. Sipariş bundan pahalıya gelecekse `409 PRICE_CHANGED` ile reddedilir ve **hiçbir
  ücret alınmaz**. [Bandwidth fiyatı hesapla](/tr/api-reference/bandwidth/quote) yanıtındaki
  `total_trx` değerini gönderin. `"0.58"` gibi ondalık bir dize (JSON sayısı da kabul edilir), 0'dan
  büyük. Bu alan olmadan sipariş, eskisi gibi güncel fiyattan satın alınır.
</ParamField>

### Başlıklar

<ParamField header="Idempotency-Key" type="string">
  İsteğe bağlı, en fazla 64 karakter. Aynı anahtar ve aynı gövdeyle yapılan tekrar, yeniden satın
  almak yerine ilk siparişi döndürür. Başarılı bir siparişten sonra aynı anahtar farklı bir gövdeyle —
  farklı bir `max_price_trx` dahil — `422 IDEMPOTENCY_KEY_REUSED` döndürür. `409 PRICE_CHANGED` veya
  `402 INSUFFICIENT_BALANCE` gibi hiçbir ücret alınmayan bir retten sonra anahtar yeniden kullanılabilir
  hâle gelir: aynı anahtarla ve yeni fiyatla tekrar deneyin.
</ParamField>

### Yanıt

<ResponseField name="id" type="number">
  Benzersiz sipariş kimliği
</ResponseField>

<ResponseField name="status" type="string">
  Sipariş durumu: `pending`, `filled`, `failed`
</ResponseField>

<ResponseField name="txid" type="string | null">
  Delegasyon yayınlandıktan sonraki on-chain işlem kimliği (`pending` iken null)
</ResponseField>

<ResponseField name="price_trx" type="string">
  Bakiyeden düşülen siparişin toplam maliyeti (TRX) — kiralama ve sabit ücret
</ResponseField>

<ResponseField name="reclaim_at" type="string | null">
  Kiralanan bandwidth geri alındığında ISO 8601 zaman damgası
</ResponseField>

<ResponseField name="activation_cost_trx" type="string">
  `target_address` henüz etkinleştirilmemişse zincirde etkinleştirilmesi için `price_trx` dışında
  ayrıca alınan tutar. Zaten aktif bir adres için `"0"`.
</ResponseField>

### Fiyatlandırma

`1h` ve `1d`: fiyat = `volume × price_sun / 1,000,000` + sabit ücret (hesabınızın kendi ücreti yoksa 0,2 TRX); burada `price_sun`,
[Bandwidth fiyatlarını al](/tr/api-reference/bandwidth/get-prices) yanıtındaki `price_sun_1h` veya
`price_sun_1d` değeridir ya da hesabınızın anlaşmalı bir tarifesi varsa o tarifedir.

`5m` … `59m`: indirimli saatlik tarife (`price_sun_1h` veya anlaşmalı saatlik tarifeniz). İndirim
5 dakikada en büyüktür ve 59 dakikada doğrusal olarak sıfıra iner:

```text
discount % = short_max_discount_pct × (59 − minutes) / 54
price_sun  = hourly price_sun × (1 − discount % / 100)
```

İndirim yalnızca kiralamaya uygulanır — sabit ücret her süre için aynıdır. Dakikalık bir sürenin
kiralama bedeli en yakın SUN'a (0,000001 TRX) yuvarlanır; tam yarımlar yukarı yuvarlanır. Güncel `short_max_discount_pct` değeri
[Bandwidth fiyatlarını al](/tr/api-reference/bandwidth/get-prices) sayfasındadır.

| Süre | `short_max_discount_pct` 5 iken indirim | `price_sun_1h` 400 iken tarife |
|---|---|---|
| `5m` | %5 | 380 SUN |
| `17m` | ≈ %3,89 | ≈ 384,44 SUN |
| `32m` | %2,5 | 390 SUN |
| `45m` | ≈ %1,3 | ≈ 394,81 SUN |
| `59m` | %0 | 400 SUN |

Bunların hiçbirini hesaplamanız gerekmez: [Bandwidth fiyatı hesapla](/tr/api-reference/bandwidth/quote)
miktarınız, süreniz ve hesabınız için tam tutarı döndürür.

### Fiyatı gösterin, sonra o fiyattan satın alın

1. `X-API-Key` anahtarınızla `GET /v1/bandwidth/quote` çağırın ve `total_trx` değerini kullanıcınıza gösterin.
2. `max_price_trx` değerini bu `total_trx` olarak ayarlayıp `POST /v1/bandwidth/buy` çağırın.

Fiyat teklifi, siparişi tahsil eden kodun aynısıyla hesaplanır; bu yüzden fiyat değişmediği sürece
sipariş tam olarak `total_trx` tutarına mal olur. Arada fiyat değiştiyse satın alma, hiçbir ücret
alınmadan `409 PRICE_CHANGED` ile reddedilir: yeni bir fiyat teklifi alın, gösterin ve tekrar
deneyin — kullanıyorsanız aynı `Idempotency-Key` ile.

<Warning>
  `max_price_trx` yalnızca bandwidth siparişini kapsar. `target_address` zincirde henüz
  etkinleştirilmemişse etkinleştirme ücreti ayrıca alınır (`activation_cost_trx`) ve
  `max_price_trx` ile karşılaştırılmaz.
</Warning>

    "target_address": "TYourRecipientAddress1234567890abc",
    "volume": 16000,
    "duration": "1d"
  }'

import requests

resp = requests.post(

### Örnek: fiyat teklifi alın, sonra 5 dakikalığına satın alın

<CodeGroup>
```bash cURL
# 1. The exact price — show total_trx to your user
curl "https://api.tronrental.com/v1/bandwidth/quote?volume=1000&duration=5m" \
  -H "X-API-Key: your_api_key"

# 2. Buy, refusing any price above the quoted total_trx
curl -X POST https://api.tronrental.com/v1/bandwidth/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "target_address": "TYourRecipientAddress1234567890abc",
    "volume": 1000,
    "duration": "5m",
    "max_price_trx": "0.580000"
  }'
```

```python Python
import requests

API = "https://api.tronrental.com/v1"
HEADERS = {"X-API-Key": "your_api_key"}
order = {"target_address": "TYourRecipientAddress1234567890abc", "volume": 1000, "duration": "5m"}

quote = requests.get(
    f"{API}/bandwidth/quote",
    params={"volume": order["volume"], "duration": order["duration"]},
    headers=HEADERS,
).json()
print("Price:", quote["total_trx"], "TRX")

resp = requests.post(
    f"{API}/bandwidth/buy",
    headers=HEADERS,
    json={**order, "max_price_trx": quote["total_trx"]},
)
if resp.status_code == 409 and resp.json()["detail"]["error"]["code"] == "PRICE_CHANGED":
    print("The price changed and nothing was charged: quote again and retry")
else:
    print(resp.json())
```

```javascript JavaScript
const API = "https://api.tronrental.com/v1";
const headers = { "X-API-Key": "your_api_key" };
const order = { target_address: "TYourRecipientAddress1234567890abc", volume: 1000, duration: "5m" };

const quote = await (
  await fetch(`${API}/bandwidth/quote?volume=${order.volume}&duration=${order.duration}`, { headers })
).json();
console.log("Price:", quote.total_trx, "TRX");

const resp = await fetch(`${API}/bandwidth/buy`, {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({ ...order, max_price_trx: quote.total_trx }),
});
const body = await resp.json();
if (resp.status === 409 && body.detail?.error?.code === "PRICE_CHANGED") {
  console.log("The price changed and nothing was charged: quote again and retry");
} else {
  console.log(body);
}
```
</CodeGroup>

```json 409 PRICE_CHANGED

    "error": {

    }
  }
}
```

### Hatalar

| Kod | Anlamı |
|------|---------|
| `400 INVALID_DURATION` | `duration` değeri `1h`, `1d` veya `5m` … `59m` değil |
| `400 INVALID_VOLUME` | Miktar 1–100.000 aralığının dışında |
| `402 INSUFFICIENT_BALANCE` | Sipariş için bakiye yetersiz. Hiçbir ücret alınmadı |
| `409 PRICE_CHANGED` | Sipariş `max_price_trx` değerinden pahalı. Hiçbir ücret alınmadı; mesaj güncel fiyatı içerir |
| `422 IDEMPOTENCY_KEY_REUSED` | Bu `Idempotency-Key` ile farklı bir gövdeyle zaten bir sipariş satın alındı |

0, negatif bir sayı veya sayı olmayan bir `max_price_trx` değeri, çerçevenin kendi biçiminde bir
`422` doğrulama hatasıdır. Diğer kodlar [Hatalar](/tr/errors) sayfasında listelenmiştir.
