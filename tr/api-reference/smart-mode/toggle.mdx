## Aboneligi Degistir

Aktif bir aboneligi duraklatir veya duraklatilmis bir aboneligi devam ettirir. Duraklatilmis durumdayken ucret alinmaz ve transferler izlenmez.

### Yol parametreleri

<ParamField path="sub_id" type="number" required>
  Abonelik kimlik numarasi
</ParamField>

### Yanit

`paused` doner: degisiklikten sonra aboneligin durumu — `true` simdi duraklatildi, `false` yeniden aktif. Ayni alan [Abonelikleri Listele](/tr/api-reference/smart-mode/list-subscriptions) icindeki her abonelikte bulunur.

### Ornek

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "paused": true
}
```
