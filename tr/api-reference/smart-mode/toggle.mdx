## Aboneligi Degistir

Aktif bir aboneligi duraklatir veya duraklatilmis bir aboneligi devam ettirir. Duraklatilmis durumdayken ucret alinmaz ve transferler izlenmez.

### Yol parametreleri

<ParamField path="sub_id" type="number" required>
  Abonelik kimlik numarasi
</ParamField>

### Yanit

`200` yaniti aboneligin duraklatildigi veya devam ettirildigi anlamina gelir. Yanit govdesi API sozlesmesinin parcasi degildir: yeni durumu [Abonelikleri Listele](/tr/api-reference/smart-mode/list-subscriptions) icindeki `paused` alanindan okuyun.

### Ornek

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```
