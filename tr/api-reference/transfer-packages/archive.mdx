## Cüzdanı Arşivle

Hesabınızın adresteki **kapanmış** paketlerini arşive taşır: panel onları ana liste yerine *Arşiv* altında gösterir. Kapanmış olanlar `completed`, `expired`, `cancelled` ve `failed_refunded` durumundakilerdir; aktif, duraklatılmış, ödeme veya etkinleştirme bekleyen bir paket ana listede kalır.

Başka hiçbir şey değişmez: paketler, geçmişleri ve ücretleri olduğu gibi kalır ve [Paketleri Listele](/tr/api-reference/transfer-packages/list) onları `archived_at` ile döndürmeye devam eder. Adrese sonradan aldığınız paket ana listededir. Cüzdanı [Cüzdanı Geri Getir](/tr/api-reference/transfer-packages/restore) ile geri getirin.

### İstek gövdesi

<ParamField body="address" type="string" required>
  Kapanmış paketleri arşivlenecek TRON adresi
</ParamField>

### Yanıt

<ResponseField name="address" type="string">
  İstekteki adres.
</ResponseField>

<ResponseField name="archived" type="boolean">
  Her zaman `true`.
</ResponseField>

<ResponseField name="packages" type="number">
  Şimdi arşive giden paket sayısı; `0` — arşivlenecek bir şey yok (kapanmış paket yok ya da hepsi zaten arşivde).
</ResponseField>

### Örnek

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/archive \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

```json Response
{
  "address": "TYourAddress...",
  "archived": true,
  "packages": 3
}
```

### Hatalar

[Standart biçimde](/tr/errors), `detail.error.code` altında döner. Bunların herhangi birinden sonra hiçbir şey değişmemiştir.

| Kod | Durum | Ne zaman |
|------|--------|------|
| `PACKAGE_NOT_FOUND` | `404` | Hesabınızın bu adreste paketi yok |
