## Paketlerimi Listele

Tum transfer paketlerinizi dondurur.

### Yanit

Paket nesneleri dizisi. Ana alanlar: `id`, `address`, `package_size`, `quota_total` (paketteki transfer sayisi), `quota_used` (hizmet verilen transferler), `subscription_used` (gunluk abonelik ucretinin kullandigi transferler, gunde bir), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `status`, `created_at`.

### Paket durumlari

| Durum | Aciklama |
|--------|-------------|
| `pending_payment` | Fatura odemesi bekleniyor |
| `provisioning` | Bakiyeden odendi, aktivasyon suruyor |
| `active` | Adres izleniyor, transferler mevcut |
| `completed` | Tum transferler kullanildi |
| `cancelled` | Kullanici tarafindan iptal edildi |
| `expired` | Fatura zamaninda odenmedi |
| `manual_review` | Aktivasyon sonucu belirsiz; destek ekibi inceler, o zamana kadar odeme bekletilir |
| `failed_refunded` | Aktivasyon basarisiz; ucret bakiyeye iade edildi |

### Ornek

```bash
curl https://api.tronrental.com/v1/transfer-packages/my \
  -H "X-API-Key: your_api_key"
```
