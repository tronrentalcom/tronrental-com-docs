## Transfer Paketi Satin Al

Hesap bakiyenizi kullanarak bir transfer paketi satin alir.

### Istek govdesi

<ParamField body="address" type="string" required>
  Izlenecek TRON adresi
</ParamField>

<ParamField body="package_size" type="number">
  Paketteki transfer sayisi (2 – 10.000). `single_transfer` `true` degilse zorunludur. `package_size: 1` `422` ile reddedilir — tek transfer satin almak icin `single_transfer: true` gonderin.
</ParamField>

<ParamField body="single_transfer" type="boolean" default="false">
  Paket yerine tek transfer satin alin; bu durumda `package_size` yok sayilir. Fiyat: [Kademeleri Al](/api-reference/transfer-packages/get-tiers) yanitindaki `single_transfer_price` (BW Garantisi ile `bw_fee_per_transfer` eklenir).
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  BW Garantisini etkinlestir
</ParamField>

### Yanit

`package_id`, `status`, `total_price_trx`, `activation_cost_trx` (adres henuz etkin degilse etkinlestirme icin harcanan TRX, aksi halde `0`) ve `total_charged_trx` dondurur.

### Ornek

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "package_size": 500,
    "bw_guarantee": true
  }'
```

```json Response
{
  "package_id": 101,
  "status": "active",
  "total_price_trx": "1500.0",
  "activation_cost_trx": "0",
  "total_charged_trx": "1500.0"
}
```

<Info>
  Ayrica `POST /api/v1/transfer-packages/buy-invoice` kullanarak fatura ile de odeme yapabilirsiniz —
  bu, TRX/USDT icin bir odeme adresi olusturur.
</Info>
