## Paket Kademelerini Al

Mevcut onceden ayarlanmis paket boyutlarini, fiyatlandirmayi ve sinirlari dondurur.

### Yanit

<ResponseField name="tiers" type="array">
  Boyut ve toplam fiyat iceren onceden ayarlanmis paket secenekleri dizisi
</ResponseField>

<ResponseField name="single_transfer_price" type="string">
  TRX cinsinden tek transfer fiyati
</ResponseField>

<ResponseField name="bw_fee_per_transfer" type="string">
  TRX cinsinden transfer basina BW Garantisi ucreti
</ResponseField>

<ResponseField name="min_custom_size" type="number">
  Minimum ozel paket boyutu (2). Tek transfer icin `single_transfer: true` kullanin
</ResponseField>

<ResponseField name="max_custom_size" type="number">
  Maksimum ozel paket boyutu (10.000)
</ResponseField>

### Ornek

```bash
curl https://api.tronrental.com/v1/transfer-packages/tiers \
  -H "X-API-Key: your_api_key"
```
