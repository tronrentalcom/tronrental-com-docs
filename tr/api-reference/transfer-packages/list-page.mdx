## Paketleri Sayfa Sayfa Listele

Transfer paketlerinizin bir sayfasını döndürür: ana listeyi veya `archived=true` ile arşivi. Önce kapanmamış paketler — aktif, duraklatılmış, ödeme veya etkinleştirme bekleyen — sonra en yeniler gelir. Panelin gösterdiği liste budur; [Paketleri Listele](/tr/api-reference/transfer-packages/list) tüm paketleri yine tek seferde döndürür.

### Sorgu parametreleri

<ParamField query="archived" type="boolean" default="false">
  `true` — arşiv ([Cüzdanı Arşivle](/tr/api-reference/transfer-packages/archive) ile oraya taşınan paketler); `false` (varsayılan) — ana liste
</ParamField>

<ParamField query="page" type="number">
  Sayfa numarası (varsayılan 1)
</ParamField>

<ParamField query="page_size" type="number">
  Sayfa başına paket (varsayılan 20, en fazla 100)
</ParamField>

### Yanıt

<ResponseField name="packages" type="array">
  Sayfanın paketleri — [Paketleri Listele](/tr/api-reference/transfer-packages/list) ile aynı nesneler, `label` ve `archived_at` ile.
</ResponseField>

<ResponseField name="total" type="number">
  İstenen listedeki paket sayısı, tüm sayfalarda.
</ResponseField>

<ResponseField name="page" type="number">
  İstekteki sayfa.
</ResponseField>

<ResponseField name="page_size" type="number">
  İstekteki sayfa boyutu.
</ResponseField>

<ResponseField name="archived_packages" type="number">
  Hesabınızın arşivdeki paket sayısı — hangi liste istenirse istensin.
</ResponseField>

<ResponseField name="archived_wallets" type="number">
  Arşivdeki bu paketlerin bulunduğu adres sayısı.
</ResponseField>

### Örnek

```bash
curl "https://api.tronrental.com/v1/transfer-packages/list?page=1&page_size=20" \
  -H "X-API-Key: your_api_key"
```

| Kod | Durum | Ne zaman |
|------|--------|------|
| — | `422` | `page` < 1, `page_size` ∉ 1–100 |
