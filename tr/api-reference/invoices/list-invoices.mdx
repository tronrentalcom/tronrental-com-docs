## Faturalari Listele

Sayfalandirilmis fatura listenizi dondurur.

### Sorgu parametreleri

<ParamField query="page" type="number" default="1">
  Sayfa numarasi
</ParamField>

<ParamField query="status" type="string">
  Duruma gore filtrele: `pending`, `paid`, `delegated`, `expired`, `failed`
</ParamField>

<ParamField query="from" type="string">
  Dönemin ilk günü, `YYYY-MM-DD`, dahil. İki tarih de verilmezse tüm liste döner.
</ParamField>

<ParamField query="to" type="string">
  Dönemin son günü, `YYYY-MM-DD`, **dahil** — kendi saat diliminizde 23:59:59.999'a kadar günün tamamı sayılır.
</ParamField>

<ParamField query="tz" type="string">
  İki tarihin okunduğu IANA saat dilimi, örn. `Europe/Berlin`. Verilmezse UTC.
</ParamField>

<Info>
  Rapordan farklı olarak listede bir yıl sınırı yoktur — liste sayfalanır. Her iki tarih de isteğe bağlıdır: yalnızca `from` «o günden itibaren», yalnızca `to` «o gün dahil olmak üzere» demektir.
</Info>

### Yanit

`invoices` dizisi ve `total` sayisini iceren sayfalandirilmis bir nesne dondurur.

### Ornek

```bash
curl "https://api.tronrental.com/v1/invoices/my?page=1&status=delegated" \
  -H "X-API-Key: your_api_key"
```
