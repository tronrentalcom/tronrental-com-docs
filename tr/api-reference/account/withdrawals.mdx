## Cekim Olustur

<div>
  `POST /api/v1/account/withdrawal`
</div>

Herhangi bir TRON adresine TRX ceker. Ucret: 1 TRX.

### Istek govdesi

<ParamField body="to_address" type="string" required>
  Hedef TRON adresi
</ParamField>

<ParamField body="amount_trx" type="string" required>
  TRX cinsinden cekilecek miktar
</ParamField>

<ParamField body="currency" type="string">
  `TRX` (varsayılan) veya `USDT`. `USDT` ile `amount_trx`, gönderilecek USDT tutarını taşır.
</ParamField>

<ParamField body="totp_code" type="string">
  2FA kodu (2FA etkinse)
</ParamField>

### Başlıklar

<ParamField header="Idempotency-Key" type="string">
  İsteğe bağlı, en fazla 64 karakter. Her yeni çekimde yeni bir anahtar (örneğin bir UUID) gönderin; yanıtını alamadığınız bir isteği tekrarlarken aynı anahtarı kullanın — tekrar, ikinci bir çekim oluşturmak yerine ilk çekimi döndürür.
</ParamField>

### Güvenli tekrar

- Aynı anahtar ve aynı `to_address`, `amount_trx` ve `currency` ile istek, ilk isteğin oluşturduğu çekimi güncel durumuyla `200` olarak döndürür. İki kez ücret alınmaz.
- Aynı anahtar farklı bir gövdeyle `422` ve `IDEMPOTENCY_KEY_REUSED` koduyla reddedilir; 64 karakterden uzun anahtar `422` ve `IDEMPOTENCY_KEY_TOO_LONG` ile reddedilir. Anahtarlar hesabınıza özeldir ve süresi dolmaz — bir anahtarı başka bir çekim için asla yeniden kullanmayın.
- Aynı anda yalnızca bir tamamlanmamış çekim (`pending`, `scheduled` veya `processing`) olabilir: varken gelen yeni istek `400` ve `You already have a pending withdrawal` alır.
- `Idempotency-Key` ile oluşturulan bir çekimden sonra bir sonraki 5 saniye içinde oluşturulabilir; başlık olmadan bekleme 60 saniye olarak kalır (`429`, bkz. [Hız limitleri](/resources/rate-limits)).

### Ornek

```bash
curl -X POST https://api.tronrental.com/v1/account/withdrawal \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 7f9c2b1e-5d4a-4c1e-9b3f-2a6d8e0c4f11" \
  -d '{
    "to_address": "TDestinationAddress...",
    "amount_trx": "100"
  }'
```

```json Response
{
  "id": 56,
  "to_address": "TDestinationAddress...",
  "amount_trx": "100.00",
  "fee_trx": "1.00",
  "status": "completed",
  "tx_hash": "a1b2c3d4e5f6...",
  "created_at": "2026-03-05T12:00:00Z"
}
```

## Cekimleri Listele

<div>
  `GET /api/v1/account/withdrawals`
</div>

Cekim gecmisinizi dondurur.

```bash
curl https://api.tronrental.com/v1/account/withdrawals \
  -H "X-API-Key: your_api_key"
```

```json Response
[
  {
    "id": 56,
    "to_address": "TDestinationAddress...",
    "amount_trx": "100.00",
    "fee_trx": "1.00",
    "status": "completed",
    "tx_hash": "a1b2c3d4e5f6...",
    "created_at": "2026-03-05T12:00:00Z"
  }
]
```

### Cekim durumlari

| Durum | Aciklama |
|--------|-------------|
| `pending` | Isleme alinmak uzere siraya alindi |
| `completed` | TRX gonderildi, tx_hash mevcut |
| `failed` | Basarisiz oldu, tutar iade edildi |
| `scheduled` | Web panelinden oluşturuldu; gönderimden önce 20 saniyelik iptal penceresini bekler |
| `processing` | Ağa gönderiliyor |
| `cancelled` | İptal penceresinde kullanıcı tarafından iptal edildi; tutar iade edildi |

API anahtarıyla oluşturulan çekimler hemen gönderilir ve hiçbir zaman `scheduled` durumundan geçmez. Web panelinde oluşturulan satırlarda `execute_after` bulunur — daha önce iptal edilmezse gönderim anı.

### E-posta değişikliğinden sonra güvenlik kilidi

Hesabın e-posta adresi değiştirildikten sonraki 24 saat boyunca çekim oluşturma `403` ve `WITHDRAWAL_EMAIL_COOLDOWN` hata koduyla reddedilir. Yanıt, çekimlerin açılmasına ne kadar süre kaldığını gösteren `retry_after_seconds` alanını içerir:

```json Response
{
  "detail": {
    "error": {
      "code": "WITHDRAWAL_EMAIL_COOLDOWN",
      "message": "Withdrawals are temporarily blocked after an email change",
      "retry_after_seconds": 79214
    }
  }
}
```

Bu kilit, `withdraw` yetkisine sahip API anahtarları dâhil olmak üzere her oturum türü için geçerlidir. Hesabın e-postasını siz değiştirmediyseniz hemen destek ekibiyle iletişime geçin.
