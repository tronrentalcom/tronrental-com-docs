## Yatirma Adresi Al

<div>
  `GET /api/v1/account/deposit`
</div>

Kisisel yatirma adresinizi ve kabul edilen para birimlerini dondurur.

```bash
curl https://api.tronrental.com/v1/account/deposit \
  -H "X-API-Key: your_api_key"
```

```json
{
  "deposit_address": "TYourDepositAddress...",
  "accepted_currencies": ["TRX", "USDT"],
  "usdt_to_trx_rate": "26.5",
  "trx_usd_rate": "0.234"
}
```

## Yatirmalari Listele

<div>
  `GET /api/v1/account/deposits`
</div>

Yatirma gecmisinizi dondurur.

```bash
curl https://api.tronrental.com/v1/account/deposits \
  -H "X-API-Key: your_api_key"
```

### Sorgu parametreleri

<ParamField query="from" type="string">
  Dönemin ilk günü, `YYYY-MM-DD`, dahil. İki tarih de verilmezse tüm liste döner.
</ParamField>

<ParamField query="to" type="string">
  Dönemin son günü, `YYYY-MM-DD`, **dahil** — kendi saat diliminizde 23:59:59.999'a kadar günün tamamı sayılır.
</ParamField>

<ParamField query="tz" type="string">
  İki tarihin okunduğu IANA saat dilimi, örn. `Europe/Berlin`. Verilmezse UTC.
</ParamField>

<Info>
  Rapordan farklı olarak listede bir yıl sınırı yoktur — liste sayfalanır. Her iki tarih de isteğe bağlıdır: yalnızca `from` «o günden itibaren», yalnızca `to` «o gün dahil olmak üzere» demektir.
</Info>

### Yatirma durumlari

| Durum | Aciklama |
|--------|-------------|
| `pending` | Islem algilandi, onay bekleniyor |
| `confirmed` | Bakiyenize eklendi |
| `expired` | Yatirma adresinin suresi doldu |

<Info>
  Yatirmalar otomatik olarak hesabiniza eklenir. TRX yatirmalari 1:1 oranindadir. USDT yatirmalari guncel piyasa kurunda TRX'e donusturulur.
</Info>
