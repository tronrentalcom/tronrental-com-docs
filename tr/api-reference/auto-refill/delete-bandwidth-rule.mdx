## Bant Genişliği Kuralını Sil

Bir kuralı siler. Bu kural için artık dolum yapılmaz ve adres yeni bir bant genişliği kuralı için serbest kalır. Zaten satın alınmış bant genişliği geri alınmaz: bu kiralamalar süreleri bitene kadar sürer. Geçmiş dolum siparişleri sipariş geçmişinizde kalır. `buy_bandwidth` kapsamını gerektirir.

Kuralı kaybetmeden dolumları bir süreliğine durdurmak için onu silmek yerine [duraklatın](/tr/api-reference/auto-refill/update-bandwidth-rule).

### Yol parametreleri

<ParamField path="rule_id" type="number" required>
  Kural kimliği — Bant Genişliği Kuralı Oluştur veya Bant Genişliği Kurallarını Listele yanıtındaki `id`
</ParamField>

### Yanıt

<ResponseField name="status" type="string">
  `ok`
</ResponseField>

### Örnek

<CodeGroup>

curl -X DELETE https://api.tronrental.com/v1/bandwidth/auto-refill/15 \

### Hatalar

| Durum | Kod | Ne zaman |
|--------|------|------|
| `403` | `FORBIDDEN` | API anahtarında `buy_bandwidth` kapsamı yok |
| `404` | `NOT_FOUND` | Hesabınızda bu kimliğe sahip bir bant genişliği kuralı yok (veya kural zaten silinmiş) |
| `409` | `AUTOREFILL_IN_PROGRESS` | Bu kural için şu anda bir dolum satın alınıyor — bir dakika sonra yeniden deneyin |

```json
{
  "detail": {
    "error": {
      "code": "NOT_FOUND",
      "message": "Auto-refill rule not found"
    }
  }
}
```
