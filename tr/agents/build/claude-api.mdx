<Info>
  20 Kasım 2026'da [MCP bağlayıcısı belgelerine](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector) (beta `mcp-client-2025-11-20`), `anthropic` **2.11.0** (Python) ve `@anthropic-ai/sdk` **1.11.0** (TypeScript) göre kontrol edildi.
</Info>

MCP bağlayıcısıyla Claude, istek sırasında TronRental'ı Anthropic tarafından çağırır — kodunuzda MCP istemcisi gerekmez. Bağlayıcı yalnızca `authorization_token` değerini `Authorization: Bearer <token>` olarak gönderir: bir API anahtarı veya kullanıcının OAuth erişim belirteci. Çağrılar Anthropic'in IP adreslerinden gelir, bu yüzden IP izin listesi olan bir anahtar reddedilir.

`mcp_servers` içindeki her sunucunun `tools` içinde eşleşen bir `mcp_toolset` girdisi olmalıdır.

## Python

```bash
pip install "anthropic>=2.11"
```

```python claude.py
import os

import anthropic

client = anthropic.Anthropic()  # ANTHROPIC_API_KEY değerini okur

response = client.beta.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "How much is 65,000 energy for 1 hour on TronRental?"}],
    mcp_servers=[
        {
            "type": "url",
            "url": "https://mcp.tronrental.com/mcp",
            "name": "tronrental",
            "authorization_token": os.environ["TRONRENTAL_API_KEY"],
        }
    ],
    tools=[
        {
            "type": "mcp_toolset",
            "mcp_server_name": "tronrental",
            # Yalnızca bu asistanın ihtiyaç duyduğu araçlar; geri kalan her şey kapalı kalır.
            "default_config": {"enabled": False},
            "configs": {
                "get_energy_prices": {"enabled": True},
                "quote_energy": {"enabled": True},
                "get_balance": {"enabled": True},
            },
        }
    ],
    betas=["mcp-client-2025-11-20"],
)

for block in response.content:
    if block.type == "text":
        print(block.text)
```

## TypeScript

```bash
npm install @anthropic-ai/sdk
```

```ts claude.mjs
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic(); // ANTHROPIC_API_KEY değerini okur

const response = await anthropic.beta.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 1024,
  messages: [{ role: "user", content: "How much is 65,000 energy for 1 hour on TronRental?" }],
  mcp_servers: [
    {
      type: "url",
      url: "https://mcp.tronrental.com/mcp",
      name: "tronrental",
      authorization_token: process.env.TRONRENTAL_API_KEY,
    },
  ],
  tools: [{ type: "mcp_toolset", mcp_server_name: "tronrental" }],
  betas: ["mcp-client-2025-11-20"],
});

for (const block of response.content) {
  if (block.type === "text") console.log(block.text);
}
```

## Satın almalar

Bağlayıcı araç çağrılarını istek içinde size sormadan çalıştırır. Claude'un harcama yapmasına izin vermeden önce:

- yalnızca ihtiyaç duyduğu araçları açın (Python örneğindeki gibi `default_config` ve `configs`);
- dar kapsamlı bir API anahtarını veya kullanıcının OAuth belirtecini tercih edin; bu belirtecin [günlük harcama limiti](/tr/agents/reference/spending-and-errors#günlük-harcama-limiti) bir isteğin harcayabileceğini sınırlar;
- her satın almayı bir kişinin onaylaması gerekiyorsa bunun yerine kendi MCP istemcinizi çalıştırın ([TypeScript](/tr/agents/build/typescript), [Python](/tr/agents/build/python)) ve kişi kabul ettikten sonra `buy_energy` çağırın.

Araç çağrıları ve sonuçları `response.content` içinde `mcp_tool_use` ve `mcp_tool_result` blokları olarak döner.
