Aşağıdaki tüm istemciler aynı sunucuya bağlanır ve sizi TronRental ile giriş yaptırır — kopyalanacak API anahtarı yok:

```
https://mcp.tronrental.com/mcp
```

İlk kullanımda istemci tronrental.com'u açar. Giriş yapın (veya kaydolun), hesabı seçin, [izinleri](/tr/agents/reference/permissions) işaretleyin, günlük harcama limitini belirleyin ve onaylayın. İstemci yalnızca bu bağlantı için bir belirteç alır.

## Çalıştığını kontrol edin

Ajana sorun: *"TronRental'da 1 saatlik 65.000 enerji için teklif al."* Ajan `quote_energy` çağırır ve fiyatı gösterir — ücret alınmaz.

Her satın almadan önce ajan fiyat teklifi alır, size gösterir ve `max_price_trx` olarak gönderir; ayrıca bir `idempotency_key` gönderir, böylece tekrar deneme asla iki kez ücret almaz. Satın almalar hesapta toplam 100 TRX yükleme gerektirir — o zamana kadar bağlantı yalnızca okuyabilir. Bkz. [Harcamalar ve hatalar](/tr/agents/reference/spending-and-errors).

## Yönetme ve bağlantıyı kesme

[API sayfasındaki](https://tronrental.com/dashboard/api) **Bağlı uygulamalar** listesi tüm bağlı istemcileri gösterir: kimin bağladığı, izinleri, günlük limiti ve son 24 saatte ne harcadığı. Limiti orada değiştirin veya bağlantıyı hemen iptal etmek için **Bağlantıyı kes** düğmesine tıklayın.

## Bunun yerine API anahtarı kullanın

Başlık ayarlamaya izin veren istemciler, giriş yapmak yerine bir [API anahtarıyla](/tr/authentication) bağlanabilir — örneğin sunucunuzda çalışan bir ajan için:

```bash
claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp \
  --header "Authorization: Bearer $TRONRENTAL_API_KEY"
```

Codex'te anahtarın ortam değişkenini `~/.codex/config.toml` dosyasına yazın:

```toml
[mcp_servers.tronrental]
url = "https://mcp.tronrental.com/mcp"
bearer_token_env_var = "TRONRENTAL_API_KEY"
```

Cursor'da `url` alanının yanına `"headers": { "Authorization": "Bearer ${env:TRONRENTAL_API_KEY}" }` ekleyin.

API anahtarının günlük limiti yoktur: ona yalnızca ajanın ihtiyaç duyduğu kapsamları verin. Bkz. [MCP ile geliştirin](/tr/agents/build/overview).

## Tarayıcısı olmayan ajanlar

Tarayıcı açamayan ajanlar yerel [@tronrental-com/mcp-server](https://www.npmjs.com/package/@tronrental-com/mcp-server) paketini kullanabilir: paket makinenizde `TRONRENTAL_API_KEY` içindeki bir API anahtarıyla çalışır veya ajanın e-postanız ve o adrese gelen bir kodla hesap açmasına izin verir. Kurulum [README](https://github.com/tronrentalcom/tronrental-com-mcp) dosyasında.
