नीचे दिया हर क्लाइंट एक ही सर्वर से जुड़ता है और आपको TronRental से साइन इन कराता है — कोई API कुंजी कॉपी नहीं करनी:

```
https://mcp.tronrental.com/mcp
```

पहली बार इस्तेमाल पर क्लाइंट tronrental.com खोलता है। साइन इन (या साइन अप) करें, खाता चुनें, [अनुमतियाँ](/hi/agents/reference/permissions) चुनें, दैनिक खर्च सीमा तय करें और स्वीकृत करें। क्लाइंट को सिर्फ़ इस कनेक्शन का टोकन मिलता है।

<Tabs>
  <Tab title="Claude">
    वेब पर Claude और डेस्कटॉप ऐप में, हर प्लान पर काम करता है (Free प्लान में एक कस्टम कनेक्टर की अनुमति है)।

    1. [Add to Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=TronRental&connectorUrl=https%3A%2F%2Fmcp.tronrental.com%2Fmcp) खोलें — या **Customize → Connectors → Add → Add custom connector** में जाएँ और नाम `TronRental` और ऊपर दिया URL डालें।
    2. TronRental के बगल में **Connect** पर क्लिक करें।
    3. tronrental.com पर साइन इन करें और स्वीकृत करें।
    4. चैट में टूल्स मेनू से TronRental चालू करें और पूछें, उदाहरण के लिए: *"What is my TronRental balance?"*

    Team और Enterprise प्लान पर मालिक **Organization settings → Connectors** में कनेक्टर जोड़ता है; फिर सदस्य **Connect** पर क्लिक करते हैं।
  </Tab>
  <Tab title="ChatGPT">
    1. [ChatGPT Plugins](https://chatgpt.com/plugins) खोलें और **+** → **Add custom MCP server** पर क्लिक करें।
    2. नाम `TronRental` डालें, **Public endpoint** चुनें और ऊपर दिया URL पेस्ट करें।
    3. ऑथेंटिकेशन **OAuth** पर रहने दें, चेतावनी की पुष्टि करें और **Create as a plugin** पर क्लिक करें।
    4. tronrental.com पर साइन इन करें और स्वीकृत करें।
    5. चैट में टूल्स मेनू से TronRental चुनें।

    अगर आपको यह विकल्प नहीं दिखता, तो शायद आपका वर्कस्पेस कस्टम MCP सर्वर की अनुमति नहीं देता — उसके एडमिन से पूछें। ChatGPT सिर्फ़ OAuth से जुड़ता है; वह API कुंजी इस्तेमाल नहीं कर सकता।
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp
    ```

    फिर Claude Code के अंदर `/mcp` चलाएँ, **tronrental** और **Authenticate** चुनें। आपका ब्राउज़र tronrental.com खोलता है; स्वीकृत करें और टर्मिनल पर लौटें।

    हर प्रोजेक्ट में TronRental इस्तेमाल करने के लिए `--scope user` जोड़ें, या `.mcp.json` के ज़रिए अपनी टीम के साथ साझा करने के लिए `--scope project`।
  </Tab>
  <Tab title="Codex">

    ```bash
    codex mcp login tronrental
    ```

## जाँचें कि यह काम करता है

एजेंट से पूछें: *"Quote 65,000 energy for 1 hour on TronRental."* वह `quote_energy` कॉल करता है और कीमत दिखाता है — कोई पैसा नहीं कटता।

हर ख़रीद से पहले एजेंट कीमत का कोट लेता है, उसे आपको दिखाता है और `max_price_trx` के रूप में भेजता है; वह `idempotency_key` भी भेजता है, ताकि दोबारा कोशिश में कभी दो बार पैसे न कटें। ख़रीद के लिए खाते पर कुल 100 TRX के टॉप-अप चाहिए — तब तक कनेक्शन सिर्फ़ पढ़ सकता है। देखें [खर्च और त्रुटियां](/hi/agents/reference/spending-and-errors)।

## प्रबंधित करें और डिस्कनेक्ट करें

[API पेज](https://tronrental.com/dashboard/api) पर **कनेक्ट किए गए ऐप** सूची हर कनेक्ट किया गया क्लाइंट दिखाती है: किसने कनेक्ट किया, उसकी अनुमतियाँ, उसकी दैनिक सीमा और पिछले 24 घंटों में उसने कितना खर्च किया। सीमा वहीं बदलें, या कनेक्शन तुरंत रद्द करने के लिए **डिस्कनेक्ट करें** पर क्लिक करें।

## इसके बजाय API कुंजी इस्तेमाल करें

जो क्लाइंट हेडर सेट करने देते हैं, वे साइन इन के बजाय [API कुंजी](/hi/authentication) से जुड़ सकते हैं — उदाहरण के लिए, आपके सर्वर पर चलने वाले एजेंट के लिए:

```bash
claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp \
  --header "Authorization: Bearer $TRONRENTAL_API_KEY"
```

Codex में कुंजी का एनवायरनमेंट वेरिएबल `~/.codex/config.toml` में रखें:

```toml
[mcp_servers.tronrental]
url = "https://mcp.tronrental.com/mcp"
bearer_token_env_var = "TRONRENTAL_API_KEY"
```

Cursor में `url` के बगल में `"headers": { "Authorization": "Bearer ${env:TRONRENTAL_API_KEY}" }` जोड़ें।

API कुंजी की कोई दैनिक सीमा नहीं होती: उसे सिर्फ़ वही स्कोप दें जो एजेंट को चाहिए। देखें [MCP के साथ बनाएँ](/hi/agents/build/overview)।

## बिना ब्राउज़र वाले एजेंट

जो एजेंट ब्राउज़र नहीं खोल सकते, वे लोकल पैकेज [@tronrental-com/mcp-server](https://www.npmjs.com/package/@tronrental-com/mcp-server) इस्तेमाल कर सकते हैं: यह आपकी मशीन पर `TRONRENTAL_API_KEY` में रखी API कुंजी के साथ चलता है, या एजेंट को आपके ईमेल और उस पर आए कोड से खाता रजिस्टर करने देता है। सेटअप उसके [README](https://github.com/tronrentalcom/tronrental-com-mcp) में है।
