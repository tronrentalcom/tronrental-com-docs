MCP कनेक्टर के साथ Claude अनुरोध के दौरान Anthropic की ओर से TronRental को कॉल करता है — आपके कोड में MCP क्लाइंट की ज़रूरत नहीं। कनेक्टर सिर्फ़ `authorization_token` भेजता है, `Authorization: Bearer <token>` के रूप में: API कुंजी, या उपयोगकर्ता का OAuth एक्सेस टोकन। कॉल्स Anthropic के IP पतों से आती हैं, इसलिए IP व्हाइटलिस्ट वाली कुंजी अस्वीकार होती है।

`mcp_servers` में हर सर्वर के लिए `tools` में एक मेल खाती `mcp_toolset` प्रविष्टि चाहिए।

## Python

```bash
pip install "anthropic>=2.11"
```

```python claude.py
import os

import anthropic

client = anthropic.Anthropic()  # ANTHROPIC_API_KEY पढ़ता है

response = client.beta.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "How much is 65,000 energy for 1 hour on TronRental?"}],
    mcp_servers=[
        {
            "type": "url",
            "url": "https://mcp.tronrental.com/mcp",
            "name": "tronrental",
            "authorization_token": os.environ["TRONRENTAL_API_KEY"],
        }
    ],
    tools=[
        {
            "type": "mcp_toolset",
            "mcp_server_name": "tronrental",
            # सिर्फ़ वे टूल्स जो इस असिस्टेंट को चाहिए; बाकी सब बंद रहते हैं।
            "default_config": {"enabled": False},
            "configs": {
                "get_energy_prices": {"enabled": True},
                "quote_energy": {"enabled": True},
                "get_balance": {"enabled": True},
            },
        }
    ],
    betas=["mcp-client-2025-11-20"],
)

for block in response.content:
    if block.type == "text":
        print(block.text)
```

## TypeScript

```bash
npm install @anthropic-ai/sdk
```

```ts claude.mjs
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic(); // ANTHROPIC_API_KEY पढ़ता है

const response = await anthropic.beta.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 1024,
  messages: [{ role: "user", content: "How much is 65,000 energy for 1 hour on TronRental?" }],
  mcp_servers: [
    {
      type: "url",
      url: "https://mcp.tronrental.com/mcp",
      name: "tronrental",
      authorization_token: process.env.TRONRENTAL_API_KEY,
    },
  ],
  tools: [{ type: "mcp_toolset", mcp_server_name: "tronrental" }],
  betas: ["mcp-client-2025-11-20"],
});

for (const block of response.content) {
  if (block.type === "text") console.log(block.text);
}
```

## ख़रीद

कनेक्टर अनुरोध के अंदर ही टूल कॉल्स चलाता है, आपसे पूछे बिना। Claude को खर्च करने देने से पहले:

- सिर्फ़ वही टूल्स चालू करें जो उसे चाहिए (`default_config` और `configs`, जैसा Python उदाहरण में है);
- सीमित स्कोप वाली API कुंजी, या उपयोगकर्ता का OAuth टोकन पसंद करें, जिसकी [दैनिक खर्च सीमा](/hi/agents/reference/spending-and-errors) तय करती है कि एक अनुरोध कितना खर्च कर सकता है;
- अगर हर ख़रीद की पुष्टि किसी व्यक्ति को करनी है, तो इसके बजाय अपना MCP क्लाइंट चलाएँ ([TypeScript](/hi/agents/build/typescript), [Python](/hi/agents/build/python)) और उनकी सहमति के बाद `buy_energy` कॉल करें।

टूल कॉल्स और उनके परिणाम `response.content` में `mcp_tool_use` और `mcp_tool_result` ब्लॉक के रूप में लौटते हैं।
