## यह कैसे काम करता है

1. TronRental सर्वर को अपने एजेंट में जोड़ें — देखें [MCP सर्वर](/hi/resources/mcp-server)।
2. एजेंट TronRental का साइन-इन पेज खोलता है। साइन इन (या साइन अप) करें; सहमति स्क्रीन पर ऐप का नाम, वह किस साइट पर लौटेगा और क्या माँग रहा है, दिखता है।
3. खाता, अनुमतियाँ और दैनिक सीमा चुनें और स्वीकृत करें।
4. एजेंट को सिर्फ़ इस कनेक्शन का टोकन मिलता है। वह आपका पासवर्ड या API कुंजी कभी नहीं देखता।

## अनुमतियाँ

| अनुमति | एजेंट क्या कर सकता है |
|---|---|
| `view` | बैलेंस, इतिहास, ऑर्डर, पता जाँच |
| `deposit_view` | डिपॉज़िट पता और डिपॉज़िट |
| `buy_energy` | एनर्जी ख़रीदना, पते सक्रिय करना, इनवॉइस |
| `buy_bandwidth` | बैंडविड्थ ख़रीदना |
| `smart_mode` | Smart Mode |
| `transfer_packages` | ट्रांसफ़र पैकेज |
| `energy_resale` | Energy Resale |
| `recurring` | अपने-आप चलने वाले खर्च चालू करना (ऑटो-रिफ़िल, ऑटो बैंडविड्थ, Smart Mode, Energy Resale, ब्रॉडकास्टर)। डिफ़ॉल्ट रूप से बंद |

जब तक खाते के टॉप-अप कुल 100 TRX नहीं हो जाते, कनेक्शन को सिर्फ़ `view` और `deposit_view` मिलते हैं; टॉप-अप के बाद ख़रीद की अनुमति देने के लिए दोबारा कनेक्ट करें।

**कनेक्ट किए गए ऐप के लिए निकासी कभी उपलब्ध नहीं है।** यह `withdraw` अनुमति, 2FA और IP व्हाइटलिस्ट वाली API कुंजियों तक ही सीमित है।

## दैनिक खर्च सीमा

हर कनेक्शन की 24 घंटे में खर्च की एक सीमा होती है — 100 TRX, जब तक आप सहमति स्क्रीन पर कोई और संख्या न रखें। खाते का मालिक «कोई सीमा नहीं» चुन सकता है। अपने-आप चलने वाले खर्च (`recurring`) सीमा से बाहर हैं: वे डैशबोर्ड में दिखते हैं और वहीं से बंद होते हैं।

## कनेक्ट किए गए ऐप

डैशबोर्ड के API पेज पर सभी कनेक्ट किए गए ऐप दिखते हैं: किसने कनेक्ट किया, अनुमतियाँ, पिछले 7 दिनों के अनुरोध। «डिस्कनेक्ट» कनेक्शन और उसके सभी टोकन एक साथ रद्द करता है — एजेंट की अगली कॉल अस्वीकार होगी।

## MCP क्लाइंट डेवलपर्स के लिए

- डिस्कवरी: `https://mcp.tronrental.com/mcp` → `401` + `WWW-Authenticate` → `https://mcp.tronrental.com/.well-known/oauth-protected-resource/mcp` (RFC 9728); `https://mcp.tronrental.com/.well-known/oauth-authorization-server` (RFC 8414).
- PKCE के साथ OAuth 2.1 (सिर्फ़ `S256`), पब्लिक क्लाइंट (`token_endpoint_auth_method: none`)। क्लाइंट पंजीकरण: Dynamic Client Registration (RFC 7591); समर्थित प्लेटफ़ॉर्म से Client ID Metadata Document स्वीकार होते हैं।
- Redirect URI: लूपबैक (`http://127.0.0.1:<कोई भी पोर्ट>`, `http://localhost:<कोई भी पोर्ट>`) और समर्थित प्लेटफ़ॉर्म के कॉलबैक। कोई और चाहिए — सपोर्ट को लिखें।
- एक्सेस टोकन — 1 घंटा, रिफ़्रेश टोकन — रोटेशन के साथ 30 दिन; पुराने रिफ़्रेश टोकन का दोबारा उपयोग कनेक्शन रद्द कर देता है।
