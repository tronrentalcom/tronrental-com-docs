TronRental एक रिमोट [Model Context Protocol](https://modelcontextprotocol.io) (MCP) सर्वर चलाता है:

```
https://mcp.tronrental.com/mcp
```

कोई भी MCP क्लाइंट — Claude, ChatGPT, Claude Code, Codex, Cursor या आपका अपना कोड — इससे जुड़ता है, TronRental से साइन इन करता है और आपके खाते के लिए टूल्स पाता है। कुछ इंस्टॉल नहीं करना, कोई API कुंजी कॉपी नहीं करनी।

## एजेंट क्या कर सकता है

| क्षेत्र | उदाहरण |
|---|---|
| एनर्जी और बैंडविड्थ | किसी भी TRON पते के लिए एनर्जी या बैंडविड्थ का कोट लेना और ख़रीदना, नया पता सक्रिय करना, बैंडविड्थ ऑर्डर वापस लेना |
| Energy Broadcaster | वॉलेट के लिए ब्रॉडकास्ट URL बनाना, उसकी सेटिंग बदलना, उसका कोटा और इवेंट देखना |
| सब्सक्रिप्शन | Smart Mode, ट्रांसफ़र पैकेज, एनर्जी और बैंडविड्थ ऑटो-रिफ़िल, ऑटो बैंडविड्थ, Energy Resale |
| स्टेकिंग | बैलेंस से TRX स्टेक करना, अनस्टेक करना, रिवॉर्ड क्लेम करना |
| Node API | प्लान और उपयोग देखना, प्लान ख़रीदना, ट्रायल शुरू करना |
| इनवॉइस | इनवॉइस बनाना, ईमेल से भेजना, उसकी स्थिति देखना |
| खाता | बैलेंस, इतिहास, ऑर्डर, डिपॉज़िट पता, रिपोर्ट |

पूरी सूची [टूल्स संदर्भ](/hi/agents/reference/tools) में है। एजेंट सिर्फ़ वही टूल्स देखता है जिनकी उसका कनेक्शन अनुमति देता है।

## नियंत्रण आपके पास रहता है

<CardGroup cols={2}>
  <Card title="सहमति स्क्रीन" icon="hand">
    जब एजेंट पहली बार जुड़ता है, आप tronrental.com पर साइन इन करते हैं और ऐप का नाम और वह साइट देखते हैं जिस पर वह लौटेगा। आपकी स्वीकृति से पहले कुछ भी साझा नहीं होता।
  </Card>
  <Card title="अनुमतियाँ" icon="key">
    आप चुनते हैं कि एजेंट क्या कर सकता है: पढ़ना, एनर्जी ख़रीदना, Smart Mode चलाना आदि। अपने-आप चलने वाला खर्च एक अलग विकल्प है, जो डिफ़ॉल्ट रूप से बंद रहता है। देखें [अनुमतियाँ](/hi/agents/reference/permissions)।
  </Card>
  <Card title="दैनिक खर्च सीमा" icon="gauge">
    हर कनेक्शन **24 घंटे में अधिकतम 100 TRX** खर्च कर सकता है, जब तक आप कोई और राशि न रखें। इसे कभी भी डैशबोर्ड के [API पेज](https://tronrental.com/dashboard/api) पर **कनेक्ट किए गए ऐप** में बदलें।
  </Card>
  <Card title="कभी भी डिस्कनेक्ट करें" icon="plug-circle-xmark">
    कनेक्ट किए गए ऐप में **डिस्कनेक्ट करें** कनेक्शन और उसके सभी टोकन एक साथ रद्द करता है। एजेंट की अगली कॉल अस्वीकार होगी।
  </Card>
</CardGroup>

- **ख़रीद से पहले टॉप-अप।** जब तक खाते के टॉप-अप कुल 100 TRX नहीं हो जाते, कनेक्शन सिर्फ़ पढ़ सकता है: बैलेंस, इतिहास और डिपॉज़िट पता। ख़रीद की अनुमति देने के लिए टॉप-अप के बाद दोबारा कनेक्ट करें।
- **वही कीमत जिस पर आप सहमत हुए।** हर ख़रीद में `max_price_trx` होता है — एजेंट पहले कोट लेता है और कोट की कुल राशि भेजता है। अगर कीमत इससे ऊपर जाती है, तो ख़रीद अस्वीकार होती है, पैसे नहीं कटते।
- **दोहरी कटौती नहीं।** ख़रीद और दूसरी बनाने वाली कॉल्स आइडेम्पोटेंसी कुंजी लेती हैं, इसलिए जवाब खो जाने पर दोबारा कोशिश पहला परिणाम लौटाती है।
- **निकासी नहीं।** कनेक्ट किया गया ऐप कभी भी फ़ंड नहीं निकाल सकता। निकासी सिर्फ़ उन API कुंजियों के लिए है जिनके पास `withdraw` अनुमति, 2FA और IP व्हाइटलिस्ट है।

एजेंट द्वारा दिए गए ऑर्डर [ऑर्डर](/hi/api-reference/orders/get-order) में और [`order.updated` webhook](/hi/api-reference/webhooks/overview) में `source: "agent"` से चिह्नित होते हैं।
