## API कुंजी प्रमाणीकरण

सभी API अनुरोधों के लिए `X-API-Key` हेडर में API कुंजी पास करना आवश्यक है।

```bash
curl https://api.tronrental.com/v1/account/balance \
  -H "X-API-Key: your_api_key"
```

### API कुंजी प्राप्त करना

1. [tronrental.com](https://tronrental.com/auth/register) पर साइन अप करें
2. [डैशबोर्ड → API Keys](https://tronrental.com/dashboard/api) पर जाएं
3. **API कुंजी बनाएं** पर क्लिक करें
4. अपनी कुंजी कॉपी करें और सुरक्षित रूप से स्टोर करें — यह केवल एक बार दिखाई जाती है

ईमेल से नया खाता तभी बनता है जब पते की पुष्टि हो जाती है: TronRental ईमेल पर 6 अंकों का एक कोड भेजता है, और यह कोड दर्ज होते ही खाता बन जाता है।

### API के ज़रिए साइन अप (AI एजेंट)

कोई एजेंट या स्क्रिप्ट वेबसाइट के बिना खाता खोल सकती है और अपनी पहली कुंजी बना सकती है। इसके लिए उपयोगकर्ता का **असली** ईमेल चाहिए: खाता केवल उसी इनबॉक्स में आए कोड से बनता है।

**1. साइन अप शुरू करें** — अभी कोई खाता नहीं बनता, पते पर 6 अंकों का कोड भेजा जाता है:

```bash
curl -X POST https://api.tronrental.com/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com", "password": "<your-password>", "language": "en"}'
```

| फ़ील्ड | प्रकार | आवश्यक | विवरण |
|-------|------|----------|-------------|
| `email` | string | हाँ | उपयोगकर्ता का ईमेल — उपयोगकर्ता को उसमें आया कोड पढ़ पाना चाहिए |
| `password` | string | हाँ | कम से कम 8 अक्षर, जिनमें एक बड़ा अक्षर, एक छोटा अक्षर और एक अंक हो |
| `language` | string | नहीं | ईमेल की भाषा, डिफ़ॉल्ट `en` |

```json
{
  "requires_email_code": true,
  "access_token": null,
  "refresh_token": null
}
```

कोड 10 मिनट तक मान्य रहता है। अगर कोई मान्य कोड पहले से लंबित है, तो दूसरा ईमेल नहीं भेजा जाता। नया कोड पाने के लिए `{"email": "...", "language": "en"}` के साथ `POST /v1/auth/email-code/send` कॉल करें: पिछला कोड काम करना बंद कर देता है, और एक पते पर प्रति घंटे अधिकतम 3 ईमेल भेजे जाते हैं।

**2. ईमेल की पुष्टि करें** — कोड को **उसी पासवर्ड** के साथ भेजें (इस चरण से पहले पासवर्ड कहीं सेव नहीं होता)। इससे खाता बनता है और साइन इन हो जाता है:

```bash
curl -X POST https://api.tronrental.com/v1/auth/email-code/verify \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com", "code": "123456", "password": "<your-password>"}'
```

| फ़ील्ड | प्रकार | आवश्यक | विवरण |
|-------|------|----------|-------------|
| `email` | string | हाँ | वही ईमेल जो चरण 1 में दिया था |
| `code` | string | हाँ | ईमेल में आया 6 अंकों का कोड |
| `password` | string | साइन अप के लिए हाँ | वही पासवर्ड जो चरण 1 में दिया था |
| `referral_code` | string | नहीं | आपको आमंत्रित करने वाले उपयोगकर्ता का रेफ़रल कोड |

```json
{
  "access_token": "eyJhbGciOi...",
  "refresh_token": "eyJhbGciOi...",
  "session_id": "3f9c...",
  "token_type": "bearer",
  "is_new": true
}
```

**3. API कुंजी बनाएं** — access token के साथ:

```bash
curl -X POST https://api.tronrental.com/v1/auth/api-keys \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-agent"}'
```

रिस्पॉन्स का `key` फ़ील्ड ही API कुंजी है — यह केवल एक बार दिखाई जाती है।

| स्थिति | कोड | अर्थ |
|--------|------|---------|
| `400` | `WEAK_PASSWORD` | पासवर्ड नियमों के अनुरूप नहीं है (कोड खर्च नहीं होता) |
| `401` | `INVALID_CREDENTIALS` | कोड गलत है या उसकी समय-सीमा खत्म हो गई है |
| `403` | `EMAIL_DOMAIN_BLOCKED` | यह ईमेल प्रदाता स्वीकार नहीं किया जाता |
| `409` | `EMAIL_EXISTS` | इस ईमेल पर पहले से खाता है — इसके बजाय साइन इन करें |
| `429` | `RATE_LIMIT_EXCEEDED` | बहुत अधिक अनुरोध या ईमेल, या लगातार 5 गलत कोड — नया कोड मंगाएँ |

<Note>
  [MCP सर्वर](/hi/resources/mcp-server) ये चरण `register` और `verify_email_code` टूल्स से पूरे करता है।
</Note>

### IP व्हाइटलिस्ट (वैकल्पिक)

अतिरिक्त सुरक्षा के लिए आप अपनी API कुंजी को विशिष्ट IP एड्रेस तक सीमित कर सकते हैं। कुंजी बनाते या संपादित करते समय डैशबोर्ड में यह कॉन्फ़िगर करें।

### कुंजी अनुमतियां

हर API कुंजी के साथ **स्कोप** (scopes) होते हैं — वे ऑपरेशन जो वह कर सकती है। कुंजी बनाते या संपादित
करते समय आप उन्हें डैशबोर्ड में चुनते हैं। नई कुंजी को पढ़ने और लिखने के सभी स्कोप मिलते हैं (एनर्जी और
बैंडविड्थ खरीदना, Smart Mode, बैलेंस और इतिहास देखना आदि), सिवाय `withdraw` के: यह स्कोप अलग से चालू
किया जाता है और इसके लिए 2FA और IP व्हाइटलिस्ट ज़रूरी हैं; इसे चालू करने, ऐसी कुंजी की IP व्हाइटलिस्ट बदलने और कुंजी को फिर से बनाने की पुष्टि आपके 2FA कोड या पासकी से होती है। कुंजी के स्कोप से बाहर का अनुरोध HTTP `403`
के साथ अस्वीकार होता है। पूरी सूची: [API कुंजी स्कोप की सूची](/hi/api-reference/account/api-key-scopes)।

<Warning>
  अपनी API कुंजी को गोपनीय रखें। इसे क्लाइंट-साइड कोड, सार्वजनिक रिपॉजिटरी या URL में एक्सपोज़ न करें।
</Warning>

## Node API कुंजियाँ

[Node API](/hi/node-api/overview) — `node.tronrental.com` पर TRON फ़ुल नोड्स तक पहुँच — की अपनी अलग
कुंजियाँ होती हैं। आप उन्हें [डैशबोर्ड → Node API](https://tronrental.com/dashboard/node-api) में
एंडपॉइंट के रूप में बनाते हैं। Node API कुंजी केवल नोड पर काम करती है: यह API उसका जवाब
`403 NODE_API_KEY_ONLY` से देता है। इस पेज पर बताई गई API कुंजियाँ भी नोड पर काम नहीं करतीं। देखें
[Node API → एंडपॉइंट और कुंजियाँ](/hi/node-api/authentication)।

## कुंजी उपयोग और अनुरोध लॉग

API कुंजी से प्रमाणित हर अनुरोध 7 दिनों तक रखा जाता है: मेथड, पाथ, स्टेटस कोड, लेटेंसी और क्लाइंट IP। क्वेरी पैरामीटर इस दृश्य में नहीं दिखाए जाते। [Dashboard → API Keys](https://tronrental.com/dashboard/api) खोलें और किसी कुंजी को विस्तृत करके उसके हाल के अनुरोध देखें; **Last Used** कॉलम सबसे हालिया कॉल दिखाता है (प्रमाणीकरण का निशान अधिकतम हर 5 मिनट में एक बार अपडेट होता है, अनुरोध लॉग सटीक है)। लॉग केवल डैशबोर्ड से उपलब्ध है — API कुंजी अपना लॉग नहीं पढ़ सकती।

## रेट लिमिट

रेट लिमिट प्रति कुंजी नहीं, प्रति खाता गिनी जाती है: एक ही खाते की सभी कुंजियां एक ही बजट साझा करती हैं। विवरण के लिए [रेट लिमिट](/hi/resources/rate-limits) देखें।

## त्रुटियां

प्रमाणीकरण त्रुटियां HTTP `401` लौटाती हैं:

```json
{
  "detail": "Invalid or missing API key"
}
```

यदि आपकी कुंजी अक्षम या ब्लॉक है, तो आपको HTTP `403` प्राप्त होगा।
