## निकासी बनाएं

<div>
  `POST /api/v1/account/withdrawal`
</div>

किसी भी TRON एड्रेस पर TRX निकालता है। शुल्क: 1 TRX।

### अनुरोध बॉडी

<ParamField body="to_address" type="string" required>
  गंतव्य TRON एड्रेस
</ParamField>

<ParamField body="amount_trx" type="string" required>
  TRX में निकासी राशि
</ParamField>

<ParamField body="currency" type="string">
  `TRX` (डिफ़ॉल्ट) या `USDT`। `USDT` के साथ `amount_trx` में भेजी जाने वाली USDT राशि होती है।
</ParamField>

<ParamField body="totp_code" type="string">
  2FA कोड (यदि 2FA सक्षम है)
</ParamField>

### हेडर

<ParamField header="Idempotency-Key" type="string">
  वैकल्पिक, अधिकतम 64 अक्षर। हर नई निकासी के साथ नई कुंजी (जैसे UUID) भेजें, और जिस अनुरोध का उत्तर नहीं मिला उसे दोहराते समय वही कुंजी भेजें — दोहराया गया अनुरोध दूसरी निकासी बनाने के बजाय पहली निकासी लौटाता है।
</ParamField>

### सुरक्षित दोहराव

- वही कुंजी और वही `to_address`, `amount_trx` व `currency` होने पर `200` के साथ पहले अनुरोध से बनी निकासी उसकी मौजूदा स्थिति में लौटती है। दो बार शुल्क नहीं कटता।
- वही कुंजी लेकिन अलग बॉडी होने पर `422` और कोड `IDEMPOTENCY_KEY_REUSED` के साथ अस्वीकार; 64 अक्षरों से लंबी कुंजी — `422` और `IDEMPOTENCY_KEY_TOO_LONG` के साथ। कुंजियाँ आपके खाते तक सीमित हैं और समाप्त नहीं होतीं — किसी दूसरी निकासी के लिए कुंजी दोबारा इस्तेमाल न करें।
- एक समय में केवल एक अधूरी निकासी (`pending`, `scheduled` या `processing`): उसके रहते नया अनुरोध `400` और `You already have a pending withdrawal` पाता है।
- `Idempotency-Key` के साथ बनी निकासी के बाद अगली 5 सेकंड में बनाई जा सकती है; हेडर के बिना विराम 60 सेकंड ही रहता है (`429`, देखें [रेट लिमिट](/resources/rate-limits))।

### उदाहरण

```bash
curl -X POST https://api.tronrental.com/v1/account/withdrawal \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 7f9c2b1e-5d4a-4c1e-9b3f-2a6d8e0c4f11" \
  -d '{
    "to_address": "TDestinationAddress...",
    "amount_trx": "100"
  }'
```

```json Response
{
  "id": 56,
  "to_address": "TDestinationAddress...",
  "amount_trx": "100.00",
  "fee_trx": "1.00",
  "status": "completed",
  "tx_hash": "a1b2c3d4e5f6...",
  "created_at": "2026-03-05T12:00:00Z"
}
```

## निकासी सूची

<div>
  `GET /api/v1/account/withdrawals`
</div>

आपका निकासी इतिहास लौटाता है।

```bash
curl https://api.tronrental.com/v1/account/withdrawals \
  -H "X-API-Key: your_api_key"
```

```json Response
[
  {
    "id": 56,
    "to_address": "TDestinationAddress...",
    "amount_trx": "100.00",
    "fee_trx": "1.00",
    "status": "completed",
    "tx_hash": "a1b2c3d4e5f6...",
    "created_at": "2026-03-05T12:00:00Z"
  }
]
```

### निकासी स्टेटस

| स्टेटस | विवरण |
|--------|-------------|
| `pending` | प्रोसेसिंग के लिए कतार में |
| `completed` | TRX भेजा गया, tx_hash उपलब्ध |
| `failed` | विफल, राशि वापस की गई |
| `scheduled` | वेब डैशबोर्ड से बनाया गया; भेजने से पहले 20 सेकंड की रद्दीकरण अवधि की प्रतीक्षा |
| `processing` | नेटवर्क पर भेजा जा रहा है |
| `cancelled` | रद्दीकरण अवधि में उपयोगकर्ता द्वारा रद्द; राशि वापस |

API कुंजी से बनाई गई निकासी तुरंत भेजी जाती है और कभी `scheduled` से नहीं गुज़रती। वेब डैशबोर्ड में बनी पंक्तियों में `execute_after` होता है — भेजने का समय, यदि पहले रद्द न किया गया हो।

### ईमेल बदलने के बाद सुरक्षा रोक

खाते का ईमेल बदलने के बाद 24 घंटे तक निकासी बनाने का अनुरोध `403` और एरर कोड `WITHDRAWAL_EMAIL_COOLDOWN` के साथ अस्वीकार किया जाता है। रिस्पॉन्स में `retry_after_seconds` आता है — निकासी खुलने में कितना समय बचा है:

```json Response
{
  "detail": {
    "error": {
      "code": "WITHDRAWAL_EMAIL_COOLDOWN",
      "message": "Withdrawals are temporarily blocked after an email change",
      "retry_after_seconds": 79214
    }
  }
}
```

यह रोक हर सेशन प्रकार पर लागू होती है, जिसमें `withdraw` स्कोप वाली API कुंजियाँ भी शामिल हैं। यदि आपने खाते का ईमेल नहीं बदला है, तो तुरंत सपोर्ट से संपर्क करें।
