## सब्सक्रिप्शन टॉगल करें

सक्रिय सब्सक्रिप्शन को रोकता है या रोके गए को फिर से शुरू करता है। रोके जाने पर, कोई शुल्क नहीं लिया जाता और ट्रांसफर मॉनिटर नहीं किए जाते।

### पथ पैरामीटर

<ParamField path="sub_id" type="number" required>
  सब्सक्रिप्शन ID
</ParamField>

### रिस्पॉन्स

`paused` लौटाता है — टॉगल के बाद सब्सक्रिप्शन की स्थिति: `true` — रोका गया, `false` — फिर से सक्रिय। यही फ़ील्ड [सब्सक्रिप्शन सूची](/hi/api-reference/smart-mode/list-subscriptions) में हर सब्सक्रिप्शन में है।

### उदाहरण

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "paused": true
}
```
