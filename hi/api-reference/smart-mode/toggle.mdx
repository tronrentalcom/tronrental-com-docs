## सब्सक्रिप्शन टॉगल करें

सक्रिय सब्सक्रिप्शन को रोकता है या रोके गए को फिर से शुरू करता है। रोके जाने पर, कोई शुल्क नहीं लिया जाता और ट्रांसफर मॉनिटर नहीं किए जाते।

### पथ पैरामीटर

<ParamField path="sub_id" type="number" required>
  सब्सक्रिप्शन ID
</ParamField>

### रिस्पॉन्स

`200` रिस्पॉन्स का अर्थ है कि सब्सक्रिप्शन रोका या फिर से शुरू किया गया। रिस्पॉन्स बॉडी API अनुबंध का हिस्सा नहीं है: नई स्थिति [सब्सक्रिप्शन सूची](/hi/api-reference/smart-mode/list-subscriptions) में `paused` फ़ील्ड से पढ़ें।

### उदाहरण

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```
