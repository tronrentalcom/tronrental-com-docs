## ऑटो बैंडविड्थ मूल्य अनुमान

बताता है कि इस `volume` वाला सब्सक्रिप्शन आपके खाते को कितने का पड़ेगा: प्रति 24 घंटे का शुल्क और प्रति ट्रांसफर का शुल्क, जिसमें ट्रांसफर शुल्क बैंडविड्थ और फिक्स्ड शुल्क में बंटा होता है। कुछ बनाया या चार्ज नहीं किया जाता। `view` स्कोप आवश्यक है। हर शुल्क कब लिया जाता है, यह जानने के लिए [लागत](/hi/api-reference/auto-bandwidth/overview#लागत) देखें।

`subscription_id` के बिना कीमत इस पर निर्भर करती है कि आप इसे कैसे कॉल करते हैं: API कुंजी से, यह उस कुंजी से बनाए गए सब्सक्रिप्शन की कीमत है; वेबसाइट से, वेबसाइट पर बनाए गए की। `subscription_id` के साथ, यह उसी सब्सक्रिप्शन की कीमत है, जो उसे बनाने वाली कुंजी के हिसाब से तय होती है — नया `volume` कितने का पड़ेगा, यह देखने के लिए इसका उपयोग करें। इसमें ऐसे एड्रेस का सक्रियण शामिल नहीं है जो अभी ऑन-चेन मौजूद नहीं है।

### क्वेरी पैरामीटर

<ParamField query="volume" type="number" required>
  एड्रेस पर रखी जाने वाली बैंडविड्थ। 1 से 5,000 तक।
</ParamField>

<ParamField query="subscription_id" type="number">
  आपके किसी सब्सक्रिप्शन की ID। वैकल्पिक।
</ParamField>

### रिस्पॉन्स

<ResponseField name="volume" type="number">
  वह वॉल्यूम जिसके बारे में आपने पूछा
</ResponseField>

<ResponseField name="daily_trx" type="string">
  प्रति 24 घंटे सब्सक्रिप्शन शुल्क
</ResponseField>

<ResponseField name="transfer_trx" type="string">
  डेलिगेट की गई बैंडविड्थ खर्च करने वाले हर ट्रांसफर का शुल्क: `transfer_bw_trx` + `transfer_fee_trx`
</ResponseField>

<ResponseField name="transfer_bw_trx" type="string">
  ट्रांसफर शुल्क का बैंडविड्थ वाला हिस्सा
</ResponseField>

<ResponseField name="transfer_fee_trx" type="string">
  ट्रांसफर शुल्क का फिक्स्ड शुल्क वाला हिस्सा। यदि आपके खाते पर बैंडविड्थ के लिए कोई फिक्स्ड शुल्क नहीं है, तो `"0.000000"`।
</ResponseField>

### उदाहरण

<CodeGroup>
```bash cURL
curl "https://api.tronrental.com/v1/bandwidth/auto/quote?volume=350" \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.get(
    "https://api.tronrental.com/v1/bandwidth/auto/quote",
    headers={"X-API-Key": "your_api_key"},
    params={"volume": 350},
)
print(resp.json())
```

```javascript JavaScript

console.log(await resp.json());
```

### त्रुटियाँ

| स्थिति | कोड | कब |
|--------|------|------|
| `403` | `FORBIDDEN` | API कुंजी के पास `view` स्कोप नहीं है |
| `404` | `NOT_FOUND` | `subscription_id` आपके सब्सक्रिप्शन में से नहीं है |
| `422` | — | `volume` गायब है या 1 – 5,000 से बाहर है |
