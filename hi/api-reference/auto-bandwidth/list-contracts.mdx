## टोकन कॉन्ट्रैक्ट की सूची

ऑटो बैंडविड्थ के लिए आपके जोड़े गए TRC-20 कॉन्ट्रैक्ट लौटाता है। `token: "CUSTOM"` या `"OWN"` वाला सब्सक्रिप्शन `contract` में इनमें से किसी का भी उपयोग कर सकता है। `view` स्कोप आवश्यक है।

USDT और USDD पहले से अंतर्निहित हैं और यहाँ कभी नहीं दिखते: उन्हें `token` से चुनें।

### रिस्पॉन्स

<ResponseField name="contracts" type="array">
  आपके कॉन्ट्रैक्ट।

  <Expandable title="कॉन्ट्रैक्ट ऑब्जेक्ट">
    <ResponseField name="address" type="string">
      कॉन्ट्रैक्ट एड्रेस
    </ResponseField>
    <ResponseField name="symbol" type="string">
      टोकन का सिंबल, जैसा कॉन्ट्रैक्ट बताता है (अधिकतम 16 अक्षर)
    </ResponseField>
    <ResponseField name="name" type="string | null">
      टोकन का नाम, जैसा कॉन्ट्रैक्ट बताता है (अधिकतम 40 अक्षर); यदि कोई नहीं तो `null`
    </ResponseField>
    <ResponseField name="decimals" type="number">
      टोकन के दशमलव स्थान
    </ResponseField>
    <ResponseField name="bandwidth" type="number">
      इस टोकन के एक ट्रांसफर में लगने वाली बैंडविड्थ — सब्सक्रिप्शन के `volume` के लिए एक संकेत
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
`symbol` और `name` कॉन्ट्रैक्ट से ही आते हैं, और कोई भी ऐसा टोकन डिप्लॉय कर सकता है जो खुद को "Tether USD" कहे। टोकन की पहचान हमेशा उसके `address` से करें।
</Warning>

### उदाहरण

<CodeGroup>
```bash cURL

  -H "X-API-Key: your_api_key"

    "https://api.tronrental.com/v1/bandwidth/auto/contracts",

print(resp.json())
```

```javascript JavaScript

```
