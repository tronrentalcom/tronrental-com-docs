## मेरे पैकेज की सूची

आपके सभी ट्रांसफर पैकेज लौटाता है।

### रिस्पॉन्स

पैकेज ऑब्जेक्ट्स का ऐरे। मुख्य फ़ील्ड: `id`, `address`, `package_size`, `quota_total` (पैकेज में ट्रांसफ़र), `quota_used` (सेवा दिए गए ट्रांसफ़र), `subscription_used` (दैनिक सब्सक्रिप्शन शुल्क द्वारा लिए गए ट्रांसफ़र, प्रति दिन एक), `remaining` (`quota_total − quota_used − subscription_used`), `bw_guarantee`, `status`, `created_at`।

### पैकेज स्टेटस

| स्टेटस | विवरण |
|--------|-------------|
| `pending_payment` | इनवॉइस भुगतान की प्रतीक्षा |
| `provisioning` | बैलेंस से भुगतान हो गया, सक्रियण जारी है |
| `active` | एड्रेस मॉनिटर हो रहा है, ट्रांसफर उपलब्ध |
| `completed` | सभी ट्रांसफर उपयोग हो चुके |
| `cancelled` | उपयोगकर्ता द्वारा रद्द |
| `expired` | इनवॉइस समय पर भुगतान नहीं हुआ |
| `manual_review` | सक्रियण का परिणाम स्पष्ट नहीं है; सपोर्ट जाँच करता है, तब तक भुगतान रोका रहता है |
| `failed_refunded` | सक्रियण विफल; राशि बैलेंस में वापस कर दी गई |

### उदाहरण

```bash
curl https://api.tronrental.com/v1/transfer-packages/my \
  -H "X-API-Key: your_api_key"
```
