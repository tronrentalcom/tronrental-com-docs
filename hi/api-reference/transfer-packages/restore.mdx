## वॉलेट वापस लाएँ

एड्रेस पर आपके खाते के संग्रहित पैकेज मुख्य सूची में वापस लाता है। पैकेज स्वयं नहीं बदलते।

### अनुरोध बॉडी

<ParamField body="address" type="string" required>
  वह TRON एड्रेस जिसके संग्रहित पैकेज वापस लाने हैं
</ParamField>

### रिस्पॉन्स

<ResponseField name="address" type="string">
  अनुरोध का एड्रेस।
</ResponseField>

<ResponseField name="archived" type="boolean">
  हमेशा `false`।
</ResponseField>

<ResponseField name="packages" type="number">
  कितने पैकेज वापस आए; `0` — संग्रह में कोई नहीं था।
</ResponseField>

### उदाहरण

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/restore \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress..."
  }'
```

```json Response
{
  "address": "TYourAddress...",
  "archived": false,
  "packages": 3
}
```

### त्रुटियाँ

[मानक रूप](/hi/errors) में, `detail.error.code` के अंतर्गत लौटाई जाती हैं। इनमें से किसी के भी बाद कुछ नहीं बदला होता।

| कोड | स्थिति | कब |
|------|--------|------|
| `PACKAGE_NOT_FOUND` | `404` | एड्रेस पर आपके खाते का कोई पैकेज नहीं है |
