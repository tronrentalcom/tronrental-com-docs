## Transfer Package खरीदें

आपके अकाउंट बैलेंस का उपयोग करके ट्रांसफर पैकेज खरीदता है।

### अनुरोध बॉडी

<ParamField body="address" type="string" required>
  मॉनिटर करने के लिए TRON एड्रेस
</ParamField>

<ParamField body="package_size" type="number">
  पैकेज में ट्रांसफर की संख्या (2 – 10,000)। `single_transfer` `true` न हो तो अनिवार्य। `package_size: 1` को `422` के साथ अस्वीकार किया जाता है — एक ट्रांसफर खरीदने के लिए `single_transfer: true` भेजें।
</ParamField>

<ParamField body="single_transfer" type="boolean" default="false">
  पैकेज के बजाय एक ट्रांसफर खरीदें; तब `package_size` को अनदेखा किया जाता है। मूल्य — [टियर प्राप्त करें](/hi/api-reference/transfer-packages/get-tiers) से `single_transfer_price` (BW Guarantee के साथ `bw_fee_per_transfer` जुड़ता है)।
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  BW Guarantee सक्षम करें
</ParamField>

### रिस्पॉन्स

`package_id`, `status`, `total_price_trx`, `activation_cost_trx` (यदि एड्रेस सक्रिय नहीं था तो उसे सक्रिय करने पर खर्च TRX, अन्यथा `0`) और `total_charged_trx` लौटाता है।

### उदाहरण

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "package_size": 500,
    "bw_guarantee": true
  }'
```

```json Response
{
  "package_id": 101,
  "status": "active",
  "total_price_trx": "1500.0",
  "activation_cost_trx": "0",
  "total_charged_trx": "1500.0"
}
```

<Info>
  आप `POST /api/v1/transfer-packages/buy-invoice` के माध्यम से इनवॉइस द्वारा भी भुगतान कर सकते हैं —
  यह TRX/USDT के लिए एक पेमेंट एड्रेस जनरेट करता है।
</Info>
