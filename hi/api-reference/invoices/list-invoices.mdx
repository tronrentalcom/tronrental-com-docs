## इनवॉइस सूची

आपके इनवॉइस की पेजिनेटेड सूची लौटाता है।

### क्वेरी पैरामीटर

<ParamField query="page" type="number" default="1">
  पेज नंबर
</ParamField>

<ParamField query="status" type="string">
  स्टेटस के अनुसार फ़िल्टर: `pending`, `paid`, `delegated`, `expired`, `failed`
</ParamField>

<ParamField query="from" type="string">
  अवधि का पहला दिन, `YYYY-MM-DD`, सहित। दोनों तिथियाँ न देने पर पूरी सूची।
</ParamField>

<ParamField query="to" type="string">
  अवधि का अंतिम दिन, `YYYY-MM-DD`, **सहित** — आपके टाइम ज़ोन में 23:59:59.999 तक पूरा दिन गिना जाता है।
</ParamField>

<ParamField query="tz" type="string">
  IANA टाइम ज़ोन जिसमें दोनों तिथियाँ पढ़ी जाती हैं, जैसे `Europe/Berlin`। न देने पर UTC।
</ParamField>

<Info>
  रिपोर्ट के विपरीत, सूची पर एक साल की सीमा नहीं है — वह पेज-दर-पेज आती है। दोनों तिथियाँ वैकल्पिक हैं: केवल `from` का अर्थ «उस दिन से आगे», केवल `to` का «उस दिन तक, सहित»।
</Info>

### रिस्पॉन्स

`invoices` ऐरे और `total` काउंट के साथ पेजिनेटेड ऑब्जेक्ट लौटाता है।

### उदाहरण

```bash
curl "https://api.tronrental.com/v1/invoices/my?page=1&status=delegated" \
  -H "X-API-Key: your_api_key"
```
