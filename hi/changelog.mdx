TronRental वेबसाइट, आपके डैशबोर्ड और API में नई सुविधाएँ और बदलाव। टैग से फ़िल्टर करें या RSS फ़ीड की सदस्यता लें।

<Update label="2026-11-18" description="100 TRX टॉप-अप के बाद API कुंजियाँ" tags={["API"]}>
ब्रेकिंग बदलाव: नई API कुंजी तब जारी होती है जब आपके अकाउंट के टॉप-अप कुल मिलाकर कम से कम 100 TRX हो जाते हैं। उससे कम पर `POST /auth/api-keys` जवाब देता है `403 API_KEY_DEPOSIT_REQUIRED`, और `missing_trx` में बाकी रकम होती है। कुल में अब तक जमा हुए सभी टॉप-अप गिने जाते हैं, इसलिए बैलेंस खर्च करने से कुंजी नहीं छिनती। [प्रमाणीकरण](/hi/authentication)
</Update>

<Update label="2026-11-18" description="Transfer Packages को रोकें" tags={["Transfer Packages", "API"]}>
जब कोई एड्रेस ट्रांसफर नहीं भेज रहा हो, तब उस पर अपने सभी पैकेज रोक दें: दैनिक शुल्क बंद हो जाता है, और बचे हुए ट्रांसफर बिना समय-सीमा के सुरक्षित रहते हैं। एड्रेस की फिर ज़रूरत हो तो उन्हें फिर शुरू करें; आपके वेबहुक को `package.paused` और `package.resumed` मिलते हैं। [पैकेज रोकें](/hi/api-reference/transfer-packages/pause)
</Update>

<Update label="2026-11-18" description="Transfer Packages को नए एड्रेस पर ले जाएँ" tags={["Transfer Packages", "API"]}>

</Update>
