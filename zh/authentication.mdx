## API 密钥验证

所有 API 请求需要在 `X-API-Key` 请求头中传入 API 密钥。

```bash
curl https://api.tronrental.com/v1/account/balance \
  -H "X-API-Key: your_api_key"
```

### 获取 API 密钥

1. 在 [tronrental.com](https://tronrental.com/auth/register) 注册
2. 前往[控制面板 → API 密钥](https://tronrental.com/dashboard/api)
3. 点击 **创建 API 密钥**
4. 复制并安全保存您的密钥 — 密钥仅显示一次

只有在确认邮箱地址后，才会创建新的邮箱账户：TronRental 会向该邮箱发送 6 位验证码，输入该验证码后账户才会创建。

### 通过 API 注册（AI 代理）

代理或脚本无需访问网站即可开设账户并创建第一个密钥。为此需要用户的**真实**邮箱：只有使用该邮箱收到的验证码才能创建账户。

**1. 开始注册** — 此时尚未创建账户，系统会向该地址发送 6 位验证码：

```bash
curl -X POST https://api.tronrental.com/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com", "password": "<your-password>", "language": "en"}'
```

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|-------------|
| `email` | string | 是 | 用户的邮箱 — 用户必须能在该邮箱中查看验证码 |
| `password` | string | 是 | 至少 8 个字符，须包含大写字母、小写字母和数字 |
| `language` | string | 否 | 邮件语言，默认为 `en` |

```json
{
  "requires_email_code": true,
  "access_token": null,
  "refresh_token": null
}
```

验证码有效期为 10 分钟。如果已有一个仍然有效的待验证验证码，则不会再发送第二封邮件。如需获取新验证码，请调用 `POST /v1/auth/email-code/send` 并传入 `{"email": "...", "language": "en"}`：之前的验证码随即失效，每个地址每小时最多收到 3 封邮件。

**2. 确认邮箱** — 将验证码与**相同的密码**一起发送（在此步骤之前密码不会被保存）。此操作会创建账户并登录：

```bash
curl -X POST https://api.tronrental.com/v1/auth/email-code/verify \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com", "code": "123456", "password": "<your-password>"}'
```

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|-------------|
| `email` | string | 是 | 与第 1 步相同的邮箱 |
| `code` | string | 是 | 邮件中的 6 位验证码 |
| `password` | string | 注册时必填 | 与第 1 步相同的密码 |
| `referral_code` | string | 否 | 邀请您的用户的推荐码 |

```json
{
  "access_token": "eyJhbGciOi...",
  "refresh_token": "eyJhbGciOi...",
  "session_id": "3f9c...",
  "token_type": "bearer",
  "is_new": true
}
```

**3. 创建 API 密钥**，使用访问令牌（access token）：

```bash
curl -X POST https://api.tronrental.com/v1/auth/api-keys \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-agent"}'
```

响应中的 `key` 字段就是 API 密钥 — 它仅显示一次。

| 状态 | 代码 | 含义 |
|--------|------|---------|
| `400` | `WEAK_PASSWORD` | 密码不符合规则（验证码不会被消耗） |
| `401` | `INVALID_CREDENTIALS` | 验证码错误或已过期 |
| `403` | `EMAIL_DOMAIN_BLOCKED` | 不接受该邮箱服务商 |
| `409` | `EMAIL_EXISTS` | 该邮箱已有账户 — 请直接登录 |
| `429` | `RATE_LIMIT_EXCEEDED` | 请求或邮件过多，或连续 5 次输入错误的验证码 — 请重新获取验证码 |

<Note>
  [MCP 服务器](/zh/resources/mcp-server)通过 `register` 和 `verify_email_code` 工具完成这些步骤。
</Note>

### IP 白名单（可选）

您可以将 API 密钥限制为特定 IP 地址，以提高安全性。在创建或编辑密钥时，可在控制面板中进行配置。

### 密钥权限

每个 API 密钥都带有**权限**（scopes），即它可以执行的操作。您在控制台创建或编辑密钥时选择这些权限。新密钥获得全部读取和写入权限（购买能量和带宽、智能模式、查询余额和历史等），但不包括 `withdraw`：该权限需单独开启，并要求启用 2FA 和 IP 白名单；开启该权限、修改此类密钥的 IP 白名单以及重新生成密钥时，需要用您的 2FA 验证码或通行密钥确认。超出密钥权限的请求会被拒绝，返回 HTTP `403`。完整列表见[列出 API 密钥权限](/zh/api-reference/account/api-key-scopes)。

<Warning>
  请妥善保管您的 API 密钥。请勿在客户端代码、公开仓库或 URL 中暴露密钥。
</Warning>

## Node API 密钥

[Node API](/zh/node-api/overview)——在 `node.tronrental.com` 访问 TRON 全节点——有自己的密钥。您可以在[控制台 → Node API](https://tronrental.com/dashboard/node-api) 中以端点的形式创建它们。
Node API 密钥只能在节点上使用：本 API 会以 `403 NODE_API_KEY_ONLY` 拒绝它。本页介绍的 API 密钥同样不能在节点上使用。参见 [Node API → 端点与密钥](/zh/node-api/authentication)。

## 密钥使用情况与请求日志

每一次使用 API 密钥认证的请求都会保留 7 天：方法、路径、状态码、延迟和客户端 IP。此视图不显示查询参数。打开 [Dashboard → API Keys](https://tronrental.com/dashboard/api) 并展开密钥即可查看其最近的请求；**Last Used** 列显示最近一次调用（认证时的标记最多每 5 分钟更新一次，请求日志则是精确的）。日志仅在控制台中可用——API 密钥无法读取自己的日志。

## 速率限制

速率限制按账户计算，而非按密钥：同一账户的所有密钥共用一份配额。详情请参阅[速率限制](/zh/resources/rate-limits)。

## 错误

身份验证错误将返回 HTTP `401`：

```json
{
  "detail": "Invalid or missing API key"
}
```

如果您的密钥已被禁用或封锁，将收到 HTTP `403`。
