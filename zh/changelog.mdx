TronRental 网站、控制台和 API 的新功能与变更。可按标签筛选，或订阅 RSS 源。

<Update label="2026-11-18" description="充值累计 100 TRX 后可创建 API 密钥" tags={["API"]}>
破坏性变更：账户充值累计达到 100 TRX 后才会签发新的 API 密钥。未达到时，`POST /auth/api-keys` 返回 `403 API_KEY_DEPOSIT_REQUIRED`，`missing_trx` 中给出还需充值的金额。累计金额计入所有曾经到账的充值，因此花掉余额不会收回密钥。[身份验证](/zh/authentication)
</Update>

<Update label="2026-11-18" description="暂停转账套餐" tags={["Transfer Packages", "API"]}>
地址暂时不发转账时，可暂停您在该地址上的全部套餐：每日扣费停止，剩余转账次数保留且不限期限。需要再次使用该地址时恢复即可；Webhook 会收到 `package.paused` 和 `package.resumed`。[暂停套餐](/zh/api-reference/transfer-packages/pause)
</Update>

<Update label="2026-11-18" description="将转账套餐迁移到新地址" tags={["Transfer Packages", "API"]}>
发送转账的钱包更换后，可将旧地址上的全部套餐连同剩余转账次数迁移到新地址。迁移免费且不限次数，Webhook 会收到 `package.moved`。[迁移套餐](/zh/api-reference/transfer-packages/move)
</Update>

<Update label="2026-11-17" description="Node API 套餐降价" tags={["Node API"]}>
Node API 套餐和超出配额的费用现已降低。当前价格始终列在套餐页面和 API 的套餐目录中。[套餐与计费](/zh/node-api/plans)
</Update>

<Update label="2026-11-16" description="在 AI 助手聊天中提现和充值" tags={["Withdrawals", "Payments"]}>
让 AI 助手提现 TRX 或 USDT，它会填好提现卡片：核对地址和金额后，直接在卡片中用 2FA 验证码或通行密钥确认，验证码不会传给 AI。询问如何充值，卡片会显示您的充值地址及其二维码。[AI 助手](https://tronrental.com/zh/ai-assistant)
</Update>

<Update label="2026-11-16" description="提现 Webhook 事件" tags={["Withdrawals", "API"]}>
从余额发起的提现发出后，Webhook 会收到 `withdrawal.completed`；提现被拒绝且金额退回余额时，会收到 `withdrawal.failed`。无论提现是通过 API、网站还是 Telegram 机器人发起的。[Webhook 概览](/zh/api-reference/webhooks/overview)
</Update>

<Update label="2026-11-16" description="自动补充规则和 Auto-Bandwidth 订阅不再限量" tags={["Auto-Refill", "Auto-Bandwidth"]}>
账户现在可以拥有任意数量的自动补充规则和 Auto-Bandwidth 订阅，无论是启用还是暂停状态；此前 20 个的上限已取消。[自动补充概述](/zh/api-reference/auto-refill/overview)
</Update>

<Update label="2026-11-13" description="AI 助手" tags={["Energy", "Bandwidth"]}>
向 TronRental AI 助手询问当前的能量和带宽价格，检查地址，并了解 USDT 转账能省多少。它会准备一张卡片，用于订购能量或带宽，或开通 Auto-Bandwidth、自动补充、Smart Mode 或 Energy Broadcaster；在您按下卡片中的按钮之前，不会购买或开通任何服务。没有账户也可以提问、检查地址并获取待支付的账单。[AI 助手](https://tronrental.com/zh/ai-assistant)
</Update>

<Update label="2026-11-13" description="Auto-Bandwidth API" tags={["Auto-Bandwidth", "API"]}>
通过 API 管理 Auto-Bandwidth：创建、修改、暂停和删除订阅，订阅前获取报价，并添加您自己的 TRC-20 代币合约。[自动带宽概述](/zh/api-reference/auto-bandwidth/overview)
</Update>

<Update label="2026-11-13" description="订单失败原因及退款金额" tags={["Energy", "Bandwidth", "API"]}>
失败的订单现在会说明原因：订单和 `order.updated` Webhook 中的 `fail_reason` 说明出了什么问题以及是否值得重试，`refunded_trx` 显示退回余额的金额。[查询订单](/zh/api-reference/orders/get-order)
</Update>

<Update label="2026-11-11" description="提前回收带宽订单" tags={["Bandwidth", "API"]}>
地址完成租用所为的那笔转账后，可通过 `POST /orders/{order_id}/reclaim` 立即收回订单的带宽，无需等到租期结束。未使用的时间不退款，重复调用是安全的。[提前回收订单](/zh/api-reference/orders/reclaim-order)
</Update>

<Update label="2026-11-09" description="购买能量的价格上限" tags={["Energy", "API"]}>
`POST /energy/buy` 支持可选参数 `max_price_trx`：传入报价中的 `total_trx`，若订单价格更高，会在扣除任何费用之前以 `409 PRICE_CHANGED` 拒绝。能量报价按与订单扣费完全相同的方式舍入到 SUN，`Idempotency-Key` 请求头让购买的重试变得安全。[购买能量](/zh/api-reference/energy/buy-energy)
</Update>

<Update label="2026-11-03" description="所有订单、激活和账单的 Webhook" tags={["API"]}>
现在，账户的每一笔能量和带宽订单都会发送 `order.updated`，无论订单是通过 API、网站、Telegram 机器人还是自动补充下的；可用 `source` 字段区分。新事件 `activation.updated` 和 `invoice.updated` 报告已结算的地址激活和账单状态变化。[Webhook 概览](/zh/api-reference/webhooks/overview)
</Update>

<Update label="2026-11-03" description="Smart Mode：下一笔转账后自动关闭" tags={["Smart Mode", "API"]}>
Smart Mode 可以只服务地址的下一笔 USDT 转账，然后自动暂停；需要时随时恢复。在 API 中，向激活接口传入 `stop_after_transfer: true`。[激活](/zh/api-reference/smart-mode/activate)
</Update>

<Update label="2026-10-30" description="Energy Broadcaster 支持 TRC-20 代币、兑换和合约调用" tags={["Broadcaster"]}>
Energy Broadcaster 现在不再只服务于 USDT：其他 TRC-20 代币的转账、SunSwap 上的兑换以及对其他智能合约的调用都能获得能量和带宽，TRX 转账则能获得带宽。每次调用的费用根据其模拟结果计算；较少见的代币、兑换和合约调用在您账户的限额内提供服务，并可在 broadcaster 设置中关闭。可选的回滚保护可在发送前拦截会失败的调用。[Energy Broadcaster](https://tronrental.com/zh/energy-broadcaster)
</Update>

<Update label="2026-10-29" description="使用邮箱验证码确认注册" tags={["API"]}>
通过邮箱注册的新账户，需使用发送到该邮箱的 6 位验证码确认。对通过 API 注册的脚本而言，这是不兼容变更：`POST /auth/register` 现在返回 `requires_email_code: true`，而不再返回令牌，账户由 `POST /auth/email-code/verify` 创建。现有账户不受影响。[身份验证](/zh/authentication)
</Update>

<Update label="2026-10-29" description="带宽租赁最短 5 分钟" tags={["Bandwidth", "API"]}>
可租用 5 至 59 分钟之间任意时长的带宽，价格在小时费率的基础上给予折扣，而不再只能按小时或按天租用。新的报价接口会返回准确金额，可选的 `max_price_trx` 会拒绝在报价后价格已发生变化的购买。[带宽报价](/zh/api-reference/bandwidth/quote)
</Update>

<Update label="2026-10-28" description="能量和带宽最低 1 单位起" tags={["Energy", "Bandwidth", "API"]}>
最低订单现为 1 单位能量或带宽，低于通常的市场最低值：网站、API、Telegram 机器人和自动补充规则均适用。能量的账单和即时购买仍从 32,000 起。[购买能量](/zh/api-reference/energy/buy-energy)
</Update>

<Update label="2026-10-28" description="Auto-Bandwidth" tags={["Auto-Bandwidth"]}>
为某个地址开启 Auto-Bandwidth 后，其转出交易会获得带宽，网络便不会为此燃烧 TRX。它适用于 USDT、TRX、USDD 和任意 TRC-20 代币；当该地址的每日免费带宽足够时会等待，并按天加上每笔使用了我们带宽的转账计费。[Auto-Bandwidth](https://tronrental.com/zh/auto-bandwidth)
</Update>

<Update label="2026-10-27" description="具有 withdraw 权限的 API 密钥需通过 2FA 确认" tags={["API", "Withdrawals"]}>
在 API 密钥上开启 `withdraw` 权限、修改此类密钥的 IP 白名单以及重新生成该密钥，现在需要用您的 2FA 验证码或通行密钥确认。此前签发的密钥继续有效。[列出 API 密钥权限](/zh/api-reference/account/api-key-scopes)
</Update>

<Update label="2026-10-20" description="提现的安全重试" tags={["Withdrawals", "API"]}>
`POST /account/withdrawal` 接受可选的 `Idempotency-Key` 请求头：使用相同密钥重复发起请求时，返回的是最初的那笔提现，而不会再创建一笔提现。带此请求头时，两次提现之间的间隔为 5 秒，而不是 60 秒。[提现](/zh/api-reference/account/withdrawals)
</Update>

<Update label="2026-10-16" description="转账套餐：每个套餐至少 2 笔转账" tags={["Transfer Packages", "API"]}>
