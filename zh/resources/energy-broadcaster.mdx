## 这是什么

Energy Broadcaster 是一个 TRON 节点地址，你只需在钱包（TronLink、TokenPocket）或自己的后端中设置一次。签名交易经过它时，broadcaster 会计算发送方所需的能量和带宽，先代理给发送方，然后才广播交易。费用从你的 TronRental 余额扣除，因此发送方地址无需为能量和带宽准备 TRX。

私钥始终由你掌握：broadcaster 收到的是已签名的交易，并原样广播。

## 接入

1. 在 [tronrental.com](https://tronrental.com) 充值 TRX 余额。
2. 在控制台的 [Broadcast](https://tronrental.com/dashboard/broadcast) 页面创建 broadcaster，你会得到一个保密的广播 URL——每个钱包一个，统计数据互不混淆。
3. 在钱包的网络设置中把该 URL 设为节点，或在你的服务器上通过 HTTP 或 gRPC 使用它（gRPC 的服务器、端口和 TLS 设置显示在控制台中）。

<Warning>
  广播 URL 相当于密码：任何拿到它的人都能消耗你的余额。如果泄露，请在控制台关闭该 broadcaster 并新建一个。
</Warning>

## 覆盖范围

| 交易 | broadcaster 代理的资源 |
|---|---|
| USDT、USDC、USDD 和 A7A5 转账 | 能量和带宽 |
| SunSwap 兑换 | 能量和带宽，在账户限额之内 |
| 其他 TRC-20 代币转账及对任何其他智能合约的调用 | 能量和带宽，在账户限额之内 |
| TRX 转账 | 带宽 |

对于兑换或合约调用，broadcaster 会在自己的节点上模拟已签名的交易，并留有余量地代理发送方需要支付的能量。如果合约部署者承担部分能量，只代理发送方的那一部分。

### 限额

兑换和合约调用在你账户的限额之内处理：每次调用最多 1,000,000 能量；其他代币转账和其他合约调用另有每日能量限额，由你的所有 broadcaster 共用（按 UTC 日计算）。超出限额的调用会原样广播——不代理、不扣费。如需调整限额，请联系客服。

## 不覆盖的内容

- **以 TRX 收取的费用。** TRON 网络有些费用以 TRX 而非能量或带宽收取：向新地址发送 TRX 或 TRC-10 代币时的激活费（约 1.1 TRX）、多重签名交易（+1 TRX）、memo（+1 TRX）以及修改账户权限（100 TRX）。代理资源无法支付这些费用，此类交易需要发送方地址自备 TRX。
- **部署智能合约。**
- **其他不含智能合约的交易**（TRC-10 转账、质押、投票）——原样通过节点。
- **不计入发送方地址上已有的能量：** broadcaster 始终代理交易所需的全部能量。

## broadcaster 设置

所有设置都在 [Broadcast](https://tronrental.com/dashboard/broadcast) 页面，每个 broadcaster 单独设置。

| 设置 | 作用 |
|---|---|
| **拦截交易** / **放行** | 余额不足以支付能量时：*拦截交易*——拒绝该交易，发送方不会燃烧 TRX；*放行*——不代理直接广播，网络费用由发送方支付。 |
| **代理带宽** | 开启（默认）——broadcaster 也会给带宽不足的发送方代理带宽。关闭——带宽由发送方自行支付，没有免费带宽时燃烧 TRX。 |
| **合约调用** | 关闭时，兑换、其他代币转账和合约调用不带能量广播，不扣费。USDT、USDC、USDD、A7A5 和 TRX 转账不受影响。 |
| **回滚保护** | 开启合约调用时显示。如果模拟显示调用会失败，broadcaster 会在下一个区块再检查一次；仍然失败则不广播该交易，钱包收到错误，不扣费，也不燃烧 TRX。如果几秒内没有等到下一个区块，或我们的节点不可用，该调用会像关闭保护时一样发出。极少数情况下会拒绝本可成功的调用——例如依赖一秒前发出、尚未进入区块的 `approve` 的调用；几秒后重新发送即可。关闭时，会失败的调用不代理直接广播，费用由发送方支付。 |
| **暂停** | 广播 URL 完全停止响应钱包（包括读取余额），直到你恢复。 |

经过 broadcaster 的转账、兑换和合约调用都会在控制台显示结果：代理并扣费的能量，或不带能量发出的原因。
