## 什么是 MCP？

[Model Context Protocol (MCP)](https://modelcontextprotocol.io) 是一个开放标准，允许 AI 代理（Claude Code、Cursor、Windsurf 等）通过统一接口与外部服务交互。

TronRental 提供官方 MCP 服务器，使 AI 代理能够完整访问能量购买 API — 从查询价格到完成购买。

## 远程服务器（使用 TronRental 登录）

主要的连接方式。智能体使用 `https://mcp.tronrental.com/mcp`；你通过 TronRental 登录，选择智能体可以做什么、每天最多花多少。无需复制 API 密钥。详情见 [智能体 OAuth](/zh/resources/oauth-for-agents)。

**Claude (web / desktop):** [添加到 Claude](https://claude.ai/new?modal=add-custom-connector&connectorName=TronRental&connectorUrl=https%3A%2F%2Fmcp.tronrental.com%2Fmcp#settings/customize-connectors) — 或在 Settings → Connectors → Add custom connector 中填入上面的地址。然后 Connect 并登录。

**ChatGPT (web):** Plugins → Add → Add Custom MCP Server → 粘贴地址 → Authentication 保持 OAuth → 创建 → 使用 TronRental 登录。如果没有该选项，请在设置中开启开发者模式。

```bash Claude Code
claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp
# then: /mcp → tronrental → Authenticate
```

```bash Codex
codex mcp add tronrental --url https://mcp.tronrental.com/mcp
# if the browser does not open: codex mcp login tronrental
```

```json Cursor (~/.cursor/mcp.json)
{ "mcpServers": { "tronrental": { "url": "https://mcp.tronrental.com/mcp" } } }
```

服务器只列出你的连接允许的工具。购买前，智能体先报价并把价格作为 `max_price_trx` 传入，同时发送 `idempotency_key`，重试永远不会重复扣款。

智能体设置指南: [tronrental.com/skill.md](https://tronrental.com/skill.md).

## 本地包（API 密钥）

添加到您的 AI 代理：

```bash
npx -y @tronrental-com/mcp-server
```

### Claude Code

```bash
# 无需 API 密钥（代理将使用您的邮箱注册账户）
claude mcp add tronrental -- npx -y @tronrental-com/mcp-server

# 使用 API 密钥
claude mcp add tronrental -e TRONRENTAL_API_KEY=your_key -- npx -y @tronrental-com/mcp-server
```

### Cursor / Windsurf

添加到您的 MCP 配置：

```json
{
  "mcpServers": {
    "tronrental": {
      "command": "npx",
      "args": ["-y", "@tronrental-com/mcp-server"],
      "env": {
        "TRONRENTAL_API_KEY": "your_key"  // pragma: allowlist secret
      }
    }
  }
}
```

`TRONRENTAL_API_KEY` 环境变量是可选的。如果未提供，代理可以通过 MCP 工具注册新账户，并使用该账户的登录令牌工作；账户累计充值达到 100 TRX 后才会发放 API 密钥。代理会询问您的邮箱：TronRental 会向该邮箱发送 6 位验证码，只有在您把验证码提供给代理后，账户才会创建。

## 可用工具

MCP 服务器提供 12 个工具：

| 工具 | 认证 | 描述 |
|------|------|------|
| `get_prices` | 无需 | 当前能量和带宽价格 |
| `calculate_savings` | 无需 | 计算节省：燃烧成本与租赁成本对比 |
| `register` | 无需 | 开始注册：向用户邮箱发送 6 位验证码 |
| `verify_email_code` | 无需 | 确认验证码并创建账户 |
| `resend_email_code` | 无需 | 重新发送验证码（已过期或未收到） |
| `login` | 无需 | 登录现有账户 |
| `create_api_key` | 令牌 | 创建 API 密钥（累计充值 100 TRX 后） |
| `get_deposit_address` | API 密钥或令牌 | 获取 TRX 充值地址 |
| `get_balance` | API 密钥或令牌 | 查询账户余额 |
| `buy_energy` | API 密钥或令牌 | 为 TRON 地址购买能量 |
| `get_order` | API 密钥或令牌 | 查询订单状态 |
| `regenerate_deposit_address` | API 密钥或令牌 | 生成新的充值地址 |

## 典型流程

### 新用户（无 API 密钥）

1. `get_prices` — 查看当前价格
2. `calculate_savings` — 根据用户的转账量计算节省
3. `register` — 用户的真实邮箱和密码；系统向该邮箱发送 6 位验证码
4. 用户在邮件中查看验证码并提供给代理
5. `verify_email_code` — 创建账户并登录
6. `get_deposit_address` — 获取充值地址，用户发送 TRX 或 USDT
7. `get_balance` — 确认充值到账
8. `buy_energy` — 购买能量
9. `get_order` — 确认委托
10. `create_api_key` — 累计充值达到 100 TRX 后：密钥可在会话结束后保留访问权限（将其设置为 `TRONRENTAL_API_KEY`）

<Note>
  代理绝不会编造邮箱地址：没有来自真实邮箱的验证码，就不会创建账户。验证码有效期为 10 分钟；`resend_email_code` 会发送新的验证码（每小时最多 3 封邮件）。在获得密钥之前，工具使用登录令牌；令牌有效期为 1 小时，之后代理会再次调用 `login`。累计充值不足 100 TRX 时，`create_api_key` 会告知还需充值多少。 通过普通 HTTP 完成相同步骤的说明见[身份验证](/zh/authentication)。
</Note>

### 现有用户（已设置 API 密钥）

1. `get_balance` — 查询余额
2. `buy_energy` — 购买能量
3. `get_order` — 确认委托

## 能量数量

| 场景 | 能量 |
|------|------|
| 接收方已持有 USDT | 65,000 |
| 接收方从未持有 USDT | 131,000 |
| 最小订单 | 1 |
| 最大订单 | 5,000,000 |

时长始终为 `1h` — 能量在几秒内即被使用，1 小时是租赁窗口。
