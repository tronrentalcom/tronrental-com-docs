连接获得你在授权页面上勾选的权限。API 密钥获得你在控制台创建它时设置的权限范围。MCP 服务器只列出这些权限开放的工具（`tools/list`），并且每次调用都会在服务器上再次检查。

| 权限 | 开放的功能 | 已连接的应用（OAuth） | API 密钥 |
|---|---|---|---|
| `view` | 余额、历史、报表、订单、报价、地址检查、广播器配额和事件、质押仓位、Node API 套餐和用量 | ✓ | ✓ |
| `deposit_view` | 充值地址、充值记录、其他币种的充值 | ✓ | ✓ |
| `buy_energy` | 购买能量、激活地址、能量自动充值、发票 | ✓ | ✓ |
| `buy_bandwidth` | 购买和回收带宽、带宽自动充值、自动带宽 | ✓ | ✓ |
| `smart_mode` | Smart Mode | ✓ | ✓ |
| `transfer_packages` | 转账套餐 | ✓ | ✓ |
| `energy_resale` | Energy Resale | ✓ | ✓ |
| `broadcaster` | 创建、修改和删除广播 URL | ✓ | ✓ |
| `staking` | 质押、解除质押、领取奖励、自动领取奖励 | ✓ 仅账户所有者 | ✓ 仅账户所有者 |
| `node_api_plan` | 购买 Node API 套餐、开始试用、自动续费 | ✓ 仅账户所有者 | ✓ 仅账户所有者 |
| `recurring` | 开启自动执行的支出——见下文 | ✓ 默认关闭 | 不需要 |
| `withdraw` | 提现 | **永不** | ✓ 需开启 2FA 并设置 IP 白名单 |

## 自动执行的支出（`recurring`）

有些工具在调用时并不花钱，而是开启之后持续进行的支出：自动充值、自动带宽、Smart Mode、Energy Resale、广播 URL、Node API 自动续费。对于已连接的应用，创建或修改它们除了产品本身的权限外还需要 `recurring`。关闭和删除永远不需要它。暂停 Smart Mode 需要，因为同一个工具也用于恢复它。

<Warning>
  自动执行的支出**不计入每日上限**，并且**在你断开应用后仍会继续**。请在控制台的对应页面关闭它。
</Warning>

## 首次充值之前

在账户累计充值达到 100 TRX 之前，授权页面只授予 `view` 和 `deposit_view`，并显示还需充值多少。充值后，再次连接应用并勾选更多权限——更新的是同一个连接。

## 团队账户

在授权页面上，你选择应用在哪个账户上工作：你自己的账户，或你管理 API 密钥的团队账户。团队成员只能授予其角色拥有的权限，不能授予 `staking` 或 `node_api_plan`，也不能取消每日上限（`OAUTH_UNCAPPED_OWNER_ONLY`）。

## API 密钥还是已连接的应用

| | 已连接的应用（OAuth） | API 密钥 |
|---|---|---|
| 适合谁 | 使用智能体或你的应用的人 | 你自己的服务器和脚本 |
| 每日消费上限 | 默认 100 TRX | 无 |
| 购买时的 `max_price_trx` | 必填 | 可选 |
| 提现 | 永不 | 需要 `withdraw`、2FA 和 IP 白名单 |
| 订单 `source` | `agent` | `api` |

账户累计充值达到 100 TRX 后才会发放 API 密钥——见[身份验证](/zh/authentication)。
