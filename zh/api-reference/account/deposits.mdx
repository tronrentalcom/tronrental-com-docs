## 获取充值地址

<div>
  `GET /api/v1/account/deposit`
</div>

返回您的专属充值地址和接受的币种。

```bash
curl https://api.tronrental.com/v1/account/deposit \
  -H "X-API-Key: your_api_key"
```

```json
{
  "deposit_address": "TYourDepositAddress...",
  "accepted_currencies": ["TRX", "USDT"],
  "usdt_to_trx_rate": "26.5",
  "trx_usd_rate": "0.234"
}
```

## 充值列表

<div>
  `GET /api/v1/account/deposits`
</div>

返回您的充值历史。

```bash
curl https://api.tronrental.com/v1/account/deposits \
  -H "X-API-Key: your_api_key"
```

### 查询参数

<ParamField query="from" type="string">
  周期的第一天，`YYYY-MM-DD`，含当天。两个日期都不传则返回完整列表。
</ParamField>

<ParamField query="to" type="string">
  周期的最后一天，`YYYY-MM-DD`，**含当天** —— 按您的时区计到 23:59:59.999。
</ParamField>

<ParamField query="tz" type="string">
  解析这两个日期所用的 IANA 时区，例如 `Europe/Berlin`。不传则按 UTC。
</ParamField>

<Info>
  与报表不同，列表没有一年的上限——它是分页的。两个日期都可选：只传 `from` 表示「从该日起」，只传 `to` 表示「截至该日（含）」。
</Info>

### 充值状态

| 状态 | 描述 |
|--------|-------------|
| `pending` | 已检测到交易，等待确认 |
| `confirmed` | 已入账到您的余额 |
| `expired` | 充值地址已过期 |

<Info>
  充值自动到账。TRX 充值按 1:1 入账。USDT 充值按当前市场汇率转换为 TRX。
</Info>
