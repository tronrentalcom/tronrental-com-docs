## 创建提现

<div>
  `POST /api/v1/account/withdrawal`
</div>

将 TRX 提现到任意 TRON 地址。手续费：1 TRX。

### 请求体

<ParamField body="to_address" type="string" required>
  目标 TRON 地址
</ParamField>

<ParamField body="amount_trx" type="string" required>
  提现金额，以 TRX 计
</ParamField>

<ParamField body="currency" type="string">
  `TRX`（默认）或 `USDT`。使用 `USDT` 时，`amount_trx` 填写要发送的 USDT 金额。
</ParamField>

<ParamField body="totp_code" type="string">
  双重验证码（如已启用双重验证）
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
  可选，最多 64 个字符。每次新的提现都发送一个新键（例如 UUID）；重试未收到响应的请求时使用同一个键——重试会返回第一次的提现，而不会创建第二笔。
</ParamField>

### 安全重试

- 同一个键且 `to_address`、`amount_trx`、`currency` 相同时，返回 `200` 及第一次请求创建的提现（当前状态），不会重复扣款。
- 同一个键但请求体不同，将以 `422` 和代码 `IDEMPOTENCY_KEY_REUSED` 拒绝；键超过 64 个字符，以 `422` 和 `IDEMPOTENCY_KEY_TOO_LONG` 拒绝。键仅在您的账户内有效，且不会过期——切勿将同一个键用于另一笔提现。
- 同一时间只能有一笔未完成的提现（`pending`、`scheduled` 或 `processing`）：存在时再次请求会收到 `400` 和 `You already have a pending withdrawal`。
- 使用 `Idempotency-Key` 创建提现后，5 秒后即可创建下一笔；不带该请求头时，间隔仍为 60 秒（`429`，参见[速率限制](/resources/rate-limits)）。

### 示例

```bash
curl -X POST https://api.tronrental.com/v1/account/withdrawal \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 7f9c2b1e-5d4a-4c1e-9b3f-2a6d8e0c4f11" \
  -d '{
    "to_address": "TDestinationAddress...",
    "amount_trx": "100"
  }'
```

```json Response
{
  "id": 56,
  "to_address": "TDestinationAddress...",
  "amount_trx": "100.00",
  "fee_trx": "1.00",
  "status": "completed",
  "tx_hash": "a1b2c3d4e5f6...",
  "created_at": "2026-03-05T12:00:00Z"
}
```

## 提现列表

<div>
  `GET /api/v1/account/withdrawals`
</div>

返回您的提现历史。

```bash
curl https://api.tronrental.com/v1/account/withdrawals \
  -H "X-API-Key: your_api_key"
```

```json Response
[
  {
    "id": 56,
    "to_address": "TDestinationAddress...",
    "amount_trx": "100.00",
    "fee_trx": "1.00",
    "status": "completed",
    "tx_hash": "a1b2c3d4e5f6...",
    "created_at": "2026-03-05T12:00:00Z"
  }
]
```

### 提现状态

| 状态 | 描述 |
|--------|-------------|
| `pending` | 已排队处理 |
| `completed` | TRX 已发送，tx_hash 可用 |
| `failed` | 失败，金额已退回 |
| `scheduled` | 在网页后台创建；发送前等待 20 秒取消窗口 |
| `processing` | 正在发送到网络 |
| `cancelled` | 用户在取消窗口内取消；金额已退回 |

通过 API 密钥创建的提现会立即发送，不会经过 `scheduled`。在网页后台创建的记录带有 `execute_after` 字段——若未提前取消，即为发送时刻。

### 更改邮箱后的安全锁定

账户邮箱更改后的 24 小时内，创建提现会被拒绝，返回 `403` 和错误码 `WITHDRAWAL_EMAIL_COOLDOWN`。响应中包含 `retry_after_seconds`，即距离提现解锁还剩多少秒：

```json Response
{
  "detail": {
    "error": {
      "code": "WITHDRAWAL_EMAIL_COOLDOWN",
      "message": "Withdrawals are temporarily blocked after an email change",
      "retry_after_seconds": 79214
    }
  }
}
```

该锁定适用于所有会话类型，包括拥有 `withdraw` 权限的 API 密钥。如果您本人没有更改账户邮箱，请立即联系客服。
