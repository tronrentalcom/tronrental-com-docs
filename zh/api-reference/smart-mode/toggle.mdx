## 切换订阅状态

暂停活跃的订阅或恢复已暂停的订阅。暂停期间不收取费用，也不监控转账。

### 路径参数

<ParamField path="sub_id" type="number" required>
  订阅 ID
</ParamField>

### 响应

返回 `paused`：切换后的订阅状态 —— `true` 表示已暂停，`false` 表示已恢复。[订阅列表](/zh/api-reference/smart-mode/list-subscriptions) 中的每个订阅也有同一字段。

### 示例

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/42/toggle \
  -H "X-API-Key: your_api_key"
```

```json Response
{
  "paused": true
}
```
