## 激活智能模式

为指定地址启动自动能量投递。首笔每日费用将立即扣除。

### 请求体

<ParamField body="address" type="string" required>
  要监控的 TRON 地址
</ParamField>

<ParamField body="label" type="string">
  此订阅的可选标签
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  启用带宽保障（每笔转账 +0.3 TRX）
</ParamField>

### 响应

返回 `subscription_id`——所创建订阅的 ID。订阅本身请通过 [订阅列表](/zh/api-reference/smart-mode/list-subscriptions) 获取。

### 示例

```bash
curl -X POST https://api.tronrental.com/v1/smart-mode/activate \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "label": "Main wallet",
    "bw_guarantee": true
  }'
```

```json Response
{
  "subscription_id": 42
}
```

<Warning>
  该地址不能同时拥有活跃的转账套餐。
  智能模式和转账套餐在同一地址上互斥。
</Warning>
