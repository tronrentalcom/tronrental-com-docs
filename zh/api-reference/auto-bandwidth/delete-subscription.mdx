## 删除订阅

删除一个订阅。我们会停止监控该地址，并在几秒之内收回已委托给它的带宽；该地址随即可用于新的订阅。在删除之前用掉我们带宽的转账仍会收费。需要 `buy_bandwidth` 权限。

如果只想暂时停止而不丢失设置，请改为用 `enabled: false` [暂停订阅](/zh/api-reference/auto-bandwidth/update-subscription)。

### 路径参数

<ParamField path="sub_id" type="number" required>
  订阅 ID——创建或列出订阅返回的 `id`
</ParamField>

### 响应

<ResponseField name="id" type="number">
  已删除订阅的 ID
</ResponseField>

<ResponseField name="status" type="string">
  `deleted`
</ResponseField>

### 示例

<CodeGroup>
```bash cURL
curl -X DELETE https://api.tronrental.com/v1/bandwidth/auto/42 \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.delete(
    "https://api.tronrental.com/v1/bandwidth/auto/42",
    headers={"X-API-Key": "your_api_key"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/bandwidth/auto/42", {
  method: "DELETE",
  headers: { "X-API-Key": "your_api_key" },
});
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "id": 42,
  "status": "deleted"
}
```

### 错误

| 状态 | 代码 | 触发条件 |
|--------|------|------|
| `403` | `FORBIDDEN` | API 密钥缺少 `buy_bandwidth` 权限 |
| `404` | `NOT_FOUND` | 您的账户中没有该 ID 的订阅（或已被删除） |

```json
{
  "detail": {
    "error": {
      "code": "NOT_FOUND",
      "message": "Auto-Bandwidth subscription not found"
    }
  }
}
```
