## 删除能量规则

删除一条规则。该规则不再进行任何补充，该地址也可以重新用于新的能量规则。已购买的能量不会被收回：这些租赁会持续到其一小时期满。以往的补充订单会保留在您的订单历史中。需要 `buy_energy` 权限。

如果只想暂时停止补充而不丢失规则，请改为[暂停规则](/zh/api-reference/auto-refill/update-energy-rule)。

### 路径参数

<ParamField path="rule_id" type="number" required>
  规则 ID——创建或列出能量规则时返回的 `id`
</ParamField>

### 响应

<ResponseField name="status" type="string">
  `ok`
</ResponseField>

### 示例

<CodeGroup>
```bash cURL
curl -X DELETE https://api.tronrental.com/v1/energy/auto-refill/12 \
  -H "X-API-Key: your_api_key"
```

```python Python
import requests

resp = requests.delete(
    "https://api.tronrental.com/v1/energy/auto-refill/12",
    headers={"X-API-Key": "your_api_key"},
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/energy/auto-refill/12", {
  method: "DELETE",
  headers: { "X-API-Key": "your_api_key" },
});
console.log(await resp.json());
```
</CodeGroup>


### 错误

| 状态 | 代码 | 触发条件 |
|--------|------|------|
| `403` | `FORBIDDEN` | API 密钥缺少 `buy_energy` 权限 |
| `404` | `NOT_FOUND` | 您的账户中没有此 ID 的能量规则（或已被删除） |
| `409` | `AUTOREFILL_IN_PROGRESS` | 该规则的一次补充正在购买中——请一分钟后重试 |

```json
{
  "detail": {
    "error": {
      "code": "NOT_FOUND",
      "message": "Auto-refill rule not found"
    }
  }
}
```
