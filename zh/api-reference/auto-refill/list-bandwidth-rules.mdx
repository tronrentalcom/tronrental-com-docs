## 列出带宽规则

返回您账户中的全部带宽自动补充规则，最早创建的在前。不包含已删除的规则。需要 `view` 权限。

### 响应

<ResponseField name="rules" type="array">
  您的带宽规则。

  <Expandable title="规则对象">
    <ResponseField name="id" type="number">
      规则 ID——在编辑和删除路径中使用
    </ResponseField>
    <ResponseField name="target_address" type="string">
      规则持续供给的地址
    </ResponseField>
    <ResponseField name="label" type="string | null">
      您为规则起的名称
    </ResponseField>
    <ResponseField name="threshold_bandwidth" type="number">
      可用带宽低于此值时，规则会购买
    </ResponseField>
    <ResponseField name="add_volume" type="number">
      每次补充购买的带宽
    </ResponseField>
    <ResponseField name="duration" type="string">
      每次补充的租赁时长——`1h` 或 `1d`
    </ResponseField>
    <ResponseField name="status" type="string">
      `active`、`paused` 或 `stopped_insufficient_balance`——参见[规则状态](/api-reference/auto-refill/overview#rule-status)
    </ResponseField>
    <ResponseField name="stopped_reason" type="string | null">
      规则被暂停或停止的原因：`insufficient_balance`、`order_failed`、`activation_failed` 或 `invalid_params`。没有原因时为 `null`。
    </ResponseField>
    <ResponseField name="consecutive_failures" type="number">
      连续失败的补充次数。达到 5 时规则会被暂停；一次成功的补充会将其重置为 0。
    </ResponseField>
    <ResponseField name="last_checked_at" type="string | null">
      我们最近一次读取该地址的时间（ISO 8601，UTC）。首次检查之前为 `null`。
    </ResponseField>
    <ResponseField name="last_available_bandwidth" type="number | null">
      那次检查时该地址的可用带宽，包括免费带宽。首次成功读取之前为 `null`。
    </ResponseField>
    <ResponseField name="last_refill_at" type="string | null">
      最近一次补充的时间。从未补充过时为 `null`。
    </ResponseField>
    <ResponseField name="refill_count" type="number">
      自规则创建以来成功补充的次数
    </ResponseField>
    <ResponseField name="total_spent_trx" type="string">
      这些补充累计花费的 TRX
    </ResponseField>
    <ResponseField name="created_at" type="string">
      规则的创建时间（ISO 8601，UTC）
    </ResponseField>
    <ResponseField name="estimated_cost_per_refill_trx" type="string | null">
      按当前价格计算的您账户补充一次的全部价格，已包含固定手续费。如需激活地址，激活费用另行收取。价格暂时不可用时为 `null`。
    </ResponseField>
    <ResponseField name="volume_below_threshold" type="boolean">
      当 `add_volume` 小于 `threshold_bandwidth` 时为 `true`。此时一次补充可能无法让地址回到阈值以上，只要地址还在消耗，规则就会不断购买——参见[概述中的警告](/api-reference/auto-refill/overview#choosing-the-numbers)。
    </ResponseField>
  </Expandable>
</ResponseField>
