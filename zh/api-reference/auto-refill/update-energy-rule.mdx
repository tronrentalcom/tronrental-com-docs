## 更新能量规则

修改规则的阈值、数量或标签，或者暂停、恢复规则。只需发送要修改的字段；其他字段保持不变。更改从下一次检查起生效。需要 `buy_energy` 权限。

规则的地址和时长无法修改。要把规则移到另一个地址，请删除它并创建一条新规则。

### 路径参数

<ParamField path="rule_id" type="number" required>
  规则 ID——创建或列出能量规则时返回的 `id`
</ParamField>

### 请求体

<ParamField body="threshold_energy" type="number">
  新的阈值。范围 1 至 50,000,000。
</ParamField>

<ParamField body="add_volume" type="number">
  每次补充的新能量数量。范围 32,000 至 5,000,000。
</ParamField>

<ParamField body="label" type="string">
  新的标签，最多 100 个字符。空字符串会移除标签。
</ParamField>

<ParamField body="status" type="string">
  `"paused"` 表示暂停规则，`"active"` 表示恢复规则。恢复时还会清除 `stopped_reason`，并将 `consecutive_failures` 重置为 0。因余额不足而停止的规则会在充值后自行恢复，因此您无需手动恢复；如果在余额仍然不足时恢复，它会在下一次检查时再次停止。`stopped_insufficient_balance` 不能直接设置。
</ParamField>

### 响应

更新后的规则，字段与[列出能量规则](/api-reference/auto-refill/list-energy-rules)中的相同。

### 示例

<CodeGroup>
```bash cURL
curl -X PATCH https://api.tronrental.com/v1/energy/auto-refill/12 \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"status": "paused"}'
```

```python Python
import requests

resp = requests.patch(
    "https://api.tronrental.com/v1/energy/auto-refill/12",
    headers={"X-API-Key": "your_api_key"},
    json={"status": "paused"},
)
print(resp.json())
```


### 错误

| 状态 | 代码 | 触发条件 |
|--------|------|------|
| `403` | `FORBIDDEN` | API 密钥缺少 `buy_energy` 权限 |
| `404` | `NOT_FOUND` | 您的账户中没有此 ID 的能量规则（或已被删除） |
| `409` | `AUTOREFILL_IN_PROGRESS` | 该规则的一次补充正在购买中——请一分钟后重试 |
| `422` | — | 数值超出范围，或 `status` 不是 `"active"` 或 `"paused"` |

```json

    }
  }
}
```
