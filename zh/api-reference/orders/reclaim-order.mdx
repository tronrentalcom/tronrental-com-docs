## 提前回收订单

立即取消您订单的带宽委托——例如地址已经完成了租用资源所需的转账——无需等待租期结束。**未使用的时间不予退款。** 仅带宽订单可以提前回收。

### 路径参数

<ParamField path="order_id" type="number" required>
  订单 ID —— Buy Bandwidth 返回的 `id`。
</ParamField>

### 响应

返回订单对象，与 Get Order 相同。`status` 表示处理结果：

| 状态 | 含义 |
|--------|-------------|
| `reclaimed` | 带宽已在本次请求中取消委托；`undelegate_txid` 为链上交易 |
| `filled` | 订单已排入下一个回收周期，通常在 30 秒内完成。结果通过 `order.updated` webhook 通知，或轮询 Get Order |
| `reclaiming` | 该订单的回收正在进行中 |
| `reclaim_failed` | 多次重试后，我们这边未能完成取消委托。您无需做任何事 |

对已处于 `reclaiming`、`reclaimed` 或 `reclaim_failed` 状态的订单再次调用，会原样返回订单，因此重试是安全的。API 密钥需要 `buy_bandwidth` 权限。

### 错误

| 代码 | 状态 | 情况 |
|------|--------|------|
| `ORDER_NOT_FOUND` | `404` | 您的账户下没有该订单 |
| `ORDER_NOT_RECLAIMABLE` | `409` | 订单尚未交付（`filled`）或已失败 |
| `BAD_REQUEST` | `400` | 不是带宽订单 |
| `FORBIDDEN` | `403` | API 密钥缺少 `buy_bandwidth` 权限 |

### 示例

```bash
curl -X POST https://api.tronrental.com/v1/orders/12345/reclaim \
  -H "X-API-Key: your_api_key"
```
