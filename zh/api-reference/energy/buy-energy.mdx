## 购买能量

将能量委托给指定的 TRON 地址。费用从您的账户余额中扣除。

### 请求体

<ParamField body="target_address" type="string" required>
  目标 TRON 地址（T... 格式，34 个字符）
</ParamField>

<ParamField body="volume" type="number" required>
  要委托的能量数量（最小 1，最大 5,000,000）
</ParamField>

<ParamField body="duration" type="string" required>
  租赁时长：`"1h"`（仅 1 小时）
</ParamField>

<ParamField body="max_price_trx" type="string">
  可选。您同意为该订单支付的最高金额（TRX）——租赁费与固定手续费合计。如果订单费用更高，将以 `409 PRICE_CHANGED` 被拒绝，**不会扣除任何费用**。请传入[价格估算](/zh/api-reference/energy/quote)返回的 `total_trx`。取值为大于 0 的十进制字符串，例如 `"2.15"`（也接受 JSON 数字）。不传时，订单按当前价格购买，与以往相同。
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
  可选，最多 64 个字符。使用同一个键和相同的请求体重试时，会返回原订单，而不会再次购买。订单成功后，同一个键配合不同的请求体——包括不同的 `max_price_trx`——会返回 `422 IDEMPOTENCY_KEY_REUSED`。若请求被拒绝且未扣除任何费用，例如 `409 PRICE_CHANGED` 或 `402 INSUFFICIENT_BALANCE`，该键可再次使用：用它和新价格重试即可。

  第一个带此键的请求仍在处理时，重试会收到 `409 IDEMPOTENT_REQUEST_IN_PROGRESS`：请等待几秒，并使用同一个键重试。如果无法检查该键，请求会在购买任何内容之前以 `503 IDEMPOTENCY_UNAVAILABLE` 被拒绝：请使用同一个键重试。键保留 24 小时；超过后，它将开启一次新的购买。
  见下方「超时与重试」一节。
</ParamField>

### 响应

<ResponseField name="id" type="number">
  唯一订单标识符
</ResponseField>

<ResponseField name="status" type="string">
  订单状态。最多 1,000,000 能量的订单通常直接返回最终状态：`filled` 或 `failed`。
  更大的订单会分批交付，可能返回 `processing`，最终为 `filled`、`partial` 或 `failed`。少于 32,000 的订单可能返回 `submitted_unknown`（见下方说明）。
  全部状态：[查询订单](/zh/api-reference/orders/get-order)。
</ResponseField>

<ResponseField name="txid" type="string | null">
  委托广播后的链上交易 ID。当 `provider_outcome` 为 `unknown_delivered` 时为空。
</ResponseField>

<ResponseField name="price_trx" type="string">
  从余额中扣除的总费用，以 TRX 计
</ResponseField>

<ResponseField name="reclaim_at" type="string | null">
  带宽租赁回收的 ISO 8601 时间戳（能量由提供方自动回收）
</ResponseField>

<ResponseField name="activation_cost_trx" type="string">
  地址激活费用（以 TRX 计），如已激活则为 `"0"`
</ResponseField>

<ResponseField name="provider_outcome" type="string | null">
  普通结果时为 `null`。否则用于说明不是单纯成功的结果：

  - `rejected` —— 确定没有交付。订单为 `failed`，全部费用已退回您的余额，`Idempotency-Key` 可再次使用。
  - `unknown` —— 交付确认丢失。订单为 `failed`（大订单为 `partial`），未确认的部分已退款，但这部分能量仍可能在几分钟内到达该地址。若到达，您无需为其付费。使用同一个 `Idempotency-Key` 重试会返回同样的结果；使用新的键则会再次购买，该地址随后可能收到两次能量。
  - `unknown_delivered` —— 确认丢失，但在链上找到了该委托。订单为 `filled` 并已扣费；`txid` 为空。
</ResponseField>

### 先展示价格，再按该价格购买

1. 使用您的 `X-API-Key` 调用 `GET /v1/energy/quote`，并向您的用户展示 `total_trx`。
2. 调用 `POST /v1/energy/buy`，并将 `max_price_trx` 设为该 `total_trx`。

报价按与订单扣费完全相同的方式舍入到 SUN，因此在价格不变期间，订单费用恰好等于 `total_trx`。能量价格随市场变动，可能在报价与购买之间发生变化：此时购买会在扣除任何费用之前以 `409 PRICE_CHANGED` 被拒绝——请重新获取报价、展示给用户，然后重试；如果您使用了 `Idempotency-Key`，请使用同一个键。

<Warning>
  `max_price_trx` 仅涵盖能量订单。如果 `target_address` 在链上尚未激活，激活费用会另行扣除（`activation_cost_trx`），且不会与 `max_price_trx` 进行比较。
</Warning>

### 超时与重试

请求一旦到达我们，即使您的连接断开，也会被处理到底：订单可能已创建并扣费，而您却没有收到响应。要安全地重试：

1. 为每次购买在您这边生成一个 `Idempotency-Key`（可使用您自己的订单 ID），并在调用之前保存好。
2. 遇到超时、连接错误或 `5xx` 响应时，使用同一个键、稍作停顿后再次发送相同的请求。您会得到原订单；如果第一个请求根本没有到达我们，这一次就会完成购买。
3. 遇到 `409 IDEMPOTENT_REQUEST_IN_PROGRESS` 时，请等待几秒，并使用同一个键重试。

结果不明时，切勿换用新的键：新的键就是一次新的购买。如果重试持续收到 `409 IDEMPOTENT_REQUEST_IN_PROGRESS` 超过一分钟，说明第一个请求在我们这边以意外状态结束——请在再次购买之前，到[订单列表](/zh/api-reference/orders/list-orders)中查找，或联系支持。不带键的重试始终是一次新的购买。

以下响应是最终的——没有扣除任何费用，且该请求以后也不会被处理：除 `409 IDEMPOTENT_REQUEST_IN_PROGRESS` 和 `422 IDEMPOTENCY_KEY_REUSED` 之外的任何 `4xx` 错误，以及错误码为 `POOL_EXHAUSTED` 或 `IDEMPOTENCY_UNAVAILABLE` 的 `503`。`422 IDEMPOTENCY_KEY_REUSED` 表示本次请求没有购买任何内容，但使用同一个键的更早请求可能已经购买。请按[错误](/zh/errors)中的说明解读错误码。

### 示例

<CodeGroup>
```bash cURL
curl -X POST https://api.tronrental.com/v1/energy/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "target_address": "TYourRecipientAddress1234567890abc",
    "volume": 65000,
    "duration": "1h"
  }'
```

```python Python
import requests

resp = requests.post(
    "https://api.tronrental.com/v1/energy/buy",
    headers={"X-API-Key": "your_api_key"},
    json={
        "target_address": "TYourRecipientAddress1234567890abc",
        "volume": 65000,
        "duration": "1h",
    },
)
print(resp.json())
```

```javascript JavaScript
const resp = await fetch("https://api.tronrental.com/v1/energy/buy", {
  method: "POST",
  headers: {
    "X-API-Key": "your_api_key",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    target_address: "TYourRecipientAddress1234567890abc",
    volume: 65000,
    duration: "1h",
  }),
});
console.log(await resp.json());
```
</CodeGroup>

```json Response
{
  "id": 12345,
  "status": "filled",
  "txid": "a1b2c3d4e5f6...",
  "price_trx": "2.75",
  "reclaim_at": "2026-06-10T05:30:00+00:00",

```

<Tip>
  **65,000 能量**可覆盖一笔向已持有 USDT 地址的转账。
  对于首次接收 USDT 的地址（新建存储槽），请使用 **131,000**。
</Tip>

<Note>
  **少于 32,000 能量的订单**由我们自己的能量池交付。如果当前无法为该地址提供服务，请求将以 `503 POOL_EXHAUSTED` 失败，**不会扣除任何费用**——请稍后重试，或订购 32,000 及以上。同一地址上一笔少于 32,000 的订单仍有效时，新订单也会以同样方式被拒绝。

  此类订单可能以 `submitted_unknown` 返回：委托已广播，但尚未在区块中确认。几分钟内会变为 `filled`，或变为 `failed` 并全额退款——请通过 [Get Order](/zh/api-reference/orders/get-order) 查询。
</Note>
