## 账单列表

返回您的账单分页列表。

### 查询参数

<ParamField query="page" type="number" default="1">
  页码
</ParamField>

<ParamField query="status" type="string">
  按状态筛选：`pending`、`paid`、`delegated`、`expired`、`failed`
</ParamField>

<ParamField query="from" type="string">
  周期的第一天，`YYYY-MM-DD`，含当天。两个日期都不传则返回完整列表。
</ParamField>

<ParamField query="to" type="string">
  周期的最后一天，`YYYY-MM-DD`，**含当天** —— 按您的时区计到 23:59:59.999。
</ParamField>

<ParamField query="tz" type="string">
  解析这两个日期所用的 IANA 时区，例如 `Europe/Berlin`。不传则按 UTC。
</ParamField>

<Info>
  与报表不同，列表没有一年的上限——它是分页的。两个日期都可选：只传 `from` 表示「从该日起」，只传 `to` 表示「截至该日（含）」。
</Info>

### 响应

返回包含 `invoices` 数组和 `total` 计数的分页对象。

### 示例

```bash
curl "https://api.tronrental.com/v1/invoices/my?page=1&status=delegated" \
  -H "X-API-Key: your_api_key"
```
