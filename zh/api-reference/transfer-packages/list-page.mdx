## 分页列出套餐

返回您的转账套餐的一页：主列表，或在 `archived=true` 时返回归档。未结束的套餐（生效中、已暂停、等待付款或激活）排在最前，其后按最新排序。控制台显示的就是这个列表；[套餐列表](/zh/api-reference/transfer-packages/list) 仍一次返回全部套餐。

### 查询参数

<ParamField query="archived" type="boolean" default="false">
  `true` — 归档（通过[归档钱包](/zh/api-reference/transfer-packages/archive)移入的套餐）；`false`（默认）— 主列表
</ParamField>

<ParamField query="page" type="number">
  页码（默认 1）
</ParamField>

<ParamField query="page_size" type="number">
  每页套餐数（默认 20，最多 100）
</ParamField>

### 响应

<ResponseField name="packages" type="array">
  该页的套餐 — 与[套餐列表](/zh/api-reference/transfer-packages/list)相同的对象，带 `label` 和 `archived_at`。
</ResponseField>

<ResponseField name="total" type="number">
  所请求列表的套餐总数（所有页）。
</ResponseField>

<ResponseField name="page" type="number">
  请求中的页码。
</ResponseField>

<ResponseField name="page_size" type="number">
  请求中的每页数量。
</ResponseField>

<ResponseField name="archived_packages" type="number">
  您的账户在归档中的套餐数 — 无论请求的是哪个列表。
</ResponseField>

<ResponseField name="archived_wallets" type="number">
  这些归档套餐所在的地址数。
</ResponseField>

```bash
curl "https://api.tronrental.com/v1/transfer-packages/list?page=1&page_size=20" \
  -H "X-API-Key: your_api_key"
```

### 错误

以[标准形式](/zh/errors)返回，错误码位于 `detail.error.code`。出现其中任何一个错误后，一切保持不变。

| 代码 | 状态 | 何时返回 |
|------|--------|------|
| — | `422` | `page` < 1, `page_size` ∉ 1–100 |
