## 购买转账套餐

使用您的账户余额购买转账套餐。

### 请求体

<ParamField body="address" type="string" required>
  要监控的 TRON 地址
</ParamField>

<ParamField body="package_size" type="number">
  套餐内的转账笔数（2 – 10,000）。除非 `single_transfer` 为 `true`，否则必填。`package_size: 1` 会被拒绝并返回 `422`——购买单笔转账请发送 `single_transfer: true`。
</ParamField>

<ParamField body="single_transfer" type="boolean" default="false">
  购买单笔转账而非套餐；此时忽略 `package_size`。价格为[获取套餐档位](/api-reference/transfer-packages/get-tiers)中的 `single_transfer_price`（启用带宽保障时另加 `bw_fee_per_transfer`）。
</ParamField>

<ParamField body="bw_guarantee" type="boolean" default="true">
  启用带宽保障
</ParamField>

### 响应

返回 `package_id`、`status`、`total_price_trx`、`activation_cost_trx`（地址尚未激活时用于激活的 TRX，否则为 `0`）和 `total_charged_trx`。

### 示例

```bash
curl -X POST https://api.tronrental.com/v1/transfer-packages/buy \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "address": "TYourAddress...",
    "package_size": 500,
    "bw_guarantee": true
  }'
```

```json Response
{
  "package_id": 101,
  "status": "active",
  "total_price_trx": "1500.0",
  "activation_cost_trx": "0",
  "total_charged_trx": "1500.0"
}
```

<Info>
  您也可以通过 `POST /api/v1/transfer-packages/buy-invoice` 使用账单付款 —
  这将生成一个用于 TRX/USDT 付款的地址。
</Info>
