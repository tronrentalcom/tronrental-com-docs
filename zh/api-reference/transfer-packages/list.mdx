## 我的套餐列表

返回您所有的转账套餐。

### 响应

套餐对象数组。主要字段：`id`、`address`、`package_size`、`quota_total`（套餐内转账次数）、`quota_used`（已服务的转账）、`subscription_used`（每日订阅费占用的转账，每天一次）、`remaining`（`quota_total − quota_used − subscription_used`）、`bw_guarantee`、`bw_fee_per_transfer` (关闭带宽保证时每笔剩余转账退回的金额；关闭时为 `null`)、`status`、`paused_at`（套餐被暂停的时间；仅当 `status` 为 `paused` 时有值，否则为 `null`）、`created_at`、`label`（您为该地址起的名称，见[为钱包命名](/zh/api-reference/transfer-packages/set-label)；`null` — 未命名）、`archived_at`（套餐归档的时间，见[归档钱包](/zh/api-reference/transfer-packages/archive)；`null` — 在主列表中）。

包含已归档的套餐。如需像控制台一样分页读取列表，请使用[分页列出套餐](/zh/api-reference/transfer-packages/list-page)。

### 套餐状态

| 状态 | 描述 |
|--------|-------------|
| `pending_payment` | 等待账单付款 |
| `provisioning` | 已用余额支付，正在激活 |
| `active` | 正在监控地址，转账可用 |
| `paused` | 已由您[暂停](/zh/api-reference/transfer-packages/pause)：不收取每日费用，转账不被服务也不计入套餐，剩余转账次数保留 |
| `completed` | 所有转账已用完 |
| `cancelled` | 已被用户取消 |
| `expired` | 账单未按时支付 |
| `manual_review` | 激活结果不明确，由客服核查，核查完成前款项暂扣 |
| `failed_refunded` | 激活失败，费用已退回余额 |
