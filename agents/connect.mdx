Every client below connects to the same server and signs you in with TronRental — no API key to copy:

```
https://mcp.tronrental.com/mcp
```

On first use the client opens tronrental.com. Sign in (or sign up), choose the account, tick the [permissions](/agents/reference/permissions), set the daily spending cap and approve. The client gets a token for this connection only.

## Check that it works

Ask the agent: *"Quote 65,000 energy for 1 hour on TronRental."* It calls `quote_energy` and shows the price — nothing is charged.

Before any purchase the agent quotes the price, shows it to you and passes it as `max_price_trx`; it also sends an `idempotency_key`, so a retry never charges twice. Purchases need top-ups of 100 TRX in total on the account — until then the connection can only read. See [Spending and errors](/agents/reference/spending-and-errors).

## Manage and disconnect

The **Connected apps** list on the [API page](https://tronrental.com/dashboard/api) shows every connected client: who connected it, its permissions, its daily cap and what it spent in the last 24 hours. Change the cap there, or click **Disconnect** to revoke the connection at once.

## Use an API key instead

Clients that let you set headers can connect with an [API key](/authentication) instead of signing in — for example, for an agent that runs on your server:

```bash
claude mcp add --transport http tronrental https://mcp.tronrental.com/mcp \
  --header "Authorization: Bearer $TRONRENTAL_API_KEY"
```

In Codex, put the key's environment variable in `~/.codex/config.toml`:

```toml
[mcp_servers.tronrental]
url = "https://mcp.tronrental.com/mcp"
bearer_token_env_var = "TRONRENTAL_API_KEY"
```

In Cursor, add `"headers": { "Authorization": "Bearer ${env:TRONRENTAL_API_KEY}" }` next to `url`.

An API key has no daily cap: give it only the scopes the agent needs. See [Build with MCP](/agents/build/overview).

## Agents without a browser

Agents that cannot open a browser can use the local package [@tronrental-com/mcp-server](https://www.npmjs.com/package/@tronrental-com/mcp-server): it runs on your machine with an API key in `TRONRENTAL_API_KEY`, or lets the agent register an account with your email and a code from it. Setup is in its [README](https://github.com/tronrentalcom/tronrental-com-mcp).
